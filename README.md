# 一念仙途 · HTML5 修仙卡牌决策游戏

## 怎么玩

直接双击 `index.html` 用浏览器打开即可。

或者本地起个服务：

```bash
cd xiuxian-card-game
python -m http.server 8080
```

然后打开 http://localhost:8080

## 操作方式

- **鼠标/手指**：在卡牌上按住滑动
- **键盘**：方向键 ↑↓←→
- **按钮**：点击屏幕下方的方向按钮

## 当前包含的系统

- 4 种功法开局（剑修、法修、体修、丹修）
- 炼气期 → 筑基期 → 金丹期 境界突破
- 五维属性：修为、道心、善因、恶因、福缘、气血
- 资源：灵石、寿元、丹药、法宝、道侣
- 因果系统：炼气期救白狐 → 筑基期报恩
- 秘境系统：古洞探险、神秘秘境
- 瓶颈突破：可服用丹药提高成功率
- 死亡与转世：死亡后保留解锁加成，转世重修

## 文件结构

```
xiuxian-card-game/
├── index.html          # 主页面
├── css/style.css       # 样式
├── js/cards.js         # 卡牌数据
├── js/game.js          # 核心逻辑
└── js/ui.js            # UI 与交互
```

## 后续打包 APK

等游戏玩法验证完，可以用以下工具把 HTML 打包成 Android APK：

- **HBuilderX**（最简单，可视化打包）
- **Cordova** / **Capacitor**

## 调试

打开浏览器控制台（F12）可以看到是否有报错。

## 已知简化

- 当前只做了炼气期、筑基期、金丹初期的卡牌内容，后续境界需要继续填充
- 功法 Build 差异主要体现在专属卡牌出现概率上，深度 Build 树后续扩展
- 多结局系统在当前版本简化为"飞升成仙"和常规死亡
