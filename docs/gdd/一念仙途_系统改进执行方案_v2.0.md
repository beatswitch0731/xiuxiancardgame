### 新增辅助方法 `_buildCombatWarning(combatCard)`

```javascript
_buildCombatWarning(combatCard) {
  const enemy = combatCard.enemy || {};
  const enemyName = enemy.name || '未知敌人';
  // 根据战场环境生成不同预警文案
  const warningTexts = {
    cave: `洞壁上的青苔被踩碎的声音从前方传来。你闻到了血腥气——${enemyName}正在前方等候。`,
    sect: `一道剑气划破空气，对方已发现你的气息。${enemyName}挡在了去路上。`,
    wilderness: `荒野中突然安静下来。你感到一股强烈的杀意从四面涌来——是${enemyName}。`,
    default: `前方出现了强大的气息。${enemyName}挡住了你的去路，似乎已准备好战斗。`
  };
  const battlefield = combatCard.battlefield || 'default';
  const desc = warningTexts[battlefield] || warningTexts.default;

  return {
    id: `_warning_${combatCard.id}`,
    title: '危险预感',
    description: desc,
    type: 'COMBAT_WARNING',
    _targetCombatCard: combatCard,
    choices: {
      left: {
        text: '迎战',
        desc: '正面应对，胜则有额外斗志加成。',
        effects: { daoHeart: 2 },
        _confirmCombat: true
      },
      right: {
        text: '服丹备战',
        desc: '消耗一颗丹药，为战斗做准备。',
        effects: { health: 15 },
        _confirmCombat: true,
        costCheck: { pill: 1 }
      }
    }
  };
}
```

### CardSystem.js 改动（核心逻辑）

**将 `advanceDungeon(nodeId)` 改为接受目标节点ID**：

```javascript
// FIX-4：图结构推进（替换原有 advanceDungeon）
advanceDungeon(exitKey) {
  const dungeons = this.dungeonCache.get(gameState.realm);
  const dungeon = dungeons ? dungeons[gameState.dungeon] : null;
  if (!dungeon) { gameState.dungeon = null; return; }

  // 新格式（图结构）
  if (dungeon.nodes && typeof dungeon.nodes === 'object' && !Array.isArray(dungeon.nodes)) {
    const currentNodeId = gameState.dungeonCurrentNode || dungeon.entryNode;
    const currentNode = dungeon.nodes[currentNodeId];
    if (!currentNode) { gameState.dungeon = null; return; }

    const nextNodeId = exitKey 
      ? (currentNode.exits && currentNode.exits[exitKey])
      : (currentNode.exits && (currentNode.exits.next || Object.values(currentNode.exits)[0]));
    
    if (!nextNodeId || nextNodeId === 'exit') {
      gameState.dungeon = null;
      gameState.dungeonCurrentNode = null;
      return;
    }
    gameState.dungeonCurrentNode = nextNodeId;
    return;
  }

  // 旧格式（数组）向后兼容
  gameState.dungeonNodeIndex = (gameState.dungeonNodeIndex || 0) + 1;
  if (gameState.dungeonNodeIndex >= dungeon.nodes.length) {
    gameState.dungeon = null;
    gameState.dungeonNodeIndex = 0;
  }
}
```

**`drawDungeon()` 同步更新读取当前节点**：

```javascript
// 在 drawDungeon 的节点获取处替换：
// 旧：const node = dungeon.nodes[gameState.dungeonNodeIndex];
// 新：
const node = Array.isArray(dungeon.nodes)
  ? dungeon.nodes[gameState.dungeonNodeIndex || 0]
  : dungeon.nodes[gameState.dungeonCurrentNode || dungeon.entryNode];
```

**分叉节点的选择项**：分叉类型节点（`type: "fork"` 或有多个exits的event节点）在卡牌的 `choices.left/right` 中携带 `_dungeonExit: "left"/"right"` 字段，`makeChoice` 中检测并传给 `advanceDungeon`：

```javascript

  cardSystem.advanceDungeon(choice._dungeonExit);

```

## FIX-6：叙事队列饥饿算法（P2）

### 问题
**文件**：`src/game.js` 第 314~316 行

低优先级叙事卡（NPC遭遇/势力事件 P=30~40）在道侣弧线卡（P=55）持续触发时永远排在后面，可能积压10+轮。

### 改动 — 在叙事队列排序中加入"饥饿权重"

```javascript
// 替换 _narrativeQueue.sort 逻辑（game.js 第316行附近）
const _now = Date.now();

// 为每个队列项计算有效优先级（考虑等待时间）
this._narrativeQueue.forEach(w => {
  if (!w._enqueuedAt) w._enqueuedAt = _now;
  const waitTurns = Math.floor((_now - w._enqueuedAt) / 1000); // 粗略转为"轮"
  // 每等待5轮，优先级提升1点，上限提升10点
  w._effectivePriority = (w.priority || w._narrativePriority || 0) + 
    Math.min(10, Math.floor(waitTurns / 5));
});

this._narrativeQueue.sort((a, b) => 
  (b._effectivePriority || 0) - (a._effectivePriority || 0)
);
```

**预期效果**：NPC遭遇卡等待约25轮后优先级提升5点，开始与道侣卡竞争出场，避免永久积压。

## FIX-7：普通卡池情绪调节（P2）

### 问题
**文件**：`src/systems/CardSystem.js` `_drawNormal()` 方法

普通卡池是纯随机抽取，没有情绪平衡逻辑。战斗后可能接着抽到另一张战斗卡。

### 改动 1/2 — 卡牌数据新增 `mood` 字段

```json
{ "id": "gather_herb", "mood": "relax", ... }
{ "id": "cave_beast",  "mood": "tense", ... }
{ "id": "trade_sect",  "mood": "neutral", ... }
```

三种情绪值：`tense`（紧张）/ `neutral`（中性）/ `relax`（放松）

### 改动 2/2 — `_drawNormal()` 末尾加入情绪权重调节

```javascript
// FIX-7：情绪权重调节（插入到 _drawNormal 的权重计算阶段）
_getEmotionMultiplier(card) {
  const history = gameState.cardHistory || [];
  const recent = history.slice(-3).map(c => c.mood || 'neutral');
  const tenseCount = recent.filter(m => m === 'tense').length;
  const relaxCount = recent.filter(m => m === 'relax').length;

  if (tenseCount >= 2 && card.mood === 'relax') return 3.0;  // 紧张后需要放松
  if (relaxCount >= 2 && card.mood === 'tense') return 1.5;  // 放松后适度增加张力
  if (tenseCount >= 2 && card.mood === 'tense') return 0.3;  // 避免连续高压
  return 1.0;
}
```

在 `_drawNormal()` 的 `totalWeight` 计算中乘以此系数：
```javascript
// 将 weight 替换为：
const emotionMult = this._getEmotionMultiplier(card);
totalWeight += card.weight * emotionMult;
```
