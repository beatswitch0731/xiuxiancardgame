# 关卡设计文档：锈蚀回廊（The Rust Corridor）

> 适用游戏：2.5D 等距视角像素风 Roguelike（移动端适配）
> 设计目标：在 6-8 分钟单局中，通过空间节奏、可读性布局和涌现战斗，让玩家感到“险象环生但公平”。

---

## 1. 意图（Intent）

### 玩家幻想
玩家是一位闯入废弃地下矿脉/古代水道的探索者。这个关卡要让人感觉：**潮湿、压抑、危险，但每死一次都能多读懂一寸地形。**

### 节奏弧线
| 阶段 | 情绪 | 空间特征 | 设计目的 |
|------|------|----------|----------|
| 1. 入口喘息 | 低紧张 | 开阔安全区 + 远景地标 | 让玩家确认操作手感、阅读终点方向 |
| 2. 教学式遭遇 | 中紧张 | 单通道 + 可破坏掩体 | 引入“水洼导电/减速”核心机制 |
| 3. 探索分叉 | 中低紧张 | 主路 + 奖励岔路 | 让玩家做风险/回报选择 |
| 4. 高压战斗 | 高紧张 | 竞技场 + 多入口 + 陷阱 | 检验玩家对机制的理解 |
| 5. Boss 前喘息 | 中紧张 | 狭窄补给廊 | 资源管理、决策窗口 |
| 6. Boss 战 | 极高 → 释放 | 分层竞技场 | 综合运用机制，击败后获得强烈正反馈 |

### 本关引入的新机制
**积水地面**：
- 玩家站在水中：移动速度 -20%，闪避距离 -30%
- 敌人站在水中：受电属性攻击伤害 +50%
- 水洼可被玩家/敌人的电击技能“传导”，形成链式 AOE

教学方式：第一间房间地面干燥，第二间在战斗区中央放一个明显的大水洼，敌人从水洼对面接近，玩家自然会发现“绕开水洼”或“把敌人引进去电疗”两种解法。

### 叙事节点
这是一条被废弃的“汲水矿道”。墙上残留的旧矿工涂鸦、断裂的轨道、倾倒的矿车，暗示这里曾发生过一次集体逃离。Boss 是留守的“水鬼监工”——一位被积水和电能异化的旧工头。

## 2. 布局规格（Layout Specification）

### 形状语言
**线性主道 + 3 个可选奖励腔室 + 1 个 Boss 前广场 + 1 个 Boss 竞技场**。整体呈“Z 字折叠”，避免一眼看穿，但始终保证玩家能在 3 秒内看到主路方向。

### 预计游玩时间
6-8 分钟（熟练玩家 4-5 分钟，探全奖励 9-10 分钟）

### 关键路径长度
约 12 个“房间节点”（包含 5 场强制遭遇、2 场可选遭遇、3 个奖励点、1 场 Boss 战）

### 可选区域
1. **左侧排水闸**：额外宝箱，但会刷出一波伏击怪
2. **上层矿桥**：捷径，可跳过后半段一个普通房间，但桥上无掩体、遭遇远程狙击
3. **沉没储藏室**：高风险高回报，全程在水洼中战斗，奖励为电系武器/技能

## 6. 房间详细规格（Room Blockouts）

### R01 入口安全区
- **尺寸**：约 16m × 12m
- **功能**：操作校准 + 空间定向
- **关键元素**：
  - 入口光从玩家身后照入，形成天然“回头路”暗示
  - 正前方远处 45° 角有一盏闪烁的蓝灯（Boss 广场方向），为主要视觉锚点
  - 右侧墙上一排旧矿镐作为环境叙事道具
  - 地面干燥，无敌人
- **可读性**：出口在 2 秒内可见；无隐藏威胁

### R02 教学房间（水洼初见）
- **尺寸**：约 14m × 10m
- **功能**：引入积水机制
- **关键元素**：
  - 中央 6m × 4m 水洼，颜色偏暗蓝，带轻微涟漪动画
  - 2 只哥布林从水洼对面刷新，玩家必须在“绕水洼”或“涉水硬打”间选择
  - 左侧有一根石柱，可作为掩体但无法绕背
- **教学验证**：观察测试者是否第一次就意识到水洼会减速；70% 玩家应能凭直觉避开或利用

### R03 分叉广场
- **尺寸**：约 18m × 14m
- **功能**：主路/奖励/捷径三向选择
- **关键元素**：
  - 主路：中间宽阔通道，地面较干燥，通向下一标准遭遇
  - 左岔：窄门洞，门上有锁链符号（暗示宝箱+伏击）
  - 右岔：向上斜坡，通向矿桥（捷径但高风险）
  - 正下方：沉没储藏室入口，被水淹没一半（暗示高奖励）
- **导航提示**：三条路用不同灯光色温区分：主路暖黄、左岔冷蓝、右岔自然灰白

### R04 主道标准遭遇
- **尺寸**：约 16m × 14m
- **功能**：应用水洼机制于常规战斗
- **关键元素**：
  - 房间两侧各有一根石柱，提供绕背空间
  - 中央一条“水洼通道”连接两个石柱，玩家可选择从干燥侧翼包抄，或把敌人拉进水洼电疗
  - 1 只投矛手站在远端高台上，必须先处理或利用掩体接近
- **战术**：至少 3 种有效打法（侧翼绕后、拉怪入水、远程点杀后收割）

### R05 高压竞技场
- **尺寸**：约 20m × 18m
- **功能**：高潮前置战斗
- **关键元素**：
  - 中央 10m × 8m 深水区，玩家和敌人进入均减速
  - 四角各有一个 2m × 2m 高台，可躲避近战但会被远程投矛威胁
  - 1 只精英电蟹会周期释放电链，若玩家站在水洼中会被传导击中
  - 增援会从玩家进入门对面的两个侧门同时出现，防止玩家堵门
- **节奏**：这是进入 Boss 前最后一次“机制综合考试”

### R06 Boss 广场/补给廊
- **尺寸**：约 12m × 8m（狭长）
- **功能**：喘息 + 资源决策
- **关键元素**：
  - 一个固定治疗泉（一次性回 30% HP）
  - 一个可破坏的物资箱（随机掉落血瓶/技能充能）
  - 通往 Boss  arena 的大门在尽头，门缝透出 Boss 战灯光
- **设计意图**：让玩家在“满状态进 Boss”或“贪一波资源”间做选择

### R07 Boss 竞技场（水鬼监工）
- **尺寸**：约 24m × 20m
- **功能**：Boss 战
- **关键元素**：
  - 场地分为三层：干燥外环、浅水中环、深水池心
  - 4 根可绕柱的石柱分布在外环，是玩家主要生存依靠
  - 深水区中央有 3 个可升降平台，Boss 放电时水面上升，玩家必须上台
  - Boss 三阶段：
    - P1（80%-100% HP）：普通近战 + 单次电链
    - P2（40%-80% HP）：召唤 2 波小怪，电链变为扇形
    - P3（0%-40% HP）：水面全面导电，玩家必须持续移动，平台升降频率加快
- **可读性**：Boss 每次放大的前 1.2 秒有蓄力闪光；水面导电时水色变亮作为预告

## 7. 环境叙事（Environmental Storytelling）

| 位置 | 叙事道具 | 玩家能推断出的故事 |
|------|----------|---------------------|
| 入口墙 | 褪色的矿工涂鸦：“水来了，先跑” | 这里曾发生突发透水事故 |
| R02 石柱 | 断裂的锁链和镣铐 | 可能曾有囚犯/劳工被锁在此地 |
| 分叉广场 | 倾倒的矿车挡住一条路 | 矿工逃离时慌乱翻车 |
| 排水闸 | 墙上干涸的血手印指向宝箱 | 有人为了宝藏被困死 |
| 矿桥 | 断裂的护栏和悬挂的残破绳索 | 桥上曾发生过追逐/坠落 |
| Boss 广场 | 成排的空工具架和腐烂的监工帽 | 这里曾是工头值守点 |
| Boss 竞技场 | 中央深水池底有累累骸骨 | 水鬼监工把许多人拖入了水中 |

## 8. 可读性审查清单（Navigation Affordance Checklist）

### 关键路径
- [x] 进入房间后 3 秒内可见出口方向（入口光/远处灯光/地面干燥路径）
- [x] 主路比岔路更亮，避免玩家把死胡同当正路
- [x] 没有“看起来像出口的死胡同”

### 战斗
- [x] 所有敌人在进入玩家受击范围前可被看见（E03 伏击有墙洞预告）
- [x] 每个遭遇点至少 2 种战术选择（侧翼/远程/控场/撤退）
- [x] 每个房间有明确 fallback 位置（门口、石柱后、高台）

### 探索
- [x] 岔路用不同灯光/地面材质区分
- [x] 奖励从选择点可见或可通过环境暗示（锁链、水淹、亮光）
- [x] 分叉广场无导航歧义：三条路视觉特征不同

### 移动端适配
- [x] 房间尺寸保证玩家拇指滑动半径内能完成一次闪避（最小开放空间 ≥ 4m × 4m）
- [x] 敌人攻击前摇 ≥ 0.5 秒，给触屏玩家反应时间
- [x] 关键 UI 提示（水洼减速、电链预警）使用大色块而非小文字

## 9. 迭代测试计划

### 灰盒测试（先不上美术）
1. 5 名测试者各玩 3 次，不告知水洼机制，观察自发发现率
2. 记录每个房间的死亡点，若同一房间死亡 >30% 则调整敌人数量或掩体
3. 测量到达 Boss 的平均时间，目标 6.5 分钟 ± 1 分钟

### 数据指标
- 首次通关率目标：35%（允许学习曲线）
- 平均死亡次数：2.5 次/局
- 探索全奖励率：>40%（说明可选路径有足够诱惑力）
- Boss 战失败率：50% 左右（Boss 作为难度峰合理）

## 10. 程序化规则补充（Roguelike 房间生成）

本关卡作为“锚点关卡” handcrafted，但若需 procedurally 生成同主题房间，遵守以下规则：

- **最小房间尺寸**：12m × 10m，保证至少 2 个战术位置
- **水洼覆盖率**：15%-35%，避免全程在水中或全程干燥
- **入口/出口**：必须互相可见或通过主道 3 秒内可达，禁止背对背的隐藏门
- **敌人密度**：每 10m² 不超过 0.8 个敌人（防止移动端屏幕拥挤）
- **奖励房间**：必须包含至少一个让玩家暴露在水中的风险点，否则奖励缺乏代价
- **Boss 房间固定**： always 生成分层水域 + 4 柱 + 3 升降平台，仅 Boss 技能组合可随机
