## 一、世界架构

### 1.1 界域结构

世界名为**苍茫界**，是下界三千小世界之一。整个宇宙分为三层：

| 层级 | 名称 | 说明 | 与游戏的关系 |
|------|------|------|-------------|
| **下界** | 苍茫界 | 玩家所在的世界，灵气浓度有限，最高可修炼至渡劫飞升 | 游戏本体全部内容 |
| **上界** | 仙庭天域 | 飞升后的世界，灵气浓郁，有仙职体系 | DLC/续作预留，本体仅在结局CG和天道线暗线中出现 |
| **混沌虚空** | 混沌 | 三千世界之间的间隙，混沌生物栖息之地 | 隐藏结局"混沌真解"相关，多周目收集碎片解锁 |

### 1.3 灵脉体系

苍茫界的灵气并非均匀分布，而是沿着**灵脉**流动：

- **主灵脉**：横贯中州，是正道六宗选址的根基。主灵脉上有十二个灵眼，每个灵眼处必有大宗门坐镇。
- **支灵脉**：延伸至四域，灵气浓度递减。西域支脉狂暴不稳，适合魔修吸纳；东海支脉温和纯净，适合丹修炼药。
- **暗灵脉**：隐藏在地底深处的古老灵脉，上古大战后断裂。部分秘境入口就在暗灵脉断裂处。
- **绝脉**：灵气完全枯竭之地，多为上古大战遗址。绝脉中常有上古遗宝，但也伴随着强大的禁制和诅咒。

### 1.4 天道法则

苍茫界受**天道**管辖，天道是这个世界的底层运行规则，不是一个人格化的神：

| 天道法则 | 内容 | 游戏体现 |
|----------|------|----------|
| **因果律** | 一切行为皆有后果，善因善果，恶因恶果 | 因果回溯系统 |
| **天劫律** | 修为达到一定程度必遭天劫，劫由心生、劫由因起 | 渡劫Boss战 |
| **寿元律** | 凡有生者必有死，修炼可延寿但不能永生（飞升前） | 寿元资源系统 |
| **灵根律** | 修炼天赋由灵根决定，灵根天生不可更改（转世除外） | 灵根系统 |
| **飞升律** | 渡劫成功者可破界飞升，前往上界 | 飞升结局 |
| **轮回律** | 身死道消者入轮回，前世因果不灭 | 转世重修系统 |

#### 天道的隐藏真相（暗线）

天道并非自古就有。上古时代，苍茫界原本没有天道法则，修炼者可以无限制提升修为而不受天劫。后来发生了一场被称为**"太古浩劫"**的灾难——具体内容已失传，只知道那场浩劫之后，天道法则降临，从此修炼者必须渡天劫才能飞升。

**真相**（仅在天道线和隐藏结局中揭示）：天道是上界仙庭设下的"筛选机制"，天劫不是为了考验，而是为了**控制**下界修士的数量和实力。飞升者到了上界就成为仙庭的"棋子"，而不飞升的修士永远困在下界。混沌真解结局就是看穿这个真相，以混沌之力打破天道束缚，不入仙庭，自成一道。

### 2.2 正道联盟 — 六大宗门

正道六宗占据中州主灵脉的六个灵眼，结成联盟已逾万年。

| 门派 | 灵眼位置 | 主修功法 | 掌门境界 | 特色 | 游戏中的角色 |
|------|----------|----------|----------|------|-------------|
| **青云剑宗** | 中州东灵眼 | 剑修（剑意流） | 化神巅峰 | 剑道至尊，门规森严，"剑出无悔" | 玩家可拜师门，师门线核心 |
| **天枢道院** | 中州中灵眼 | 法修（五行流） | 化神中期 | 术法百科，兼容并蓄，学术氛围浓 | 法修玩家师门，提供多选项卡牌 |
| **万象体宗** | 中州北灵眼 | 体修（筋骨流） | 化神初期 | 肉身成圣，门人稀少但个体极强 | 体修玩家师门，战斗卡丰富 |
| **神农丹谷** | 东海仙岛 | 丹修（丹方流） | 化神中期 | 丹道泰斗，掌控丹药市场命脉 | 丹修玩家师门，丹药获取渠道 |
| **天机阁** | 中州西灵眼 | 阵修（辅阵流） | 化神后期 | 阵法第一，掌管天机盘碎片 | 阵修玩家师门，天机盘系统来源 |
| **灵符宗** | 中州南灵眼 | 符修（符箓流） | 化神初期 | 符道传承，一次性爆发型战斗 | 符修玩家师门，符箓资源来源 |

#### 正道联盟内部矛盾

六宗联盟并非铁板一块：

- **青云剑宗 vs 天枢道院**：剑修认为法修"博而不精"，法修认为剑修"莽夫之勇"。两宗弟子经常私下斗法。
- **天机阁的独立性**：天机阁掌握天机盘碎片，对天道有独到见解，经常做出与其他五宗相左的决策。暗线中天机阁掌门是唯一知道天道真相的正道修士。
- **万象体宗的衰落**：体修修炼周期长、收徒困难，体宗门人最少，但单个弟子战力最强。近年来有被边缘化的趋势。
- **神农丹谷的经济霸权**：丹谷控制着全界七成以上的丹药流通，其他门派虽然不服，但离了丹药供给就打不了渡劫战。

### 2.3 魔道联盟 — 三宗一阁

魔道势力盘踞西域荒漠和北荒边缘，以"弱肉强食"为核心信条。

| 门派 | 据点 | 主修功法 | 宗主境界 | 特色 | 游戏中的角色 |
|------|------|----------|----------|------|-------------|
| **血煞宗** | 西域血煞绿洲 | 剑修（杀伐流） | 化神巅峰 | 以杀证道，血祭之法，剑修魔道分支 | 正魔线核心冲突源，魔修邀约卡来源 |
| **万毒门** | 南疆边缘 | 法修（毒术流） | 化神中期 | 毒术通神，与妖族有暗中合作 | 蛊毒危机事件，魔道合作选项 |
| **幽冥阁** | 北荒冥谷 | 符修（禁术流） | 化神后期 | 专精禁术，阴阳符咒，召唤亡灵 | 禁术诱惑卡，宿命卡来源 |
| **噬魂宗** | 西域幽魂沙漠 | 符修（咒道流） | 化神初期 | 魂道禁术，吞噬他人修为 | 恶因的主要来源，魔修Build支持 |

#### 魔道联盟内部矛盾

- **血煞宗 vs 噬魂宗**：两宗都走杀伐路线，经常争夺资源和地盘。血煞宗崇尚正面碾压，噬魂宗喜欢暗中偷袭，互相看不起。
- **万毒门的骑墙**：万毒门与南疆妖族有秘密同盟，在正魔大战中经常首鼠两端。
- **幽冥阁的野心**：幽冥阁宗主暗中研究上古亡灵术，试图复活太古浩劫中陨落的大能，这是整个苍茫界最大的定时炸弹。

### 2.4 妖族十三部

妖族是苍茫界的原住民，比人类修士更早存在。太古浩劫后势力大减，退守南疆密林和北荒冰原。

| 妖族 | 领地 | 族长境界 | 特征 | 游戏中的角色 |
|------|------|----------|------|-------------|
| **白狐部** | 南疆边缘 | 金丹（族长）/ 元婴（老祖） | 幻术传承，善于化形，与人类修士关系最密切 | 因果链核心——白狐报恩线 |
| **蛟龙部** | 东海深处 | 元婴 | 水系妖族，掌控海域，与丹修有丹材交易 | 东海事件卡，海妖遭遇 |
| **金鹏部** | 北荒高空 | 元婴 | 速度极快，领地意识强，攻击入侵的修士 | 北荒探索卡，飞行妖兽遭遇 |
| **玄龟部** | 北荒冰湖 | 化神 | 防御极强，龟甲是顶级炼器材料，但玄龟部严禁猎杀 | 法宝获取线，体修机缘 |
| **九尾部** | 南疆深处 | 化神（九尾天狐） | 白狐部的上位种族，九尾天狐是妖族最强者之一 | 高阶道侣线，妖族剧情线 |
| **岩甲部** | 北荒山地 | 金丹 | 矿脉守护者，甲壳坚硬，秘境守兽常由岩甲兽担任 | 秘境战斗卡来源 |
| **冥蛇部** | 南疆毒沼 | 金丹 | 毒系妖族，与万毒门有合作关系 | 蛊毒事件，毒系战斗 |
| **天狼部** | 北荒草原 | 元婴 | 群居妖族，战力强悍，与血煞宗有世仇 | 正魔线支线，妖族恩怨 |

| **冰蚕部** | 北荒冰原 | 筑基（族长）/ 金丹（老祖） | 吐丝可织法袍，冰蚕丝是顶级阵法材料 | 法宝获取线，阵修材料 |
| **混沌兽** | 虚空裂隙 | 未知 | 太古遗种，极罕见，混沌碎片携带者 | 隐藏结局线核心NPC |

#### 妖族与人类的关系

太古浩劫前，妖族是苍茫界的主宰。浩劫后灵气衰退，妖族势力大减，被人类修士挤压到边缘地带。

- **正道修士**普遍视妖族为"妖兽"——可杀取内丹、可炼丹炼器。这是正魔线的主要冲突源之一。
- **魔修**与部分妖族有合作（万毒门+冥蛇部），但本质是利用关系。
- **妖族道侣**是人类修士与妖族和解的唯一桥梁。拥有妖族道侣的修士会触发正道排斥事件（正魔线），但也可能获得妖族功法加持。
- **九尾天狐**是唯一与正道六宗有正式和平协议的妖族首领。白狐部在她的庇护下勉强维持与人类的和平。

### 2.5 中立势力

不属于正魔任何一方的独立势力：

| 势力 | 据点 | 性质 | 游戏中的角色 |
|------|------|------|-------------|
| **散修联盟** | 西域各大绿洲城邦 | 松散联盟，互通有无，无统一领导 | 散修路线卡牌，坊市交易，灰色地带事件 |
| **万象商会** | 中州、西域、东海均有分部 | 跨阵营商业组织，贩卖丹药、法宝、情报 | 商人卡牌，灵石消费渠道，拍卖会事件 |
| **器修宗** | 东海器修岛 | 专精炼器的中小门派，不参与正魔之争 | 法宝获取/修复/升级 |
| **轮回殿** | 位置不明，传说在地底暗灵脉交汇处 | 神秘组织，研究轮回与因果，与天道有隐秘关联 | 转世系统叙事包装，宿命卡来源 |
| **天外楼** | 悬浮在中州上空的仙舟 | 独立于地面的空中势力，由渡劫失败的散仙组成 | 高阶事件卡，跨境界奇遇 |

### 2.6 混沌教（隐藏势力）

**玩家在一周目几乎不会遇到**的隐藏势力，仅在多周目收集混沌碎片后逐渐显现：

- **信条**：天道是牢笼，飞升是骗局，唯有混沌之力能打破轮回
- **成员**：极少数，都是看穿了天道真相的化神期以上的修士，他们选择不飞升，暗中收集混沌碎片
- **首领**：**虚无道人**——据传是太古浩劫的幸存者，修为已不可测，从未现身
- **游戏作用**：混沌碎片收集线最终指向混沌教，解锁隐藏结局"混沌真解"

### 3.3 战力对比参照

以炼气初期 = 1为基准：

| 境界 | 相对战力 | 能做到的事 |
|------|----------|-----------|
| 炼气 | 1-5 | 肉身强化，简单术法，感知灵气 |

**跨境界战斗**：正常情况下一个大境界差距 = 不可战胜。但有例外：

- **以多欺少**：3-5个同境界修士围攻可以对抗高一个小境界的对手
- **天时地利**：阵修在自家阵法中可以越级

## 四、修炼方式与功法体系

### 4.1 六大功法详解

#### 剑修 — 一剑破万法

**核心理念**：以剑入道，剑即是道。不求万法通，但求一剑精。

**修炼方式**：
- **养剑**：炼气期以灵气温养剑胚（可以是实体剑，也可以是体内凝聚的剑意）
- **凝剑**：筑基期凝聚剑气，剑气可离体伤敌
- **剑意**：金丹期领悟剑意，剑意成型后可斩无形之物（心魔、因果）
- **剑域**：元婴期展开剑域，域内万物皆为剑
- **剑心**：化神期剑心通明，万物皆可为剑，一念可斩

**功法分支**：
```
剑修
├── 剑意流（攻击向）: 剑气 → 剑意 → 剑域 → 剑心
│   特征：极致攻击，一击必杀，但防御薄弱
│   代表人物：青云剑宗掌门 白刃真人
│
├── 剑体流（防御向）: 剑骨 → 剑肤 → 剑脏 → 剑心
│   特征：以身化剑，肉身即剑，攻防一体
│   代表人物：万象体宗客卿长老 铁剑翁
│
└── 剑魂流（召唤向）: 剑灵 → 剑仆 → 剑阵 → 剑心
    特征：操控飞剑群，以量取胜，可远程消耗
    代表人物：青云剑宗前任掌门 万剑老祖（已化神飞升）
```

**剑修专属卡牌主题**：剑冢共鸣、剑意突破、万剑归宗、剑心通明、以剑斩因果

**剑修的天劫**：**万剑噬主**——天劫化万剑反噬，剑修必须以自身剑意对抗天劫之剑。越级使用禁剑的剑修，天劫之剑会更多更锋利。

---

#### 法修 — 诸术并修

**核心理念**：万法归一，不拘一术。以天地灵气为笔，以五行法则为墨，书写万变之术。

**修炼方式**：
- **识术**：炼气期学习基础术法，火球、水幕、土墙、木藤、金刃
- **融术**：筑基期融合五行术法，产生复合效果（如风水合→冰刃）
- **悟法**：金丹期领悟术法本质，可自创术法
- **法域**：元婴期展开法域，域内法则由法修掌控
- **万法归一**：化神期万法通明，一法即万法

**功法分支**：
```
法修
├── 五行流: 五行术 → 五行阵 → 五行遁 → 五行真解
│   特征：均衡发展，攻防兼备，最正统的法修路线
│   代表人物：天枢道院掌院 玄机真人
│
├── 雷法流: 掌心雷 → 雷池 → 雷劫体 → 雷神降世
│   特征：极致毁灭力，与天劫亲和（双刃剑），雷变异灵根专属
│   代表人物：天枢道院雷峰首座 惊雷子
│
└── 符法双修: 符箓精通 → 阵法通晓 → 万法归一
    特征：兼修符阵，灵活性极高，但每项都不精通
    代表人物：天枢道院万象堂主 灵笔居士
```

**法修专属卡牌主题**：五行生克、术法组合、法域展开、万法归一、五行神雷（天劫）

**法修的天劫**：**五行神雷**——天劫按五行相生相克排列，法修必须用对应属性的术法应对。选错属性 = 伤害加倍。法修独有多选项卡，在天劫中可以更准确地选择应对方式。

---

#### 体修 — 肉身成圣

**核心理念**：以身化道，万法不侵。肉身即是最强法宝，最坚硬的阵法。

**修炼方式**：
- **锻体**：炼气期以灵气淬炼筋骨皮肉，承受常人难以想象的痛苦
- **淬骨**：筑基期灵力渗入骨骼，骨如精铁
- **炼脏**：金丹期灵力淬炼五脏六腑，内脏坚不可摧
- **战体**：元婴期肉身蜕变，形成"战体"——超凡肉身形态
- **肉身成圣**：化神期肉身与法则融合，万法不侵，肉身即是道

**功法分支**：
```
体修
├── 筋骨流: 铁骨 → 铜皮 → 银血 → 金身
│   特征：极致防御，打不死的小强，但攻击力不足
│   代表人物：万象体宗掌门 金刚不坏
│
├── 内脏流: 炼心 → 淬肺 → 养肾 → 合道
│   特征：内功绵长，续航极强，后期爆发力惊人
│   代表人物：万象体宗内院首座 五脏翁
│
└── 战体流: 战意 → 不屈 → 不灭 → 修罗
    特征：越战越强，受伤越重攻击越高，狂战士路线
    代表人物：万象体宗客卿（已叛逃至血煞宗） 修罗
```

**体修专属卡牌主题**：淬体试炼、肉身突破、硬扛天劫、气血沸腾、以力破法

**体修的天劫**：**肉身重塑**——天劫不降雷，而是以天劫之力重塑肉身。成功了肉身成圣，失败了肉身崩碎。体修在天劫中反而比其他功法更从容，因为他们的渡劫方式就是"硬扛"。

---

#### 丹修 — 以丹入道

**核心理念**：万物皆可入丹，以丹之力悟天地之道。丹道通天，一颗金丹可改命。

**修炼方式**：
- **识药**：炼气期辨识灵药，学习药理基础
- **控火**：筑基期掌握丹火，开始正式炼丹
- **成丹**：金丹期丹术大成，可炼制高阶丹药
- **丹劫**：元婴期丹术引发丹劫——天地不容凡人炼出仙丹
- **丹道通神**：化神期以丹入道，一颗丹药可改变一场战争的走向

**功法分支**：
```
丹修
├── 丹方流: 丹方辨识 → 火候掌控 → 炼丹宗师 → 丹道通神
│   特征：正统丹修，以丹方和火候为核心，稳定产出
│   代表人物：神农丹谷谷主 药圣
│
├── 药理流: 药性识别 → 毒丹 → 禁丹 → 以丹入道
│   特征：偏门丹修，善用毒丹和禁丹，与魔道有交集
│   代表人物：神农丹谷禁药堂主 毒丹真人（已叛逃至万毒门）
│
└── 养生流: 养生 → 延寿 → 不死 → 长生
    特征：以丹延寿为核心，修炼速度最慢但寿元最长
    代表人物：神农丹谷长老 长生叟（据说活了九千岁）
```

**丹修专属卡牌主题**：炼丹成功/失败、丹方获取、丹毒反噬、延寿丹、禁丹诱惑

**丹修的天劫**：**丹毒劫**——天劫化为丹毒反噬全身，丹修必须以自身丹术化解。平时炼丹积累的丹毒越多，天劫越猛。但丹修也是唯一可以用丹药对抗天劫的功法（渡厄丹+0.5秒）。

---

#### 阵修 — 阵法控场

**核心理念**：天地为盘，万物为子。以阵法改写规则，以阵眼掌控生死。

**修炼方式**：
- **识阵**：炼气期学习阵法基础，阵纹绘制
- **布阵**：筑基期可独立布置中级阵法
- **阵意**：金丹期领悟阵意，可即时布阵（不用预先准备）
- **阵域**：元婴期展开阵域，域内规则由阵修改写
- **天地棋局**：化神期以天地为阵，山川河流皆为阵眼

**功法分支**：
```
阵修
├── 困阵流: 迷阵 → 困阵 → 杀阵 → 诛仙阵
│   特征：以困杀敌，消耗战，防御极强
│   代表人物：天机阁杀阵堂主 万阵叟
│
├── 辅阵流: 聚灵阵 → 护山大阵 → 传送阵 → 天地棋局
│   特征：辅助型，增益己方，传送机动，战略价值极高
│   代表人物：天机阁掌阁 天机老人
│
└── 符阵流: 符阵入门 → 阵符合一 → 万法阵眼 → 阵道真解
    特征：符阵双修，灵活多变，但上限不如纯阵流
    代表人物：天机阁符阵堂主 灵阵子
```

**阵修专属卡牌主题**：布阵/破阵、阵眼控制、天机盘拨动、规则改写、阵法反噬

**阵修的天劫**：**阵眼崩塌**——天劫从内部瓦解阵修的阵法，阵修必须在天劫中不断修补和重构阵法。阵修是天机盘的主要使用者，在天劫中可以免费拨动天机盘。

---

#### 符修 — 符道通神

**核心理念**：一笔画天地，一符镇乾坤。符箓是法则的载体，是浓缩的术法。

**修炼方式**：
- **画符**：炼气期学习符文绘制，以灵力为墨
- **蓄符**：筑基期可储存符箓，战斗时一次性释放
- **灵符**：金丹期符箓有灵，可自主追踪目标
- **符阵**：元婴期符箓可组成阵法，效果倍增
- **天符**：化神期可绘制天符——直接调用天道法则的符箓

**功法分支**：
```
符修
├── 符箓流: 基础符 → 中级符 → 高级符 → 天符
│   特征：正统符修，攻击/防御/辅助符都有，全能型
│   代表人物：灵符宗掌门 千符真人
│
├── 召唤流: 纸人 → 阴兵 → 鬼神 → 天兵
│   特征：召唤型，以量取胜，与幽冥阁有渊源
│   代表人物：灵符宗召唤堂主 阴符叟
│
└── 禁术流: 血符 → 命符 → 禁咒 → 咒道
    特征：以血/寿命为代价的强力符术，极度危险
│   代表人物：幽冥阁阁主（叛出灵符宗后自创咒道）
```

**符修专属卡牌主题**：画符成功/失败、符力爆发、血符代价、天符降临、符力暴走

**符修的天劫**：**符力暴走**——天劫引发体内符力失控，符修必须在符力暴走中维持自身稳定。平时储存的符箓太多，天劫时暴走更严重。

### 4.2 修炼通用知识

#### 修炼的基本要素

| 要素 | 说明 | 游戏体现 |
|------|------|----------|
| **灵气** | 天地间的能量，修炼的基础资源 | 每轮自动获取（修为缓慢增长） |
| **功法** | 吸收和运用灵气的方法，决定修炼方向 | 功法选择 |
| **丹田** | 储存灵力的核心，位于小腹 | 境界突破的叙事描述 |
| **经脉** | 灵力运行的通道，全身有十二正经+奇经八脉 | 走火入魔的叙事描述 |
| **神识** | 精神力量，可感知周围、攻击他人神魂 | 元婴期解锁元神分身 |
| **道心** | 修炼者的意志和信念，道心不稳则走火入魔 | 道心属性条 |

#### 修炼的日常

一个修士的日常修炼包括：
1. **吐纳**：吸收灵气，温养丹田（最基础的修炼方式）
2. **运功**：引导灵力在经脉中运行，疏通经脉
3. **参悟**：领悟功法精要，提升境界理解
4. **实战**：通过战斗磨炼术法和心境
5. **闭关**：长时间封闭修炼，通常在突破前进行

#### 灵石经济

灵石是修仙界的硬通货：

| 灵石品质 | 灵气含量 | 等价物 | 获取方式 |
|----------|----------|--------|----------|
| 下品灵石 | 1单位 | 基础货币 | 灵石矿开采、任务报酬 |
| 中品灵石 | 100单位 | 100下品 | 高阶矿脉、金丹以上修士凝聚 |
| 上品灵石 | 10000单位 | 100中品 | 顶级矿脉、元婴以上修士凝聚 |
| 极品灵石 | 无限接近纯净灵气 | 无价 | 传说级，仅化神以上修士可凝聚 |

> 游戏中的"灵石"默认指下品灵石。100灵石 = 1中品灵石。后期境界可能切换为中品灵石计价。

## 五、修炼秘闻与禁忌

### 5.1 修炼禁忌

这些是修仙界公认的禁忌，触犯者会遭到正道追杀：

| 禁忌 | 内容 | 后果 | 游戏体现 |
|------|------|------|----------|
| **采补之术** | 以夺取他人修为来提升自己 | 恶因暴涨，天劫难度倍增 | 魔修邀约卡，恶因+20 |
| **炼魂为器** | 将活人灵魂炼入法器 | 恶因爆表，被正道六宗联合追杀 | 幽冥阁相关事件，宿命卡 |
| **以人炼丹** | 以活人为丹材炼丹 | 恶因满值，直接触发天劫降世 | 万毒门相关事件 |
| **逆乱经脉** | 强行逆转经脉运行方向 | 短暂战力暴增，但走火入魔概率90% | 禁术选项，道心暴扣 |
| **截断灵脉** | 破坏大地灵脉 | 天道降下"天罚"（非天劫，是直接毁灭性打击） | 高阶因果事件 |
| **沟通混沌** | 尝试接触混沌虚空中的存在 | 获得混沌碎片，但可能引来混沌生物 | 隐藏线触发条件 |

### 5.2 修炼秘闻

这些是修仙界流传的秘闻，部分为真，部分为谣传，玩家需要通过探索验证：

| 秘闻 | 内容 | 真实度 | 游戏体现 |
|------|------|--------|----------|
| **剑冢之秘** | 青云剑宗的剑冢深处埋着一把上古仙剑，只有剑心通明者才能拔出 | 真。但仙剑是上界仙人留下的"监视器" | 剑修专属卡，天道线碎片 |
| **丹谷禁地** | 神农丹谷的禁地中藏着一颗"不死丹"配方 | 半真。配方存在，但材料需要混沌之力 | 丹修专属线，隐藏结局碎片 |

| **轮回殿** | 传说有一个超越正魔两道的神秘组织，掌控轮回之力 | 真。轮回殿确实存在，与混沌教有隐秘关联 | 转世叙事包装，宿命卡来源 |
| **飞升骗局** | 有修士声称飞升不是登仙，而是被上界"收割" | 真。这是天道线的核心真相 | 天道线，隐藏结局 |
| **太古浩劫** | 万年前有一场毁天灭地的大战，之后天道法则才出现 | 真。浩劫是上界仙庭为了控制下界而发动的 | 混沌线，隐藏结局 |

## 六、秘境体系

### 6.1 秘境总览

秘境是上古大战遗留的特殊空间，内部灵气浓郁、宝物众多，但也危机四伏。苍茫界已知秘境如下：

| 秘境名称 | 位置 | 进入条件 | 危险等级 | 主要奖励 | 游戏中的对应 |
|----------|------|----------|----------|----------|-------------|
| **剑冢秘境** | 青云剑宗后山 | 剑修专属，筑基以上 | ★★★ | 残剑、剑意感悟、剑修法宝 | 剑修专属秘境卡 |
| **万药谷** | 东海仙岛深处 | 丹修专属或药理流，筑基以上 | ★★ | 灵药、丹方、丹修材料 | 丹修专属秘境卡 |
| **上古战场** | 北荒冰原 | 任意功法，金丹以上 | ★★★★ | 上古法宝、残缺功法、混沌碎片(极低概率) | 通用高阶秘境 |
| **龙宫遗址** | 东海海底 | 水系功法或法修，金丹以上 | ★★★★ | 龙族法宝、水系功法、蛟龙内丹 | 法修/丹修秘境 |
| **天魔窟** | 西域荒漠深处 | 任意功法，元婴以上 | ★★★★★ | 魔道至宝、禁术、大量灵石 | 高阶通用秘境 |
| **轮回殿遗址** | 位置不明，暗灵脉交汇处 | 需要特殊因果触发 | ★★★★★ | 因果相关法宝、轮回碎片、混沌碎片 | 隐藏秘境，多周目触发 |
| **混沌裂隙** | 虚空薄弱处随机出现 | 需携带混沌碎片 | ★★★★★★ | 混沌碎片、混沌灵根碎片 | 终极隐藏秘境 |

### 6.2 秘境详细设计

#### 剑冢秘境（剑修专属）

```
入口: 剑冢石门
  ↓
第1层: 残剑长廊（战斗×2 + 事件×1）
  - 战斗: 剑灵残影（剑修中期强度）
  - 事件: 剑意石碑（领悟基础剑意，修为+20）
  ↓
第2层: 剑池（休息×1 + 战斗×1 + 宝箱×1）
  - 休息: 剑池温养（气血全恢复，道心+10）
  - 宝箱: 残剑碎片（可合成"断罪剑"——剑修专属法宝）
  ↓
第3层: 剑冢之主（Boss战）
  - Boss: 上古剑灵（金丹后期强度）
  - 胜利奖励: 剑意感悟（修为+40） + 法宝"断罪剑"
  - 失败: 气血-50，被驱逐出秘境
```

**卡牌主题**：剑气纵横、残剑共鸣、剑灵考验、剑意领悟、断罪之剑

#### 万药谷（丹修专属）

```
入口: 药谷迷雾
  ↓
第1层: 灵药园（采集×2 + 事件×1）
  - 采集: 百年灵芝（丹药材料）+ 龙涎草（稀有材料）
  - 事件: 药灵对话（获得丹方"回春丹"或"延寿丹"）
  ↓
第2层: 炼丹室（事件×1 + 战斗×1 + 商人×1）
  - 事件: 上古丹炉（可炼制一颗免费丹药）
  - 战斗: 药叉兽（守护丹炉的妖兽）
  - 商人: 药灵商人（以灵石换丹方/材料）
  ↓
第3层: 药王遗府（Boss战）
  - Boss: 药王残魂（金丹中期强度，会使用毒术）
  - 胜利奖励: 丹方"破境丹" + 法宝"万宝炉"（丹修专属）
  - 失败: 中毒，气血持续下降3轮
```

**卡牌主题**：灵药采集、丹方获取、药叉战斗、药王考验、万宝炉认主

#### 上古战场（通用高阶）

```
入口: 冰原裂缝
  ↓
第1层: 遗骸平原（事件×2 + 战斗×1）
  - 事件: 上古修士遗骸（可选择安葬获善因，或搜刮获资源+恶因）
  - 事件: 残破阵法（阵修可修复获阵法感悟，其他功法需绕路）
  - 战斗: 冰封亡灵（筑基强度的不死生物）
  ↓
第2层: 灵宝阁（宝箱×1 + 陷阱×1 + Boss×1）
  - 宝箱: 随机上古法宝（可能是攻击/防御/特殊型）
  - 陷阱: 上古禁制（触发则气血-30，道心-10）
  - Boss: 冰封战将（金丹后期强度，物理攻击极强）
  ↓
第3层: 浩劫记忆（事件×1 + 隐藏Boss×1）
  - 事件: 上古记忆碎片（获得天道线线索，5%概率获得混沌碎片）
  - 隐藏Boss: 太古残魂（化神强度，极难击败，但击败后必得混沌碎片）
```

**卡牌主题**：遗骸安葬/搜刮、冰封亡灵、上古法宝、禁制陷阱、浩劫记忆、太古残魂

#### 轮回殿遗址（隐藏秘境）

```
触发条件: 累计转世3次以上，且携带前世未了因果≥5个
  ↓
入口: 轮回之门（需要消耗1个因果种子作为"门票"）
  ↓
第1层: 前世回廊（事件×3）
  - 前世记忆重现：玩家看到自己前几世的关键决策
  - 每个事件都是"如果当时选了另一个选项会怎样"的if线
  - 选择正确（与前世善因一致）获奖励，错误（矛盾）获惩罚
  ↓
第2层: 因果审判庭（Boss战）
  - Boss: 轮回判官（元婴强度，但会使用玩家的前世因果作为攻击手段）
  - 战斗中会出现"前世所杀之人的幻象"作为心魔卡
  ↓
第3层: 轮回之眼（事件×1）
  - 获得法宝"轮回镜"（因果型法宝，宿命卡提前2轮显示）
  - 10%概率获得混沌碎片
  - 获得天道线重要线索
```

**卡牌主题**：前世回溯、if线抉择、因果审判、心魔幻象、轮回之眼

### 6.3 秘境通用规则

- **秘境内不触发常规因果种子**：避免因果系统在秘境中交叉复杂化
- **秘境专属卡池**：每个秘境有专属卡牌，不影响主卡池
- **退出机制**：可随时退出，保留一半奖励；Boss战失败失去全部奖励
- **每局限1次**：每局游戏最多进入1次秘境
- **境界限制**：炼气期不出现秘境入口；筑基以上才可能出现

## 十二、世界暗线与隐藏真相

### 12.1 暗线总览

游戏有四条暗线，需要多周目游玩才能完整拼凑：

```
暗线1: 天道阴谋线
  化神期天道选择 → 天机老人揭露 → 万卷楼天道书 → 上古战场浩劫记忆 → 飞升骗局真相
  → 结局: 因果归一(看穿但不揭穿) 或 混沌真解(打破天道)

暗线2: 混沌碎片线
  秘境随机获取碎片(5%) → 轮回殿遗址(10%) → 混沌裂隙(必得) → 收集7块
  → 虚无道人现身 → 混沌灵根解锁 → 混沌真解结局

暗线3: 妖族和平线
  炼气救白狐 → 金丹白狐报恩(道侣) → 元婴妖族冲突 → 化神九尾天狐
  → 揭露妖族曾是苍茫界主宰 → 太古浩劫真相 → 人妖和解结局(红尘兵解的变体)

暗线4: 幽冥阁危机线
  金丹禁术诱惑 → 元婴亡灵袭击 → 化神复活仪式
  → 阻止/参与复活太古大能 → 影响8个结局中的3个
```

### 12.2 太古浩劫真相（完整版）

仅在天道线+混沌碎片线全部完成后揭示：

> 万年前，苍茫界没有天道法则。修士可以无限制修炼，不需要渡天劫。那个时代被称为"太古"，修士的实力远超当今。
>
> 但太古修士的过度修炼导致苍茫界灵气枯竭，世界濒临崩溃。上界仙庭为了保护"灵气供应链"（上界需要下界灵气供养），发动了**太古浩劫**——以仙力降下天道法则，限制下界修士的修炼上限。
>
> 天道法则的核心就是**天劫**：修为越高，天劫越强。天劫不是为了考验，而是为了**淘汰**——淘汰掉太多的高阶修士，防止他们耗尽灵气。
>
> 飞升也不是"登仙"，而是被仙庭"收编"——飞升者成为仙庭的打工人，为仙庭维护天道法则。拒绝飞升的修士会被天道慢慢消耗，最终轮回。
>
> 唯一打破这个循环的方法是**混沌之力**——混沌是三千世界之外的原始力量，天道法则无法约束它。收集7块混沌碎片，可以凝聚混沌灵根，以混沌之力打破天道，不入仙庭，自成一道。
>
> 这就是"混沌真解"结局的真相。

### 12.3 各结局与世界暗线的对应

| 结局 | 对应暗线 | 揭示的真相 |
|------|----------|-----------|
| 正道飞升 | 无(常规结局) | 无——玩家不知道真相，顺利"登仙"(实为被收编) |
| 魔道飞升 | 无(常规结局) | 无——玩家以力破天劫，但仍然被仙庭收编 |
| 红尘兵解 | 妖族和平线(变体) | 部分——玩家选择不飞升，留在下界与道侣相伴 |
| 因果归一 | 天道阴谋线(部分) | 知道飞升是骗局，但选择不揭穿，以"无因果"之身超脱 |
| 天道傀儡 | 天道阴谋线(反面) | 顺从天道，成为天道的维护者——悲剧结局 |
| 永堕轮回 | 无(失败结局) | 无——渡劫失败，因果缠身，继续轮回 |
| 混沌真解 | 天道+混沌全线 | 全部真相——打破天道，不入仙庭，自成一道 |
| 逆天成圣 | 天道阴谋线(暴力版) | 知道真相后选择以力证道，击败天道化身——但代价是苍茫界灵气大减 |

1. **语气**：半文半白，修仙小说风格。避免现代词汇
2. **人称**：第二人称"你"（与王权一致）
3. **长度**：标题≤10字，描述50-100字，选项文本≤15字
