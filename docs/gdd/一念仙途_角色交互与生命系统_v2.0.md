## 一、点击角色交互系统

### 1.1 设计理念

**不是"弹出对话框"，是"进入这个人的世界"**。太吾绘卷的人物界面之所以让人沉浸，是因为你看到的不是一个数据面板，而是一个"人"——他的处境、他的关系、他的心情、他的秘密，全在一个界面上。

本游戏做不到太吾那么复杂的社会模拟，但可以做到：**每次点击一个角色，你都获得一次"对话"体验，而不是"查资料"体验。**

### 1.2 人物面板结构

当玩家在游戏中点击一个可交互角色时，弹出**人物面板**，分五个板块：

```
┌─────────────────────────────────────────────┐
│  [立绘]         白刃真人                     │
│  半身像         ～～青云剑宗掌门～～           │
│                 化神巅峰 · 剑修·剑意流          │
│                 与你关系: 师尊(敬重)            │
├─────────────────────────────────────────────┤
│  今日心境: 「忧心忡忡」                        │
│  "这个弟子天赋不错，但心性……还得再看。"         │
│                                              │
│  [闲聊]  [请教]  [赠礼]  [论道]  [告辞]        │
├─────────────────────────────────────────────┤
│  ★ 与你互动记录                               │
│  炼气期·拜师时: 他说你"剑骨尚可，剑心未成"       │
│  筑基期·指点时: 他传了你一式"破云剑"            │
│  金丹期·上次: 他看了你的剑一眼，什么都没说走了    │
├─────────────────────────────────────────────┤
│  ★ 你知道的关于他的事                          │

│  - 最近他眉心皱得比平时多——肯定有心事            │
│  (灰色标注"尚未知晓"的条目表示你需要探索发现)     │
└─────────────────────────────────────────────┘
```

### 1.3 五个交互按钮

每个按钮不是一个简单的"好感+1"，而是一次**有上下文的对话**：

| 按钮 | 功能 | 行为 | 次数限制 | 好感影响 |
|------|------|------|----------|----------|
| **[闲聊]** | 从该NPC的"闲聊话题池"随机抽取1个话题，展开2-3轮对话 | 弹出对话文本，玩家可选回应 | 每境界3次 | ±3-5 |
| **[请教]** | 针对该NPC的专业领域请教 | 根据功法/境界解锁专属指点 | 每境界1次 | +5 |
| **[赠礼]** | 赠予物品，NPC根据性格和偏好反应 | 赠礼界面→选择物品→反应 | 无限但有冷却(3轮) | ±5-15 |
| **[论道]** | 与该NPC进行道法辩论(仅限同境界或相近) | 进入论道小游戏/对话链 | 每境界1次 | ±10 |
| **[告辞]** | 关闭面板 | — | — | — |

### 1.4 NPC记忆系统

每个NPC记住你对他做过的事——不是全局flag，是储存在NPC个人记忆里的：

```javascript

```

## 二、三层灵魂模型

### 2.1 核心理念

一个人物的"灵魂"不是静态性格数值，而是**三个动态层**：

```
第一层: 情绪 (每轮变化)  ← 表层的，能直接看到/感知的
第二层: 心境 (每天/每事件变化) ← 中层的，影响行为和对话倾向
第三层: 秘密 (不变或极慢变化) ← 最深的，决定终极抉择
```

### 2.2 第一层：情绪系统

每个NPC每个时段有一个**当前情绪**，影响对话语气和可选行为：

| 情绪 | 触发条件 | 对话影响 | 赠礼接受度 |
|------|----------|----------|-----------|
| **平静** | 无事发生时的默认状态 | 正常对话 | 正常 |
| **欣喜** | 修为突破/收到喜欢的礼物/久别重逢 | 话语增多，可能透露秘密 | +30% |
| **忧心** | 宗门压力/弟子出事/天劫临近 | 话语简短，频繁叹气 | -20% |
| **愤怒** | 被背叛/宗门受辱/妖族道侣事发 | 可能拒绝对话，或直接发火 | -50%(除非送安抚类物品) |
| **哀伤** | 道侣死亡/同门陨落/重要之人飞升 | 话少，语气低沉，偶尔停顿 | -10%(除非送纪念品) |
| **焦虑** | 天劫将至/大事将临/谜团未解 | 话多但是碎片化，有自言自语 | 正常 |
| **兴奋** | 发现上古遗迹/天道线索/稀有功法 | 话多，主动分享信息 | +50% |

**情绪切换规则**：

```
情绪不是随机的——由事件驱动:
  收到坏消息 → 忧心/哀伤
  被玩家帮助 → 欣喜
  被玩家背叛 → 愤怒
  长时间没事件 → 回归"平静"

情绪持续时间:
  平静: 持续到下一事件
  欣喜/忧心/愤怒/哀伤: 3-5轮后慢慢消退
  焦虑: 由特定事件驱动，事件解决后消退
```

### 2.3 第二层：心境系统

心境比情绪更深一层——它是角色的"心理状态基线"，影响情绪反应的幅度和方向：

| 心境 | 描述 | 对话整体调性 | 对情绪的影响 |
|------|------|-------------|-------------|
| **通明** | 心无挂碍，洞悉一切 | 言语精炼，一针见血 | 情绪波动减小50% |
| **执念** | 心中有放不下的事 | 反复提及某个话题 | 相关事件的情绪波动×2 |
| **迷茫** | 对前路失去方向 | 说话犹豫，常反问自己 | 容易受玩家影响 |
| **释然** | 放下执念后的通透 | 言语温和，看淡得失 | 情绪波动减小30%，但积极情绪增多 |
| **阴沉** | 心里有不可告人的计划 | 话里有话，欲言又止 | 愤怒+50%，欣喜-50% |

**心境触发事件示例**：

| 心境 | 触发条件 |
|------|----------|
| 通明 | 道心≥90 + 天道线深入 + 没道侣羁绊 |
| 执念 | 有未复仇的对象 / 有未完成的追求 / 道侣羁绊Lv4+但面临分离 |
| 迷茫 | 天道真相揭露后 / 正魔大战后失去太多 / 道侣背叛 |
| 释然 | 执念达成后 / 时间冲刷 / 玩家帮助其放下 |
| 阴沉 | 暗中计划进行中 / 恶因≥60 / 魔道线深入 |

### 2.4 第三层：秘密系统

每个NPC有1-3个**秘密**，按等级分级——这些秘密决定了角色在关键抉择中的真正立场：

| 秘密等级 | 特征 | 获取方式 | 对结局的影响 |
|----------|------|----------|-------------|
| **浅层秘密(Lv1)** | 日常生活细节、个人喜好 | 闲聊3次以上或赠对礼 | 解锁赠礼偏好，不影响结局 |
| **深层秘密(Lv2)** | 过去经历、内心矛盾、与其他NPC的恩怨 | 羁绊≥Lv3 或 特殊事件触发 | 可能影响支线走向 |
| **核心秘密(Lv3)** | 最深的真相——与天道/太古浩劫/某个关键抉择相关 | 非常特殊的事件链，一般只有化神期+羁绊极高+特定flag | 直接影响结局判定 |

**核心NPC秘密一览**：

| NPC | Lv1秘密 | Lv2秘密 | Lv3秘密 |
|-----|---------|---------|---------|
| **白刃真人** | 喜欢喝东海醉仙酿 | 师弟血煞老祖是他一生之痛 | 剑冢仙剑是上界监视器，他一直在找毁掉仙剑的方法 |
| **玄机真人** | 每天子时在万卷楼读《天道书》 | 他知道飞升有问题但不敢说出来 | 万卷楼《天道书》最后一页是空白——那是天道删掉的 |
| **药圣** | 禁药堂是他亲手封的 | 前谷主研究过不死丹，以活人为容器 | 不死丹配方在他手里，他每天夜里都在纠结该不该销毁 |
| **天机老人** | 天机盘只有3/7碎片——4块在混沌虚空 | 他是唯一知道完整天道真相的正道修士 | 他不是沉默，是在等——等一个道心够强、能承受真相的人 |
| **九尾溯月** | 三千年前差点飞升，在最后一刻回头 | 太古浩劫的亲眼见证者 | 混沌之力是唯一能打破天道的东西，她一直在收集 |
| **血煞老祖** | 离开青云剑宗不是因为叛变——是发现了仙剑的秘密 | 他杀了剑祖留下的最后一个剑灵 | 他是白刃真人的师弟，两人都在用不同方式对抗天道 |
| **幽冥阁主** | 曾是灵符宗最优秀的天才 | 偷走的血符术能复活太古大能——但他不确定该复活谁 | 他的研究其实是为了对抗天道——只是方法极端到没人理解 |
| **虚无道人** | 是太古浩劫前就已经存在的人 | 修为超越了化神但不飞升——因为他知道飞升是死路 | 混沌教的创始人，他的目的是集齐混沌之力、杀死天道 |

**秘密如何在游戏中体现**：

- 点击角色面板时，"你知道的关于他的事"会显示已解锁的秘密
- 闲聊和论道中，如果羁绊足够高，角色可能"说漏嘴"透露Lv2秘密
- Lv3秘密只能在特定事件链中揭露——比如天机老人在化神期才主动联系
- 秘密解锁后，会永久记录在"江湖录"（游戏内置图鉴）中

### 3.1 设计理念

角色不应该只跟玩家有关系——他们之间的关系才是让世界"活"起来的关键。**秦师兄暗恋林师妹但林师妹喜欢魔教少主，这种八卦才是江湖。**

### 3.3 NPC-NPC关系如何影响游戏

这些关系不是摆设——它们在游戏中直接产生事件卡：

| 关系机制 | 触发事件示例 |
|----------|-------------|
| 两个敌对的NPC同时在场（比如宗门大比） | "你看到白刃真人和血煞老祖隔空对视，空气都凝固了。" → 玩家选站队 |
| NPC请求你处理他与另一个NPC的矛盾 | "慕青岚私自告诉你，铁柔最近在淬体时用了禁术，她不知道该不该举报。" → 保密/上报 |
| NPC因为你与另一个NPC的关系而改变对你的态度 | "你与殷血结交的事传到剑灵儿耳中，她在练剑时比平时狠了三成。" |
| NPC之间的秘密关系被揭开 | "你在万毒门的地窖里发现了一本交易记录——上面有药圣的签名。" |

### 3.4 NPC对玩家的"第三方认知"

NPC不仅看你怎么对他，也看你**怎么对别人**：

```
场景: 你在剑灵儿面前提到殷血

if (你与殷血关系好) {
  剑灵儿(好感≥60): "那个魔修？你怎么会……算了，我不问了。"
  // 好感-5，信任-10，但没有爆发
```

## 四、角色日常行为与日程系统

### 4.1 设计理念

让角色**不在你的屏幕上也"活着"**。当你在西域坊市购物时，剑灵儿在剑冢练剑，白落霜在南疆采药，殷血在血煞绿洲杀人——他们都有自己的"生活"。

### 4.2 日程系统

每个NPC每天有一个**时辰安排表**（游戏里不显示具体时间，但用"轮"来计算）：

| 时辰 | 白刃真人 | 白落霜 | 殷血 |
|------|----------|--------|------|
| 子时(深夜) | 剑冢练剑 | 南疆修炼 | 血祭修行 |
| 寅时(凌晨) | 剑冢练剑 | 采药(南疆) | 血祭修行 |
| 辰时(早晨) | 宗门议事 | 采药(南疆) | 练剑 |
| 午时(中午) | 教导弟子 | 白狐部议事 | 战斗/杀人 |
| 申时(下午) | 闭关 | 幻术修炼 | 战斗/杀人 |
| 戌时(傍晚) | 宗门巡查 | 发呆(看夕阳) | 血煞绿洲喝酒 |

### 4.3 NPC位置系统

NPC不是固定站在某个地方的——他们有**当前所在位置**，根据日程移动：

```javascript
// NPC位置追踪
npcLocation: {
  "bai_ren": { current: "青云剑宗·剑冢", lastMoved: 120 },
  "bai_luoxuan": { current: "南疆·白狐部", lastMoved: 115 },
  "yin_xue": { current: "西域·血煞绿洲", lastMoved: 118 }
}
```

**位置对游戏的影响**：

| 场景 | 影响 |
|------|------|
| NPC当前不在师门 | 点击他时提示"某某某正在XX地，是否需要传讯？"（消耗灵石或等待） |
| NPC在同一地点 | 互动效果提升，可触发特殊对话（"没想到在这遇到你"） |
| NPC在危险地点（秘境/战场） | 可能出现"某某某遇险"事件卡 |
| 两个NPC意外在同一地点 | 触发他们之间的关系事件 |

### 4.4 NPC自主行为

即使玩家不互动，NPC也会自主做出决策：

| 行为 | 概率 | 效果 |
|------|------|------|
| 修为提升 | 5%/轮 | NPC修为缓慢增长 |
| 独自探索 | 2%/轮 | NPC可能发现秘境/宝物，也可能受伤 |
| NPC-NPC互动 | 3%/轮 | 两个在相近位置的NPC可能互动，产生新的事件 |
| 心境变化 | 事件驱动 | NPC经历事件后心境可能改变 |

## 五、势力内政与暗流系统

### 5.1 设计理念

正道六宗和魔道三宗一阁不只是标签——它们内部有派系斗争、权力更迭、暗流涌动。

### 5.2 青云剑宗内政

**派系**：

| 派系 | 首领 | 立场 | 对你(剑修弟子)的态度 |
|------|------|------|---------------------|
| **剑意派** | 白刃真人 | 剑意至上，不重术法 | 严苛但公正 |
| **古剑派** | 铁剑翁 | 崇尚古法，反对新剑道 | 轻视年轻人，觉得你根基不实 |
| **革新派** | 惊鸿道人(元婴) | 主张融合法修术法入剑道 | 欣赏创新，但被剑意派排斥 |

**暗流**：
- 古剑派与革新派每三年一次的"论剑大会"明争暗斗
- 如果你与天枢道院的玄机真人走近，古剑派会认为你"叛宗"
- 革新派暗中招募弟子进行"剑法双修"实验，白刃真人睁一只眼闭一只眼

### 5.3 天枢道院内政

**派系**：

| 派系 | 首领 | 立场 | 对你(法修弟子)的态度 |
|------|------|------|---------------------|
| **五行流** | 玄机真人 | 五行平衡，全面发展 | 温和指导 |
| **雷法流** | 惊雷子 | 主攻雷法，追求极致破坏 | 嫌你太慢 |
| **万卷流** | 慕青岚 | 研究古籍，追求理论 | 书呆子式友善 |

**暗流**：
- 慕青岚私下发现了《天道书》的空页秘密，在犹豫要不要告诉玄机
- 惊雷子与青云剑宗的革新派有私下交流——"融合雷法与剑道"

### 5.4 天机阁内政

天机阁规模最小，派系不如其他宗门明显，但有一个核心裂痕：

- 天机老人主张"观察天道，等待时机"
- 一批年轻阵修主张"主动对抗天道，无论代价"
- 两派在金丹→元婴阶段可能分裂——届时玩家必须选边

### 5.5 势力暗流事件

这些派系斗争不是背景板，而是**直接生成事件卡**的：

| 事件 | 触发条件 | 玩家选择 |
|------|----------|----------|
| "论剑大会"请柬 | 金丹期+剑修 | 支持剑意派 / 支持古剑派 / 支持革新派 → 影响你在宗门的声望和后续事件 |
| 惊雷子私下邀请 | 法修+金丹期 | 接受秘密会面(雷法BUFF) / 上报玄机真人(善因+) / 拒绝(两边不讨好) |
| 禁药堂秘密泄露 | 丹修+元婴期 | 销毁配方(善因+) / 保留但不上报(中立) / 自己使用(恶因+) |
| 天机阁年轻派请愿 | 阵修+金丹期 | 支持请愿 / 劝他们耐心 / 告密天机老人 |

### 7.5 道侣事件调度算法

```
每轮开始时检查：

Step 1: 是否有待触发的危机/情劫事件(flag驱动)?
  YES → 强制触发
  NO ↓

Step 2: 距离上次道侣事件已过N轮?
  N ≥ 阈值 → 进入Step 3
  N < 阈值 → 不出事件

Step 3: 计算触发概率
  基础概率 = 15%
  好感修正 = 好感度/100 × 10%（好感越高概率越高）
  羁绊修正 = 羁绊等级 × 3%
  多道侣惩罚 = (道侣数-1) × (-5%) （道侣多了，单个道侣事件概率降低）
  
  最终概率 = min(基础+修正, 35%)

Step 4: 从匹配的事件池中随机选取
  优先: 好感度匹配（好感低不出高好感事件）
  其次: 剧情阶段匹配（还没到元婴期不出元婴事件）
  最后: 随机抽取
```

## 八、物品赠予与好感系统

### 8.1 赠予机制

玩家可以在人物面板选择[赠礼]，从背包中选择物品送给NPC：

```javascript
// 赠予效果计算
赠予好感变化 = 基础波动 × 偏好修正 × 关系修正 × 性格修正 × 时机修正

其中:
  基础波动 = 根据物品价值（1-20）
  偏好修正 = 2.0(挚爱) / 1.5(喜欢) / 1.0(普通) / 0.5(不喜欢) / 0.1(厌恶)
  关系修正 = 1.0 + 好感度/200 （关系越好，送什么都香）
  性格修正 = 根据NPC的"傲"值:
    傲≥80: ×0.7（不容易被收买）
    情≥80: ×1.3（重情的人容易被感动）
  时机修正: 
    心境=欣喜: ×1.3
    心境=愤怒: ×0.5
    心境=哀伤+送纪念品: ×2.0
```

## 九、情报网络系统

### 9.1 设计理念

NPC是信息的载体。不同NPC知道不同的秘密、传言、情报。玩家通过与NPC互动来获取这些信息——这就是"江湖消息"的来源。

### 9.2 情报类型

| 情报类型 | 来源 | 内容 | 稀有度 |
|----------|------|------|--------|
| **宗门八卦** | 师门NPC闲聊 | 谁和谁有矛盾、谁要突破了、谁可能要叛逃 | 常见 |
| **江湖传言** | 散修、商人 | 某秘境即将开启、某魔修最近在附近活动 | 常见 |
| **势力暗流** | 中层以上NPC | 门派内部的派系斗争、即将发生的大事 | 少见 |
| **天道线索** | 天机阁、九尾、虚无道人 | 天道的真相碎片 | 稀有 |
| **人物秘密** | 本人(羁绊高时透露)或知情NPC | 某个NPC不为人知的过去 | 稀有 |
| **太古秘闻** | 九尾溯月、虚无道人 | 太古浩劫的细节 | 极稀有 |

## 十一、与游戏工作流对接指南

### 11.1 数据结构对接

所有新增系统只需在`game.js`中新增以下数据结构：

```javascript
// === 新增到 GameState ===
this.npcMemories = {};        // NPC记忆系统
this.npcEmotions = {};        // NPC当前情绪
this.npcMindsets = {};        // NPC心境
this.npcSecrets = {};         // 已解锁的NPC秘密
this.npcLocations = {};       // NPC当前位置
this.unlockedGossip = [];     // 已解锁的情报
this.companionEvents_history = []; // 道侣事件历史
```

### 11.2 HTML游戏版接入步骤

1. **在`game.js`中新增NPC记忆和情绪初始化**（开局时）
2. **在`ui.js`中新增人物面板UI**（点击NPC时弹出）
3. **在`cards.js`中新增道侣事件卡**（使用`type: "COMPANION"`标记）
4. **新增`npc.js`**：管理所有NPC的日程、情绪、台词库
5. **在`CardPool.draw()`中新增道侣事件优先出牌逻辑**

### 11.3 最小可行接入（MVP）

如果想让"角色活起来"最快见效，优先接入：

1. **人物面板**（点击角色→弹窗显示心境+台词+互动按钮）— 这是"太吾感"的核心
2. **核心NPC台词库的前10句**（覆盖最常见场景）
3. **道侣事件的TOP 5**（日常陪伴类）
4. **灵魂三层的前两层**（情绪+心境——秘密可以后面补）

这四项接入后，玩家点击任何一个核心角色，都会有"这个人是活的"的感觉。
