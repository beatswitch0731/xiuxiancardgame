## 一、道侣系统总则

### 1.1 设计理念

道侣不是"一个Buff"，而是一个**有独立意志、有自己的性格和修为追求、会与你产生化学反应的角色**。

| 设计原则 | 说明 |
|----------|------|
| **道侣有灵魂** | 每个道侣有独立的性格五维、修为路径、情感需求和人生目标 |
| **性格决定互动** | 不是随机出"道侣事件"，而是根据两个角色的性格匹配度动态生成 |
| **养成有深度** | 道侣的修为可以独立培养，甚至可以比你更强 |
| **关系有风险** | 道侣可能背叛、可能死去、可能出现情劫——修仙不是谈恋爱，是修心 |
| **多道侣有代价** | 开后宫不是福利，是麻烦——争风吃醋、资源分配、时间管理 |

### 1.2 道侣在游戏中的角色

| 角色维度 | 说明 |
|----------|------|
| **被动增益** | 提供属性加成、卡牌权重变更、资源获取 |
| **主动事件** | 解锁专属道侣事件卡（每境界2-3张） |
| **因果联动** | 道侣的安危/好感直接影响因果种子和天劫难度 |
| **结局影响** | 有道侣→红尘兵解结局可触发；妖族道侣→正魔线深化 |
| **叙事深度** | 道侣有自己的故事线，会跨境界成长，不是一次性NPC |

### 1.3 道侣槽位与限制

| 规则 | 说明 |
|------|------|
| **道侣槽位** | 最多3个（初始1个，金丹解锁第2个，化神解锁第3个） |
| **未了情缘占位** | 已分手/死亡的道侣仍占用槽位（心结未解），需通过特定事件化解 |
| **多情惩罚** | 2个道侣时，每10轮触发1次"争风吃醋"事件；3个道侣时每5轮1次 |
| **太上忘情** | 道心≥90时，所有道侣自动离开（道不同） |
| **跨世保留** | 转世后道侣关系清零，但前世道侣的因果种子以"宿命卡"形式在新一世出现 |

## 二、性格引擎 — 五维性格模型

### 2.1 核心设计

每个人物（道侣、道友、敌人、NPC）都有**五个性格维度**，每个维度0-100。这个模型决定了：
- 这个人会说什么话
- 这个人对你的行为会怎么反应
- 不同的道侣组合会不会"性格不合"
- 道侣的修炼方式和效率

### 2.2 五维性格定义

| 维度 | 英文标签 | 低分(0-30) | 中分(31-70) | 高分(71-100) | 对修炼的影响 |
|------|----------|-----------|-------------|--------------|-------------|
| **仁/戾** | Benevolence | 冷酷无情，视人命为草芥 | 有底线的现实主义者 | 慈悲为怀，舍己为人 | 善因获取+/-、正道好感 |
| **傲/谦** | Pride | 目中无人，看不起弱者 | 自尊自爱，不卑不亢 | 虚怀若谷，见贤思齐 | 道心稳定性、拒绝帮助概率 |
| **执/达** | Persistence | 执念深重，走火入魔风险 | 有目标但不钻牛角尖 | 看淡得失，随遇而安 | 突破成功率、道心波动 |
| **情/冷** | Warmth | 多情重义，容易受伤 | 理性与感性平衡 | 冷漠疏离，不为情困 | 道侣好感度增长速度、情劫风险 |
| **勇/慎** | Courage | 莽撞冒进，不计后果 | 该出手时就出手 | 深思熟虑，谋定后动 | 战斗气血消耗、险境规避概率 |

### 2.3 性格维度与六维属性的映射

性格不仅影响对话，还直接关联游戏数值：

| 性格维度 | 对属性的影响 | 对卡牌的影响 |
|----------|-------------|-------------|
| 仁(高) | 每轮善因+0.5、道心+0.3 | 善因卡权重+20% |
| 戾(低仁) | 每轮恶因+0.5 | 战斗/杀伐卡权重+20% |
| 傲(高) | 道心-0.2/轮（易不满） | 拒绝帮助的卡牌选项权重+ |
| 谦(高) | 道心+0.3/轮、福缘+0.2 | 获得指点卡概率+15% |
| 执(高) | 突破成功率+15%、道心波动×1.5 | 瓶颈卡出现频率+ |
| 达(高) | 道心恢复速度+50%、修为增长-20% | 消极事件的效果减半 |
| 情(高) | 道侣好感增长+50%、情劫伤害×2 | 红尘线卡牌权重+30% |
| 冷(低情) | 道侣好感增长-30%、情劫免疫 | 红尘线卡牌权重-50% |
| 勇(高) | 战斗气血消耗-20%、险境触发+1 | 战斗卡收益+30%、风险+30% |
| 慎(高) | 险境触发-1、战斗气血消耗+20% | 战斗卡出现概率-20% |

### 2.4 性格判定口诀（设计者用）

判断一个角色的性格五维，问他/她五个问题：

| 维度 | 判定问题 | 
|------|----------|
| 仁/戾 | "路边倒了一个重伤的陌生人，你？" 救人(高仁) … 补刀(高戾) |
| 傲/谦 | "有人说你的功法有缺陷，你？" 不屑一顾(高傲) … 虚心请教(高谦) |
| 执/达 | "突破失败三次了，你？" 不惜代价再来(高执) … 算了，时机未到(高达) |
| 情/冷 | "道侣要离开了，你？" 舍命挽留(高情) … 祝你好运(高冷) |
| 勇/慎 | "前方有化神妖兽的气息，你？" 冲上去(高勇) … 绕路走(高慎) |

## 三、道侣养成体系 — 参数与公式

### 3.1 道侣核心参数

每个道侣有以下数据字段：

```javascript
{
  companionId: "white_fox_bailuoxuan",
  name: "白落霜",
  
  // === 基础信息 ===
  species: "妖族",           // 种族: 人族/妖族/混血/灵体
  faction: "白狐部",        // 所属势力
  realm: "foundation",      // 当前修为境界
  path: null,               // 修炼功法（可学习）
  
  // === 五维性格 ===
  personality: {
    benevolence: 75,  // 仁
    pride: 35,         // 傲
    persistence: 60,   // 执
    warmth: 90,        // 情
    courage: 45         // 勇
  },
  
  // === 关系状态 ===
  affection: 50,       // 好感度 0-100
  trust: 50,           // 信任度 0-100（独立于好感）
  bondLevel: 1,        // 羁绊等级 1-5
  
  // === 修为参数 ===
  cultivation: 30,     // 道侣修为值 0-100（满了可突破）
  cultivationSpeed: 1.2,  // 修炼速度倍率
  breakthroughChance: 0.6, // 突破成功率（受性格和关系影响）
  
  // === 道侣专属能力 ===
  passiveEffects: [     // 被动增益
    { type: "fortune", value: 10 },
    { type: "cardWeight", path: "sword", value: 0.05 }
  ],
  exclusiveCards: [     // 专属事件卡ID列表
    "companion_whiteFox_1", 
    "companion_whiteFox_2"
  ],
  specialAbility: {     // 特殊能力（每个道侣独一无二）
    name: "狐息感应",
    description: "可预知下1张卡的类型",
    cooldown: 5,        // 冷却轮数
    energyCost: 1       // 元神能量消耗(元婴以上可用)
  },
  
  // === 状态标记 ===
  alive: true,
  injured: false,
  inSeclusion: false,     // 闭关中（不参与事件）
  hasHeartDemon: false,   // 有心魔
  deathTriggers: []       // 死亡时触发的因果种子
}
```

### 3.2 核心公式

#### 公式1: 好感度变化

```
Δaffection = baseAffectionGain × personalityMatch × eventMultiplier × realmModifier

其中:
  baseAffectionGain = 根据互动类型的基准值（见面+2、帮助+8、赠送礼物+5~15、疏远-10）
  
  personalityMatch = 你和道侣的五维性格余弦相似度
    similarity = cos(你的五维向量, 道侣的五维向量)
    personalityMatch = 0.5 + similarity × 0.5
    // 范围: 0~1, 性格越像, 好感涨得越快
  
  eventMultiplier = 根据事件类型:
    日常互动 ×1.0
    危机救援 ×2.0
    赠送心爱之物 ×1.5
    争吵 ×(-1.5)
    背叛 ×(-3.0)
  
  realmModifier = 1 + (你的境界等级 - 道侣境界等级) × 0.1
    // 你比道侣强, 道侣更崇拜你, 好感+快; 你比道侣弱, 道侣可能看不起你
```

#### 公式2: 信任度变化

信任度比好感度更难获得，也更重要。好感度高但信任度低的道侣可能在关键时刻背叛。

```
Δtrust = baseTrustGain × honestyFactor × eventType

其中:
  honestyFactor = 你的"仁"值 / 100（你越仁慈, 道侣越信任你）
  
  eventType:
    坦诚相告 +5~10 信任
    隐瞒事实 -10~20 信任
    舍命相救 +30 信任（且好感+15）
    出卖道侣 -50 信任（且好感-30, 直接触发道侣离开事件）
```

#### 公式3: 羁绊等级升级条件

```
bondLevel升级条件:
  Lv1→Lv2: affection ≥ 60 且 trust ≥ 50 且 陪伴轮数 ≥ 20
  Lv2→Lv3: affection ≥ 75 且 trust ≥ 70 且 共同战斗次数 ≥ 3
  Lv3→Lv4: affection ≥ 85 且 trust ≥ 85 且 经历一次"道侣危机"事件（如正魔线冲突）
  Lv4→Lv5: affection ≥ 95 且 trust ≥ 95 且 共同渡劫1次

羁绊等级效果:
  Lv1: 解锁道侣被动效果
  Lv2: 专属卡牌+1，道侣可参与秘境探索
  Lv3: 道侣修炼速度+30%，解锁特殊能力
  Lv4: 道侣可代替你承受一次致命伤害（一次性）
  Lv5: 道侣成为"天命道侣"，转世后可保留羁绊种子
```

#### 公式4: 道侣修为增长

道侣有自己的修炼进度，不受玩家直接控制，但可以间接影响。

```
道侣每轮修为增长 = cultivationSpeed × realmBaseRate × resourceBonus × bondBonus

其中:
  realmBaseRate: 根据道侣当前境界的基础增长
    炼气: 0.3/轮  筑基: 0.25/轮  金丹: 0.2/轮  元婴: 0.15/轮  化神: 0.1/轮
  
  resourceBonus: 玩家给道侣分配资源
    不分配: ×1.0
    分配灵石: ×1.3（每轮消耗5灵石）
    分配丹药: ×1.8（消耗1颗丹药，持续5轮）
    分配修炼洞府: ×2.0（消耗10灵石/轮）
  
  bondBonus: 羁绊加成
    Lv1: ×1.0  Lv2: ×1.1  Lv3: ×1.3  Lv4: ×1.5  Lv5: ×2.0
```

#### 公式5: 道侣突破成功率

```
道侣突破成功率 = baseRate × personalityMod × playerAssist × realmGapMod

其中:
  baseRate: 境界基础成功率
    炼气→筑基: 80%   筑基→金丹: 60%   金丹→元婴: 40%   元婴→化神: 25%
  
  personalityMod = (道侣的"执"值/100 + 道侣的"勇"值/200)
    // 执念深+勇气高=突破更猛, 但走火入魔风险也更大
  
  playerAssist: 玩家帮助
    不帮助: ×1.0
    提供破境丹: ×1.5
    亲自护法: ×1.3（消耗10轮不能做其他事）
    请师尊护法: ×1.4（消耗灵石和宗门贡献）
  
  realmGapMod: 境界差距修正
    玩家比道侣高1个境界: ×1.1
    玩家比道侣高2个境界: ×1.2
    玩家与道侣同境界: ×1.0
    道侣比玩家高: ×0.9（道侣不服，心理压力大）
```

#### 公式6: 多道侣冲突概率

```
每轮冲突触发概率 = baseConflictProb × personalityClash × bondJealousy

其中:
  baseConflictProb:
    2个道侣: 每10轮触发1次(10%)
    3个道侣: 每5轮触发1次(20%)
  
  personalityClash: 两个道侣之间的性格冲突度
    clash度 = 1 - cos(道侣A五维, 道侣B五维)
    // 性格差异越大, 冲突越多
    
  bondJealousy: 嫉妒系数
    = (与你羁绊最高的道侣的bondLevel - 与你羁绊最低的道侣的bondLevel) × 0.1
    // 羁绊差距越大, 低羁绊方越是嫉妒
```

| **五维性格** | 仁75、傲35、执60、情90、勇45 |
