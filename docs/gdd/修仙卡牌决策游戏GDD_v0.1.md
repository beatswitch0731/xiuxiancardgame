## 一、设计立柱 (Design Pillars)

游戏必须交付的4个非 negotiable 玩家体验。所有设计决策以此为标尺。

| 立柱 | 玩家体验 | 衡量标准 |
|------|----------|----------|
| **一念因果** | 每次滑动都有重量 — 炼气期的一个善念，金丹期化成报恩的妖兽 | 玩家能回忆起"导致后果的那次决策" |
| **万法归Build** | 功法选择有真实意义 — 剑修和丹修玩起来是两个游戏 | 不同功法Build的卡牌池≥60%不同 |
| **层层叠扣飞升路** | 境界提升 = 打开新世界 — 不只是数值增长，是规则变化 | 每个境界至少引入1个新机制 |
| **转世不空修** | 死亡不是清零 — 前世的因成为来世的缘 | 转世后玩家有"这次我知道该怎么选"的冲动 |

## 二、核心循环 (Core Loop)

### Moment-to-Moment (0-15秒)
- **Action**: 卡牌出现 → 阅读修仙情境 → 左滑(拒绝/不纳)/右滑(接受/纳取)
- **Feedback**: 四维属性数值即时波动 + 因果种子静默记录 + 音效/粒子反馈
- **Reward**: 修为推进 + 剧情推进 + 偶尔的功法/法宝/丹药获取

### Session Loop (10-20分钟)
- **Goal**: 在当前境界内维持四维平衡 → 积累修为 → 触发突破瓶颈
- **Tension**: 道心太低走火入魔 / 因果太重天劫难度飙升 / 修为归零陨落
- **Resolution**: 突破成功(进入新境界) 或 陨落(转世重修)

### Long-Term Loop (数小时-数周)
- **Progression**: 境界攀升(炼气→飞升) + 功法Build跨境界成长 + 剧情线解锁
- **Retention Hook**: 前世未解之谜 / 隐藏飞升结局 / 多功法Build体验 / 因果链全收集

## 三、境界系统 — 层层叠扣的世界观

这是修仙题材和王权玩法的核心融合点。**境界 = 游戏阶段 = 新规则层**。

### 境界阶梯

| 境界 | 卡牌主题 | 新机制引入 | 突破条件 | 突破方式 |
|------|----------|------------|----------|----------|
| **炼气** | 入门机缘、灵根觉醒、拜师、初遇妖兽 | 基础滑动决策 | 修为满 + 道心≥30 | 选功法(定Build方向) |
| **筑基** | 师门历练、功法修炼、初入红尘、筑基丹 | 功法专属卡牌池开启 | 修为满 + 因果≤50 | 筑基大典(连续3张关键决策) |
| **金丹** | 结丹、斗法、秘境探索、道侣机缘 | **因果种子首次发芽** + 法宝系统 | 修为满 + 道心≥50 | 渡心劫(内在Boss战) |
| **元婴** | 元神出窍、跨境追杀、势力争斗、旧因果爆发 | 元神分身(可同时处理2张卡) | 修为满 + 因果结算 | 渡天劫(外在Boss战) |
| **化神** | 窥天道、飞升前兆、界域真相、因果大爆发 | 天道选择(影响飞升结局) | 修为满 + 道心≥80 | 渡九重天劫(终极考验) |
| **渡劫→飞升** | 最终因果结算、飞升抉择 | 全因果链回放 | 渡劫成功 | 飞升(通关) / 兵解(转世) |

### 关键设计：境界不只是数值门槛

每个境界引入**新机制**，让玩家感觉"换了游戏"：

- **炼气→筑基**：从被动应对 → 主动选功法(Build确立)
- **筑基→金丹**：因果系统激活(之前的决策开始有后果了)
- **金丹→元婴**：元神分身(同时处理2张卡，策略复杂度翻倍)
- **元婴→化神**：天道选择(剧情分支，决定结局走向)
- **化神→飞升**：全因果结算(所有前世今生的因一次性收割)

### 突破瓶颈设计

突破不是自动的 — 需要满足条件 + 通过"瓶颈事件链"：

```
修为满 → 触发瓶颈事件链 → 连续3-5张关键决策卡 → 
  成功：突破，进入新境界
  失败：修为回落30%，或直接陨落(高境界)
```

瓶颈事件链的卡牌是**锁入式**的(类似王权的地牢) — 进入后不能退出，必须做完。

## 四、四维属性系统

替代王权的"宗教/人民/军队/金钱"。修仙化重构：

| 属性 | 含义 | 归零后果 | 爆满后果 | 设计意图 |
|------|------|----------|----------|----------|
| **修为** | 修炼进度/境界能量 | 陨落(转世) | 自动触发突破 | 主进度条，驱动游戏前进 |
| **道心** | 心性稳定/精神状态 | 走火入魔(强制疯狂决策3轮) | 心如止水(下3轮决策效果翻倍) | 内在风险控制，阻止无脑堆修为 |
| **因果** | 业力累积/善恶债 | 机缘断绝(好事件卡概率归零) | 天劫难度飙升/劫雷提前 | 长期债务，让玩家"不敢乱来" |
| **福缘** | 运势/气运 | 厄运缠身(坏事件卡概率翻倍) | 天降机缘(必出稀有卡) | 短期波动，增加RNG趣味性 |

### 与王权四维的关键区别

王权的四维是**对称的**(都是"不能太高不能太低")。修仙版引入**不对称设计**：

- **修为**：越高越好(只有爆满=突破，没有"太高"惩罚)
- **道心**：双向风险(太低走火入魔，太高"太上忘情"失去红尘羁绊=丢失道侣/师门线)
- **因果**：善恶双轨(不是简单的"越低越好"，善因和恶因有不同后果)
- **福缘**：纯波动条(随机性来源，玩家无法直接控制)

### 因果双轨设计

因果不是单数值，而是**善恶双轨**：

```
善因 ────────────── 恶因
-50    -25    0    +25    +50

善因高：渡劫时天劫难度降低，但可能有"恩将仇报"反转事件
恶因高：渡劫时天劫难度飙升，但魔道功法威力增强
平衡态：正常渡劫，无特殊加成/减成
```

这让"善恶选择"不是简单的道德题 — **恶人有恶人的玩法(魔修Build)**。

## 五、修炼路径系统 (功法Build)

这是突破王权"无长期Build"瓶颈的核心设计。

### 六大功法路径

| 功法 | 核心幻想 | 专属卡牌特征 | Build方向 | 天劫特色 |
|------|----------|--------------|-----------|----------|
| **剑修** | 一剑破万法 | 攻击性强、因果恶因增长快、道心消耗大 | 杀伐果断，以战养战 | 剑劫(万剑噬主) |
| **法修** | 五术万变 | 策略性强、多选项、需要预判 | 灵活应变，术法组合 | 五行劫(相生相克) |
| **体修** | 以身化道 | 被动增益多、修为增长慢但稳、抗揍 | 肉身成圣，硬扛一切 | 肉身劫(身碎重塑) |
| **丹修** | 炼丹辅修 | 资源转换强、可制造道具、辅修型 | 以丹入道，资源循环 | 丹毒劫(药力反噬) |
| **阵修** | 阵法控场 | 控制型、改变卡牌规则、延迟效果 | 以阵困敌，规则改写 | 阵法劫(阵眼崩塌) |
| **符修** | 符箓召唤 | 召唤型、一次性强力效果、资源消耗 | 符道通神，爆发控场 | 符劫(符力暴走) |

### 功法选择时机

在**炼气→筑基**突破时选择功法。选择后：
1. 专属功法卡牌加入卡池(权重高)
2. 通用卡牌权重降低
3. 解锁该功法的Build升级树

### 功法Build升级树

每个功法有3条升级分支，在金丹期"结丹"时选择：

```
剑修:
├── 剑意流(攻击向): 剑气→剑意→剑域→剑心
├── 剑体流(防御向): 剑骨→剑肤→剑脏→剑心
└── 剑魂流(召唤向): 剑灵→剑仆→剑阵→剑心
```

升级通过**重复使用同类卡牌**触发 — 做多了某类决策，该类卡牌升级，效果增强。

### 跨境界Build成长

功法Build不会因转世重修完全清零：
- **道基**：每次转世保留1个Build升级(玩家选择保留哪个)
- **道基共鸣**：如果连续多世选同一功法，解锁隐藏的"道基共鸣"加成
- **转修**：也可以转世后换功法，但道基加成重置

## 六、因果回溯系统 — 修仙版蝴蝶效应

这是本游戏**最大的创新点**，也是修仙题材和王权玩法的灵魂融合。

### 设计理念

修仙的核心哲学是**因果轮回**。王权的概率卡池是"伪因果"(其实没有真正的因果链)。本游戏做**真因果**：

### 机制规格

```
## Mechanic: 因果回溯系统

**Purpose**: 让每次决策都有跨境界的长期后果，解决王权"决策无长期影响"的瓶颈
**Player Fantasy**: "种什么因，得什么果" — 玩家感受到修仙世界的因果律

**Input**: 每次滑动决策
**Output**: 生成隐藏的"因果种子"，在N轮后发芽为事件卡

**因果种子结构**:
  - 来源决策ID
  - 善/恶标记
  - 涉及角色/势力
  - 发芽延迟轮数(境界相关: 炼气期5轮, 金丹期10轮, 元婴期15轮)
  - 发芽条件(需要达到某境界/遇到某角色)
  - 后果事件卡ID

**发芽流程**:
  1. 检查所有因果种子是否满足发芽条件
  2. 满足的种子转化为事件卡，加入卡池(高权重)
  3. 事件卡出现时，显示模糊预兆("似有旧识来访...")
  4. 玩家可能认出也可能不认出(取决于是否记得之前的决策)

**渡劫总结算**:
  - 所有未发芽的因果种子在渡劫时一次性结算
  - 善因总和 - 恶因总和 = 渡劫难度修正
  | 净善因 | 渡劫难度 |
  |--------|----------|
  | ≥30 | 天劫难度-50% |
  | 10~29 | 天劫难度-20% |
  | -10~9 | 正常 |
  | -30~-11 | 天劫难度+30% |
  | ≤-31 | 天劫难度+80% (魔修反而可能借此突破) |

**Edge Cases**:
  - 因果种子在转世后是否保留？→ 保留，以"宿命卡"形式出现
  - 同一角色的多个因果如何处理？→ 合并为复合事件(恩怨交织)
  - 因果种子太多怎么办？→ 渡劫前显示"因果预览"，让玩家知道有哪些未了

**Tuning Levers**:
  - 发芽延迟轮数 [PLACEHOLDER]
  - 因果权重(影响卡池概率) [PLACEHOLDER]
  - 善恶因对渡劫的影响系数 [PLACEHOLDER]
```

### 因果链示例

```
炼气期: 遇到受伤妖兽
  ├─ 右滑(救治) → 善因种子A(妖兽·善·发芽延迟15轮)
  └─ 左滑(杀取内丹) → 恶因种子B(妖兽·恶·发芽延迟10轮) + 修为+10

  ...15轮后，金丹期...

金丹期: 种子A发芽 → 事件卡"化形妖兽来报恩"
  ├─ 右滑(接纳) → 获得妖兽道侣(强力长期卡) + 善因+5
  └─ 左滑(拒绝) → 妖兽心碎离去 + 道心-10(红尘劫种)

  ...10轮后，元婴期...

元婴期: 种子B发芽(如果当初选了杀) → 事件卡"妖兽族群寻仇"
  ├─ 右滑(赔罪) → 损失法宝 + 恶因-10(化解)
  └─ 左滑(再杀) → 恶因+15 + 获得妖兽内丹 + 因果恶化
```

### 因果预兆系统

为了让玩家**感知到因果**而不是被随机打脸：

- 因果种子发芽前2轮，显示**模糊预兆**："你近日心神不宁，似有旧事将了..."
- 发芽时，如果玩家之前做过类似选择，事件卡会带**回溯标记**："此事似乎与你在炼气期的某个决定有关..."
- 渡劫前，显示**因果总览**：列出所有未了因果，让玩家做最后准备

## 七、转世重修系统 (Roguelike核心)

### 死亡条件

| 死亡方式 | 触发条件 | 频率预期 |
|----------|----------|----------|
| 修为归零 | 修为条见底 | 最常见(新手主要死法) |
| 道心崩溃 | 道心归零→走火入魔→3轮内未恢复 | 中期常见 |
| 天劫不渡 | 渡劫失败 | 高境界主要死法 |
| 因果反噬 | 恶因爆满→业火烧身 | 魔修Build风险 |

### 转世保留机制

| 保留项 | 说明 | 设计意图 |
|--------|------|----------|
| **前世记忆** | 解锁的剧情线永久可见 | 长期叙事进度 |
| **道基(1个)** | 玩家选择保留1个功法Build升级 | 跨世Build成长 |
| **灵根选择权** | 解锁的灵根类型可在转世时重新选择 | 策略灵活性 |
| **因果种子** | 前世未了因果 → 转世后的"宿命卡" | 因果连贯性 |

### 转世重置机制

| 重置项 | 说明 |
|--------|------|
| 修为 | 回到炼气期初始 |
| 道心/福缘 | 回到初始值 |
| 因果值 | 重置为0(但因果种子保留) |
| 当前功法Build | 重置(除了保留的1个道基) |
| 法宝/丹药 | 全部清空 |

### 宿命卡系统

前世未了的因果，转世后以"宿命卡"形式介入：

```
宿命卡特征:
  - 在新一世的特定境界强制出现(无法跳过)
  - 带有"前世记忆"标记，玩家能看到前世的因果
  - 选择会影响当前世的因果走向
  - 解决后宿命卡消失，因果链关闭

示例:
  前世你杀了一个散修。
  转世后，筑基期出现宿命卡:
  "一散修拦路，眼神似有恨意...你隐约记得，此人面容与前世所杀之人相似。"
    ├─ 右滑(认罪赔礼) → 恶因-10，损失资源，但化解宿命
    └─ 左滑(再杀) → 恶因+15，获得资源，但宿命加深(下一世还会出现，更凶)
```

## 八、故事线架构

### 横向故事线 (同一境界内并行)

| 故事线 | 主题 | 卡牌特征 | 跨境界延续 |
|--------|------|----------|------------|
| **师门线** | 师徒恩怨、同门争斗、门派兴衰 | 师门角色卡、门派事件 | 师门存亡影响后期资源 |
| **正魔线** | 正道vs魔道的选择 | 立场抉择卡、势力冲突 | 正魔倾向影响渡劫方式 |
| **红尘线** | 道侣、凡人羁绊、情劫 | 情感决策卡、道侣事件 | 道侣可跨境界成长，情劫是主要道心风险 |
| **天道线** | 探索世界真相、飞升秘密 | 稀有探索卡、上古遗迹 | 解锁隐藏飞升结局 |

### 纵向故事线 (跨境界的长线)

| 故事线 | 触发方式 | 跨越范围 |
|--------|----------|----------|
| **前世因果** | 转世后的宿命卡 | 跨越2-3世 |
| **天道阴谋** | 化神期天道选择 | 从元婴到飞升 |
| **界域战争** | 飞升后解锁(续作DLC?) | 下界→上界 |
| **混沌初开** | 隐藏线，需多世收集碎片 | 全游戏周期 |

### 故事线交织设计

故事线不是独立的 — 它们通过**因果系统**自然交织：

```
师门线决策(救同门) 
  → 善因种子(同门·善)
  → 金丹期发芽: 同门报恩，介绍你认识道侣候选
  → 红尘线开启
  → 道侣是妖族
  → 正魔线触发(正道不容人妖恋)
  → 正魔选择影响天道线
```

这种交织不是脚本预设的，而是**因果系统自然产生**的 — 这就是"层层叠扣"。

## 十四、核心机制增强 (Advanced Mechanics)

本部分是将《王权》系列高阶理论（空间探索、多维决策、概率袋显性化）与修仙体系深度融合的进阶玩法。

### 1. 空间维度引入：【秘境试炼】 (节点地图)
当玩家在游戏中抽到特定机缘卡（如：上古秘境开启）并右滑进入时，游戏暂时脱离无限抽卡模式，转入节点地图界面。
- **玩法呈现**：弹出一个类似《杀戮尖塔》的树状节点地图。玩家需要选择前进路线（例如：遭遇妖兽节点 -> 采药节点 -> 秘境守护兽）。
- **设计价值**：打破单一的左右滑动节奏，给玩家提供强烈的“主动探索感”和“阶段性目标感”。在秘境中，每次节点触发的是特殊的秘境专属卡池。

### 2. 决策维度突破：【多目标互动】 (多方向滑动)
在特定的复杂事件（如多方势力火拼、正邪交锋）中，打破二元选择的限制。
- **玩法呈现**：卡牌不仅可以左右滑动，还可以向上/向下拖拽，甚至拖向屏幕四周代表特定势力的人像上。
  - *左滑*：相助正道（得罪魔道，积累善因）
  - *右滑*：相助魔修（得罪正道，积累恶因，获重利）
  - *上滑*：坐山观虎斗，两败俱伤后夺宝（极度增加天道业力，苟道流/阵修流专属）
  - *下滑*：直接遁走（无事发生，保存实力）
- **设计价值**：极大地丰富了修仙那种“弱肉强食、见机行事”的尔虞我诈感，扩展了策略空间。

### 3. Bag系统显性化：【天机/气运盘】 (可视化的权重干预)
将《王权》底层隐性的概率抽卡系统（Bag System）包装成修仙概念里的“天机”。
- **玩法呈现**：UI 角落新增一个“天机盘”。当玩家修剑道时，天机盘亮起剑形符文，明确提示：“剑道机缘卡牌概率大幅提升”。当积累恶因时，天机盘被黑气缠绕，预警“仇家寻仇卡牌即将到来”。
- **进阶互动**：允许精通【阵修】或拥有特定法宝的玩家，主动花费寿元“拨动天机盘”，强行剔除卡池里的一张大凶之卡，或将某张机缘卡的权重拉满。这就把底层的数学机制变成了玩家可以主动把玩的策略系统。

### 4. 节奏极端化：【极速天劫 Boss 战】 (限时反应挑战)
传统的左右划卡没有时间限制，但修仙的“渡劫”需要生死一线的压迫感。
- **玩法呈现**：触发天劫时，脱离常规模式。天雷与心魔卡牌会以极快的速度砸来，每张卡只有 1.5 秒的反应时间。玩家必须根据雷劫属性（如五行神雷），迅速左滑（肉身硬抗）、右滑（法宝抵挡）或拖拽底部法阵。
- **因果联动**：如果之前的【因果】恶因太多，天雷速度会更快，且会出现真假难辨的心魔卡（滑错则道心大损）。
- **设计价值**：平时修仙是慢节奏的运筹帷幄（种因），渡劫时则是肾上腺素飙升的动作反应（得果），完美契合修仙小说中渡劫时九死一生的紧张感。

## 十五、底层基建与资源系统 (Core Infrastructure)

针对界面层玩法的底层支撑，定义以下核心数据结构与实体资源经济循环。

### 1. 卡牌数据结构定义 (Card Data Structure)
卡牌是游戏的核心驱动单元。每张卡牌在底层的 JSON 结构定义如下，这确保了功法判定、天机盘干预和因果播种在代码层面能够正确挂载：

```json
{
  "cardId": "event_qi_012",
  "cardType": "NORMAL", // 枚举: NORMAL(普通), KARMA_ECHO(因果), BOTTLENECK(瓶颈锁入), REALM_EXCLUSIVE(秘境), DESTINY(宿命), TRIBULATION(渡劫)
  "realmRequirement": "QI_CONDENSATION", // 境界限制
  "prerequisites": {
    "requiredTags": ["sect_member"], // 需具备的标签(如已拜师)
    "exclusiveBuild": "SWORD" // 仅限剑修触发(可选)
  },
  "baseWeight": 100, // 初始概率袋(Bag)权重
  "karmaTags": ["凶", "杀伐"], // 标签(用于天机盘剔除判定/法宝被动加成判定)
  "content": {
    "title": "拦截",
    "description": "一名黑衣人拦住去路，索要过路费。"
  },
  "decisions": {
    "LEFT_SWIPE": {
      "text": "拔剑硬闯",
      "statChanges": {"cultivation": 5, "dao": -5, "karmaGood": 0, "karmaBad": 5, "fortune": 0}, // 四维状态波动
      "resourceChanges": {"health": -30, "spiritStone": 0}, // 实体资源消耗
      "generatedKarmaSeeds": [ // 播种延时因果
        {"seedId": "black_suit_revenge", "delayTurns": 20, "type": "BAD"}
      ],
      "addedTags": ["enemy_blacksuit"] // 为后续事件打标签
    },
    "RIGHT_SWIPE": {
      "text": "破财消灾",
      "statChanges": {"cultivation": 0, "dao": 5, "karmaGood": 0, "karmaBad": -2, "fortune": 0},
      "resourceChanges": {"spiritStone": -50}
    }
  }
}
```

### 2. 可消耗资源系统 (Consumable Resources)
四维属性本质是“状态条（平衡度）”，不作为支付手段。游戏需引入以下具体的实体资源，以支撑经济循环与主动干预玩法：

| 资源类型 | 核心定位 | 获取途径 | 消耗途径 | 跨界/转世处理 |
|----------|----------|----------|----------|---------------|
| **灵石 (Spirit Stone)** | 基础经济货币 | 门派俸禄、战斗夺宝、秘境事件 | 贿赂、购买法宝/丹药、启动阵法选项 | 跨界保留，转世清零 |
| **寿元 (Lifespan)** | 倒计时与高级代价 | 突破境界上限翻倍、珍稀延寿丹 | 每划卡固定-1年、**发动禁术（如拨动天机盘剔除凶卡）**、重伤折寿 | 跨界保留，转世重置 |
| **丹药栏 (最大3格)** | 战术一次性消耗品 | 炼丹（丹修专属卡）、探索奖励、商人 | 战斗前/渡劫中主动拖拽使用 | 跨界保留，转世清零 |
| **法宝槽 (最大2格)** | 常驻被动装备 | Boss战掉落、上古秘境获取 | 无（穿戴即生效，如：持青锋剑时，所有战斗选项战损减半），可被更高级法宝替换，或在恶劣因果中损毁 | 跨界保留，转世可能作为遗泽 |

*注：通过将“寿元”定义为核心可消耗资源，天机盘的“逆天改命”功能有了极具修仙代入感的代价支撑，玩法彻底逻辑自洽。*
