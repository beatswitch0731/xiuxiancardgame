## 0. 设计总纲

### 0.1 核心哲学：修仙是要"争"的

修仙的本质只有一个字：**争**。

与天斗，与地斗，与人斗。资源要争，机缘要争，连天道本身也要争。这不
是一场修身养性的旅途——这是一场**你死我活的竞争**。

太善良的人争不了。善人让出机缘，善人退避纷争，善人不愿出手伤人——
于是他们永远积累不到足够的力量突破境界。天道看到这样的人，只会说：
"你不需要再修了，你已经够好了。"然后接走。

这不是飞升。这是**淘汰**。

```
                   修仙之路（争）
    ┌─────────────────────────────────────────┐
    │                                         │
    │   与天争机缘 · 与地争资源 · 与人争道途   │
    │                                         │
    │        ↑ 道心 = 你的"争心"              │
    │        │                                │
    │   太善 ←─●─→ 太恶                       │
    │   不争      疯争                         │
    │   被淘汰    被抹除                       │
    │   (羽化)    (天劫)                       │
    │                                         │
    │         修仙者活着的空间                  │
    │         只有中间这道缝隙                 │
    └─────────────────────────────────────────┘
```

**一句话**: 太善良的人没有仙的资质——因为修仙是要争的。太恶的人也没有——因为天道不会容忍一个疯子。你必须在善与恶之间杀出一道平衡。

### 0.2 三条死亡轴线

| 死亡方式 | 触发条件 | 哲学含义 |
|----------|---------|----------|
| **身死道消** | health ≤ 0 | 肉体承受不了修行的代价 |
| **羽化登仙** | karmaGood ≥ 100 | 不争之人不配有仙途 — 天道接引，实为淘汰 |
| **天劫临身** | karmaBad ≥ 100 | 争过头了 — 恶念积累到天道不容，抹除 |
| **走火入魔** | daoHeart ≤ 0 | 道心崩溃——失去自我意识 |
| **天诛地灭** | fortune ≤ 0 | 运气耗尽——天道抹除这个"错误" |
| **寿元耗尽** | lifespan ≤ 0 | 自然法则——时间到了 |

**设计意图**: 修仙是要争的。太善良（不争）——天道把你接走，因为你没有继续争下去的资质。太恶（疯争）——天道把你抹除，因为你不配活下去。玩家被迫在善恶之间找到那个"争而不疯"的平衡点。

## 1. 道心 DAO HEART — 重定位

### 1.1 道心不是什么

道心**不是**道德值，**不是**善良属性。

### 1.2 道心是什么

> **道心 = 你对自己修仙之路的信念强度。**
> 它是你在善恶两极之间的"锚"。
> 道心高，你可以在极端的善与恶之间来回而不迷失自我。
> 道心低，善会把你推向上界，恶会把你拉向魔道。

### 1.3 道心的游戏机制

| 道心区间 | 游戏效果 |
|----------|----------|
| **80-100** | 「明心见性」——免疫恐惧/魅惑/迷惑等精神DEBUFF。战斗中心魔类敌人对你的伤害-40%。平衡窗口扩大：善因/恶因在±20以内的波动不触发警告。 |
| **60-79** | 「坚定如磐」——可以主动使用一次"道心护体"（消耗道心5，抵消一次死亡判定——冷却20回合）。 |
| **40-59** | 「心湖微澜」——基准线。所有死亡判定照常。善因和恶因的增长速度正常。 |
| **20-39** | 「心魔初现」——触发"存在裂隙"事件卡。每次善恶变化超过±5时有10%概率获得负面DEBUFF。 |
| **0-19** | 「道心将碎」——每回合自动-1道心。善因和恶因的增长速度×1.5倍。随时可能走火入魔。 |
| **0** | 「走火入魔」——立即死亡。 |

### 1.4 道心如何变化

| 来源 | 变化量 | 触发 |
|------|--------|------|
| 遵守诺言（完成委托） | +5 | 支线完成 |
| 拒绝诱惑（心魔中选择抵抗） | +3 | 心魔反噬事件 |
| 突破成功 | +5 | 境界突破 |
| 与师尊交流（白刃真人事件） | +3 | NPC事件 |
| 背弃诺言 | -10 | 主动放弃委托 |
| 使用魔道法宝 | -3/次 | 战斗中使用 |
| 杀死曾经放过的人 | -15 | 因果涟漪事件 |
| 突破失败 | -15 | 瓶颈卡 |
| 战斗惨胜（HP < 20%） | +3 | 战斗结算 |

## 2. 法宝装备系统

### 2.1 装备槽位设计

```
┌─────────────────────────────────────┐
│  🗡️ 武器槽 ×1   决定了"攻击"的姿态   │
│  🛡️ 防具槽 ×1   决定了"防御"的效果   │
│  📿 饰品槽 ×1   提供持续被动加成     │
│  🔮 秘宝槽 ×1   一次性/冷却型强大效果 │
└─────────────────────────────────────┘
```

### 2.2 与旧系统的区别

| | 旧系统 | 新系统 |
|---|--------|--------|
| 拥有方式 | `gameState.resources.treasures` 数组 | 分为「未装备」和「已装备」 |
| 效果来源 | 拥有效果始终生效 | 只有装备中的法宝才生效 |
| 数量限制 | 无限制 | 最多4个槽位，每个槽位1件 |
| 替换代价 | 无 | 替换时旧法宝效果失效 |

### 2.3 数据结构

```javascript
// GameStateManager 新增字段
this.equipment = {
  weapon: null,    // 法宝id
  armor: null,
  accessory: null,
  artifact: null
};
this.treasureInventory = []; // 未装备的法宝id列表
this.treasureCooldowns = {}; // { 法宝id: 剩余冷却回合 }

// 保留旧字段兼容性
this.resources.treasures = []; // = equipment中所有id + inventory
```

### 2.5 复活法宝触发优先级

```
死亡判定 → 检查装备中的秘宝槽:
  1. 涅槃羽 → HP=50%，道心-5 → 继续游戏
  2. 替身符 → HP=30%，灵石-50% → 继续游戏
  3. 轮回镜 → 弹出"是否回溯"选择 → 回到10回合前 → 继续游戏
  4. 混沌茧 → HP恢复，所有属性初始化50 → 继续游戏
  5. 全部没有或已消耗 → 真正的死亡 → 死亡卡
```

## 3. 集市刷新机制

### 3.1 触发时机

集市不是随时可进的——它是**偶遇**机制：

```
触发条件: 每12-18回合概率触发一次「集市偶遇」卡
优先级: 55（低于道侣事件60，高于势力暗流40）

集市偶遇卡:
  ┌────────────────────────────────────┐
  │  🏪 鬼市偶遇                        │
  │  你路过一座废弃坊市时，               │
  │  感到一阵空间波动——                  │
  │  这不是普通的坊市，                   │
  │  是鬼市——只在特定时辰出现的修士黑市。   │
  │                                    │
  │  [左] 进去逛逛  → 打开集市面板       │
  │  [右] 绕道而行  → 无事发生           │
  └────────────────────────────────────┘
```

### 3.2 福源影响

集市商品的质量和数量直接受 `fortune` 属性影响：

| 福源区间 | 商品槽位数 | 稀有度权重修正 | 刷新价格倍率 |
|----------|-----------|---------------|-------------|
| 0-20 | 3 | 白70%/蓝17%/紫10%/金3% | ×1.5 |
| 21-40 | 4 | 白50%/蓝30%/紫15%/金5% | ×1.2 |
| 41-60 | 5 | 白35%/蓝35%/紫20%/金10% | ×1.0 |
| 61-80 | 6 | 白25%/蓝30%/紫25%/金20% | ×0.9 |
| 81-100 | 7 | 白15%/蓝30%/紫30%/金25% | ×0.8 |

**核心公式**:
```
金质法宝出现概率 = max(3%, 5% + (fortune - 40) × 0.3%)
```

> 福源低于20时仍有保底3%金质概率。天道无情，但也不绝人之路。

举例：fortune 100 的玩家遇到金质法宝概率 = 5% + 18% = **23%**。

### 3.3 刷新规则

- 每次进入集市，从法宝池中随机抽取 3-7 件（取决于福源）
- 同一件法宝不会重复出现（本次集市）
- 已拥有的法宝不会出现在集市中
- 高于当前境界的法宝不会出现
- 金质法宝保证出现不超过2件（防欧皇碾压）

### 3.4 灵石定价

| 稀有度 | 价格范围（灵石） |
|--------|-----------------|
| ★★ (白) | 20-30 |
| ★★★ (蓝) | 40-70 |
| ★★★★ (紫) | 80-150 |
| ★★★★★ (金) | 150-300 |
| ★★★★★★ (传说) | 300-500 |

## 4. 死亡系统全面重设计

### 4.1 死亡判定顺序

```
每次状态变化后:
  1. checkDeath() → 检查六大死亡条件
  2. 如果触发死亡 →
     a. 检查秘宝槽是否有复活法宝
     b. 如果有 → 复活并消耗法宝
     c. 如果有多个 → 按优先级依次尝试
     d. 如果全部消耗或没有 → 真正死亡
  3. 真正死亡 → 触发死亡卡 → 转世结算
```

### 4.2 六种死亡的哲学含义

| 死亡 | 文本 | 转世解锁 |
|------|------|----------|
| 道心崩碎 | "你的道心在最后一次打击中化为碎片。你感到自我在消散——不是死亡，是比死亡更可怕的东西：你忘了你是谁。" | 解锁"心如铁石"开局buff：道心初始+10 |
| 气血耗尽 | "你倒下时，最后的念头是——还有一件事没做完。是什么来着？你想不起来了。" | 解锁体修功法加成：气血初始+20 |
| 羽化登仙 | "天道有声：『汝善已满，无需再争。』你被捧上云巅。下方，那个马匪头子正在抢夺你没能杀他而留下的机缘。你终于懂了——太善良的人，不配修仙。" | 解锁天枢道院声望+20 |
| 天劫临身 | "九道天雷劈下——不是因为天要杀你，是你的恶业重到天道法则自动响应。你最后一眼看见的是血月。" | 解锁血煞老祖暗线剧情 |
| 厄运缠身 | "一切错失良机，一切运气耗尽。连一只路过的鸟都会在你头上拉屎。你死得毫无壮烈——只有荒谬。" | 解锁"天命在我"buff：福源初始+10 |
| 寿元耗尽 | "你感觉到生命的烛火逐渐微弱。你没有恐惧——只有一种奇怪的平静。坐化的过程，像一场漫长的日出。" | 寿元上限+5 |

### 4.3 善因/恶因的"死亡不是惩罚"

**关键设计**: 善因和恶因满了导致的死亡，不是"失败"——它们是**不同的结局方向**。

- 羽化登仙（善因满）—— 天道接引。**不是飞升，是淘汰。** "你已够好，无需再争。"太善良的人没有仙的资质——因为修仙的本质是争。
- 天劫临身（恶因满）—— 天道抹除。但解锁暗线剧情。

玩家应该能接受"我太善良了，天道把我接走了，修不到仙了——下一局试试走魔道路线"。

## 5. 全参数互连矩阵

### 5.1 参数一览

| 参数 | 含义 | 游戏影响维度 |
|------|------|-------------|
| cultivation | 修为 | 卡池境界、战斗灵力、境界突破 |
| daoHeart | 道心 | 死亡抵抗、精神免疫、善恶缓冲 |
| karmaGood | 善因 | 羽化风险、道侣好感、因果涟漪 |
| karmaBad | 恶因 | 天劫风险、魔化可能、禁忌力量 |
| fortune | 福源 | 集市品质、随机事件、暴击率 |
| health | 气血 | 战斗HP、濒死触发、生存基础 |
| lifespan | 寿元 | 时间限制、转世继承 |
| spiritStone | 灵石 | 集市购买、丹药获取、贿赂 |

### 5.2 参数互连矩阵（A → B 表示 A 影响 B）

```
            cultivation  daoHeart  karmaGood  karmaBad  fortune  health  lifespan  spiritStone
cultivation     —           ∓       ∓          ∓         ↑        ↑       ↑         —
daoHeart        ↑           —       ↓*         ↓*        ↑        ↑       —         —
karmaGood       —           ↓       —          ↓         —        ↓       —         ↑
karmaBad        ↑           ↓       ↓          —         ↓        ↓       ↓         ↑
fortune         ↑           —       —          —         —        ↑       ↑         ↑
health          —           —       —          —         —        —       ↓         —
lifespan        —           —       —          —         —        —       —         —
spiritStone     —           —       ↑(捐赠)    —         —        ↑(买药) —         —

↑ = 正面影响（X增加时Y增加）
↓ = 负面影响（X增加时Y减少）
∓ = 不确定（取决于方向）
* = 道心高时对善恶增长的缓冲作用
```

### 5.3 每个参数的具体影响链

#### cultivation（修为）— 引擎核心
```
修为 → 灵力值 (maxQi = cultivation/10+3)
     → 战斗基础伤害 (ATK += cultivation/8)
     → 卡池境界解锁
     → 道心：突破成功+5，失败-15（间接影响）
     → fortune：高修为吸引高机缘事件（间接）
     → lifespan：修为增长速度影响寿元消耗速率（修的快，燃烧寿命）
```

**设计意图**: 修为不是越高越好——修得太快会灼烧寿元（失衡惩罚）。玩家需要找自己的修行节奏。

#### daoHeart（道心）— 平衡之锚
```
道心 → 战斗暴击率 (暴击 += daoHeart/10)
     → 免疫恐惧/魅惑/迷惑DEBUFF（道心≥80）
     → 善恶缓冲：道心高时，karmaGood/karmaBad的波动更小
     → 死亡抵抗：道心≥60时可主动消耗5道心抵消一次死亡
     → 心魔反噬：道心低时，心魔出现频率和强度均提升
     → 突破成功率：道心≥70时突破成功率+10%
```

**设计意图**: 道心是唯一一个"全部正面"的属性——但它很难提升。维持道心就是维持人性。

#### karmaGood / karmaBad（善恶）— 双刃剑
```
善因 → 羽化登仙风险（≥100死亡=被淘汰，但解锁天枢结局）
     → 道侣好感度提升（道侣更信任善良的你）
     → 战斗中"天谴豁免"：善因>100时50%概率死亡复活（反直觉——善因本身就是死亡风险）
     → NPC事件偏向：善良NPC主动接近你

恶因 → 天劫临身风险（≥100死亡，但解锁血煞暗线）
     → 战斗中"魔化"能力：恶因>50且HP<30%时伤害×2
     → 禁忌选项：某些卡牌出现第三选择（恶因专属）
     → 恐惧光环：部分NPC不敢得罪你
     → 天机一闪频率增加（恶因吸引天机）

善恶互相抑制：
    善因增加时，恶因减少（缓慢）
    恶因增加时，善因减少（缓慢）
    但无法通过减少一侧来完全消除死亡风险——两侧都在爬坡。
```

**设计意图**: 善恶两端都是死路——但路上的风景完全不同。玩家必须在一个维度上推进的同时警惕另一个维度。

#### fortune（福源）— 运气即实力
```
福源 → 集市刷新品质（直接影响获得稀有法宝的概率）
     → 战斗随机天助（fortune/100概率触发+50%伤害）
     → 秘境隐藏路线发现
     → 转世bonus加成
     → 厄运事件概率（fortune<20时厄运事件概率+30%）
     → 道心间接影响：走运的修士道心更稳固（fortune>70时道心+1/10回合）
```

**设计意图**: 福源是玩家最容易感知到的"运气"数值。高福源让游戏更宽容，低福源让游戏更残酷。

#### health（气血）— 肉体代价
```
气血 → 战斗HP (maxHP = health × 3)
     → 战斗恢复 (回合恢复 = health/20)
     → 濒死触发：HP<30%时触发专属事件（心魔/机遇）
     → 寿元消耗：重伤时消耗寿元
     → 善因影响：气血低时更倾向于选择"安全"的善选项
     → 恶因影响：气血低时"魔化"概率提升
```

**设计意图**: 气血是你最直观的生存指标。低气血迫使玩家做高风险决策——这是压力。

#### lifespan（寿元）— 时间限制
```
寿元 → 硬性回合上限（80+初始值）
     → 战斗失败扣3年
     → Boss战扣1年
     → 修为增长速度×寿元消耗速率（修太快=烧命）
     → 转世加成：上一局存活30轮以上 → 下一局寿元+5
```

#### spiritStone（灵石）— 经济循环
```
灵石 → 集市购买法宝
     → 购买丹药
     → 贿赂NPC（跳过危险事件）
     → 替身符复活代价（50%灵石消耗）
     → 捐赠寺庙（灵石→善因转换）
```
