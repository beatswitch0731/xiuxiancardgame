## 一、支线任务系统总则

### 1.1 支线任务 vs 普通卡牌

| 维度 | 普通卡牌 | 支线任务链 |
|------|----------|-----------|
| **结构** | 单卡，左右滑一次就结束 | 多卡串联，有起承转合 |
| **触发** | 随机抽卡 | 满足条件后触发第一张，后续卡按链推进 |
| **后果** | 即时属性变化 | 跨境界因果、NPC关系变化、永久解锁 |
| **叙事** | 一句话情境 | 完整故事弧，有冲突和转折 |
| **设计意图** | 填充节奏、日常体验 | 让玩家记住"那个故事" |

### 1.2 支线任务类型

| 类型 | 标识 | 特征 | 数量目标 |
|------|------|------|----------|
| **师门线** | `SECT` | 与玩家所属门派绑定，推进师徒关系 | 每境界1条 |
| **红尘线** | `WORLD` | 凡间/散修/江湖人物交织的情感线 | 每境界1-2条 |
| **正魔线** | `FACTION` | 正道vs魔道的立场选择，影响结局 | 筑基后开始，每境界1条 |
| **因果线** | `KARMA` | 跨境界的因果回溯链，炼气种因→高境界结果 | 全局3条主线 |
| **天道线** | `HEAVEN` | 揭露世界真相的隐藏线，需多周目解锁 | 化神后开始 |
| **隐藏线** | `HIDDEN` | 极低概率触发，奖励稀有 | 全局2-3条 |

### 1.3 支线任务结构

每条支线任务是一个**卡牌链**，结构如下：

```
触发条件满足
  ↓
[入口卡] — 第一张卡，引入冲突/悬念
  ↓ (根据玩家选择)
[发展卡A] 或 [发展卡B] — 不同选择走不同路线
  ↓
[高潮卡] — 矛盾爆发 / Boss战 / 关键抉择
  ↓
[结局卡A] / [结局卡B] / [结局卡C] — 后果结算
  ↓
奖励发放 + 因果种子种下(为后续境界铺路) + NPC关系更新
```

### 1.4 支线与主线卡池的关系

- 支线卡牌的 `weight` 设为 `0`，不会被随机抽到
- 通过 `nextCard` 字段串联支线内部的卡牌
- 支线入口卡通过 `questTrigger` 条件触发，当条件满足时**强制插入**下一次抽卡
- 同一时间最多激活2条支线（避免叙事过载）
- 支线一旦激活，优先于普通卡牌出牌

## 二、支线数据结构标准

### 2.1 支线任务定义格式

在 `cards.js` 中新增 `QUESTS` 对象，定义所有支线任务：

```javascript
const QUESTS = {
  // 支线ID: 支线定义
  q_whiteFox_line: {
    id: "q_whiteFox_line",
    name: "白狐报恩",
    type: "KARMA",          // 支线类型
    realm: "qi",            // 起始境界
    path: null,             // 功法限制(null=全功法)
    trigger: {
      // 触发条件：满足全部条件后，入口卡强制插入下一次抽卡
      turnMin: 5,           // 至少经过5轮
      attributes: {},       // 属性条件(可选)
      resources: {},        // 资源条件(可选)
      notPlayed: ["q_whiteFox_line"], // 未触发过
    },
    entryCard: "q_whiteFox_1",  // 入口卡ID
    chainLength: 3,              // 链长度
    rewards: {
      completion: { karmaGood: 15, fortune: 10 },
      // 完成奖励，在最终结局卡发放
    },
    karmaSeeds: [
      // 完成后种下的因果种子(为后续境界铺路)
      { id: "whiteFox", delay: 8, realm: "foundation", priority: 1 }
    ],
    flags: {
      // 完成后设置的游戏标记
      whiteFoxSaved: true,
      // 这些flag会影响后续卡牌的触发条件
    }
  }
};
```

### 2.2 支线卡牌的额外字段

支线卡牌在标准卡牌JSON基础上，增加以下字段：

```javascript
{
  id: "q_whiteFox_1",
  title: "白狐受困",
  description: "...",
  type: "QUEST",              // 新增卡牌类型：QUEST
  questId: "q_whiteFox_line", // 所属支线ID
  questStep: 1,               // 支线第几步
  weight: 0,                  // 支线卡不参与随机抽卡
  choices: {
    left: {
      text: "妖兽当诛",
      effects: { cultivation: 10, karmaBad: 15, health: -5 },
      questNext: "q_whiteFox_1a_kill",  // 支线分支：选择杀狐后的下一张卡
    },
    right: {
      text: "救它脱困",
      effects: { cultivation: -5, karmaGood: 15, fortune: 5 },
      questNext: "q_whiteFox_1b_save",  // 支线分支：选择救狐后的下一张卡
      karmaSeed: { id: "whiteFox", delay: 8, realm: "foundation", priority: 1 }
    }
  }
}
```

### 2.3 游戏工作流对接

在 `game.js` 的 `CardPool.draw()` 方法中，新增支线触发逻辑：

```javascript
draw() {
  // 1. 优先检查已激活支线的下一张卡
  if (this.gameState.activeQuest && this.gameState.questNextCard) {
    const card = CARD_DATA[this.gameState.questNextCard];
    this.gameState.questNextCard = null;
    return card;
  }

  // 2. 检查是否有新支线可触发
  for (const [questId, quest] of Object.entries(QUESTS)) {
    if (this.canTriggerQuest(quest)) {
      this.gameState.activeQuest = questId;
      return CARD_DATA[quest.entryCard];
    }
  }

  // 3. 正常抽卡（现有逻辑）
  // ...
}

canTriggerQuest(quest) {
  // 检查触发条件
  if (this.gameState.turn < quest.trigger.turnMin) return false;
  if (this.gameState.activeQuest) return false; // 已有支线进行中
  if (this.gameState.completedQuests.includes(quest.id)) return false;
  // 检查属性/资源条件...
  return true;
}
```

## 十、与游戏工作流对接指南

### 10.1 卡牌数据接入

本文档中所有卡牌JSON数据，可直接复制到 `cards.js` 的 `CARD_DATA` 对象中。需要注意：

1. **新增卡牌类型**：`QUEST` 类型需要在 `game.js` 的卡牌处理逻辑中新增分支
2. **新增字段**：`questId`、`questStep`、`questNext`、`questEnd`、`triggerKarma`、`triggerFlag`、`flags`、`requireFlag`、`triggersEnding`、`effects_extra` 都是新字段
3. **新增对象**：`QUESTS` 对象需要新增到 `cards.js`

### 10.4 支线触发逻辑伪代码

```javascript
// game.js CardPool.draw() 修改版
draw() {
  // 1. 优先出支线后续卡
  if (this.gameState.questNextCard) {
    const card = CARD_DATA[this.gameState.questNextCard];
    // 检查 requireFlag 条件
    if (card.choices) {
      for (const choice of Object.values(card.choices)) {
        if (choice.requireFlag && !this.checkFlag(choice.requireFlag)) {
          // 该选项不可用，但不影响卡牌出现
        }
      }
    }
    this.gameState.questNextCard = null;
    return card;
  }

  // 2. 检查因果种子是否发芽
  const readySeeds = this.gameState.karmaSeeds.filter(s =>
    s.delay <= 0 && (!s.realm || s.realm === this.gameState.realm)
  );
  if (readySeeds.length > 0) {
    readySeeds.sort((a, b) => b.priority - a.priority);
    const seed = readySeeds[0];
    this.gameState.karmaSeeds = this.gameState.karmaSeeds.filter(s => s !== seed);
    // 因果种子触发对应的支线入口卡
    const quest = Object.values(QUESTS).find(q => q.triggerKarma === seed.id);
    if (quest) {
      this.gameState.activeQuest = quest.id;
      return CARD_DATA[quest.entryCard];
    }
    // 如果没有对应支线，退回到普通因果卡
    const karmaCard = KARMA_CARDS[seed.id];
    if (karmaCard) return CARD_DATA[karmaCard];
  }

  // 3. 检查flag触发的新支线
  for (const [questId, quest] of Object.entries(QUESTS)) {
    if (quest.triggerFlag && this.checkFlag(quest.triggerFlag) &&
        !this.gameState.completedQuests.includes(questId) &&
        !this.gameState.activeQuest) {
      this.gameState.activeQuest = questId;
      return CARD_DATA[quest.entryCard];
    }
  }

  // 4. 正常随机抽卡（现有逻辑不变）
  // ...
}

// 处理支线卡牌的选择
handleQuestChoice(card, direction) {
  const choice = card.choices[direction];
  
  // 设置支线下一张卡
  if (choice.questNext) {
    this.gameState.questNextCard = choice.questNext;
  }
  
  // 设置flags
  if (choice.flags) {
    Object.assign(this.gameState.flags, choice.flags);
  }
  
  // 支线结束
  if (choice.questEnd || !choice.questNext) {
    this.gameState.completedQuests.push(card.questId);
    this.gameState.activeQuest = null;
  }
  
  // 触发结局
  if (choice.triggersEnding) {
    this.triggerEndingSequence();
  }
}

checkFlag(condition) {
  // 解析 "flag=value" 或 "flag" 格式
  if (condition.includes('=')) {
    const [key, val] = condition.split('=');
    return this.gameState.flags[key] === val;
  }
  if (condition.includes('>=')) {
    const [key, val] = condition.split('>=');
    return (this.gameState.flags[key] || 0) >= parseInt(val);
  }
  return !!this.gameState.flags[condition];
}
```
