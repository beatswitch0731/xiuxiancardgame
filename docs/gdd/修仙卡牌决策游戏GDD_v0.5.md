## 一、设计立柱 (Design Pillars)

游戏必须交付的4个非 negotiable 玩家体验。所有设计决策以此为标尺。

| 立柱 | 玩家体验 | 衡量标准 |
|------|----------|----------|
| **一念因果** | 每次滑动都有重量 — 炼气期的一个善念，金丹期化成报恩的妖兽 | 玩家能回忆起"导致后果的那次决策" |
| **万法归Build** | 功法选择有真实意义 — 剑修和丹修玩起来是两个游戏 | 不同功法Build的卡牌池≥60%不同 |
| **层层叠扣飞升路** | 境界提升 = 打开新世界 — 不只是数值增长，是规则变化 | 每个境界至少引入1个新机制 |
| **转世不空修** | 死亡不是清零 — 前世的因成为来世的缘 | 转世后玩家有"这次我知道该怎么选"的冲动 |

## 二、核心循环 (Core Loop)

### Moment-to-Moment (0-15秒)
- **Action**: 卡牌出现 → 阅读修仙情境 → 左滑(拒绝/不纳)/右滑(接受/纳取)，或触发多方向拖拽卡
- **Feedback**: 五维属性数值即时波动 + 资源变动 + 因果种子静默记录 + 音效/粒子反馈
- **Reward**: 修为推进 + 剧情推进 + 资源/功法/法宝/丹药/道侣获取

### Session Loop (10-20分钟)
- **Goal**: 在当前境界内维持五维平衡 → 积累修为 → 触发突破瓶颈
- **Tension**: 道心太低走火入魔 / 因果太重天劫难度飙升 / 修为归零陨落 / 寿元耗尽天人五衰
- **Resolution**: 突破成功(进入新境界) 或 陨落(转世重修)

### Long-Term Loop (数小时-数周)
- **Progression**: 境界攀升(炼气→飞升) + 功法Build跨境界成长 + 剧情线解锁
- **Retention Hook**: 前世未解之谜 / 隐藏飞升结局 / 多功法Build体验 / 因果链全收集

## 三、境界系统 — 层层叠扣的世界观

这是修仙题材和王权玩法的核心融合点。**境界 = 游戏阶段 = 新规则层**。

### 境界阶梯

| 境界 | 卡牌主题 | 新机制引入 | 突破条件 | 突破方式 |
|------|----------|------------|----------|----------|
| **炼气** | 入门机缘、灵根觉醒、拜师、初遇妖兽 | 基础滑动决策 | 修为满 + 道心≥30 | 选功法(定Build方向) |
| **筑基** | 师门历练、功法修炼、初入红尘、筑基丹 | 功法专属卡牌池开启 | 修为满 + 因果≤50 | 筑基大典(连续3张关键决策) |
| **金丹** | 结丹、斗法、秘境探索、道侣机缘 | **因果种子首次发芽** + 法宝系统 | 修为满 + 道心≥50 | 渡心劫(内在Boss战) |
| **元婴** | 元神出窍、跨境追杀、势力争斗、旧因果爆发 | **元神分身系统**（解锁第二决策选项） | 修为满 + 因果结算 | 渡天劫(外在Boss战) |
| **化神** | 窥天道、飞升前兆、界域真相、因果大爆发 | 天道选择(影响飞升结局) | 修为满 + 道心≥80 | 渡九重天劫(终极考验) |
| **渡劫→飞升** | 最终因果结算、飞升抉择 | 全因果链回放 | 渡劫成功 | 飞升(通关) / 兵解(转世) |

### 关键设计：境界不只是数值门槛

每个境界引入**新机制**，让玩家感觉"换了游戏"：

- **炼气→筑基**：从被动应对 → 主动选功法(Build确立)
- **筑基→金丹**：因果系统激活(之前的决策开始有后果了)
- **金丹→元婴**：元神分身系统（每张卡增加一个消耗性的"元神选项"，策略层扩展但UI不炸裂）
- **元婴→化神**：天道选择（剧情分支，决定结局走向）
- **化神→飞升**：全因果结算(所有前世今生的因一次性收割)

### 突破瓶颈设计

突破不是自动的 — 需要满足条件 + 通过"瓶颈事件链"：

```
修为满 → 触发瓶颈事件链 → 连续3-5张关键决策卡 → 
  成功：突破，进入新境界
  失败：修为回落30%，或直接陨落(高境界)
```

瓶颈事件链的卡牌是**锁入式**的(类似王权的地牢) — 进入后不能退出，必须做完。

## 四、五维属性系统

替代王权的"宗教/人民/军队/金钱"。修仙化重构：

| 属性 | 含义 | 归零后果 | 爆满/过高后果 | 设计意图 |
|------|------|----------|---------------|----------|
| **修为** | 修炼进度/境界能量 | 陨落(转世) | 触发突破 | 主进度条，驱动游戏前进 |
| **道心** | 心性稳定/精神状态 | 走火入魔(强制随机决策3轮) | 心如止水/太上忘情(下3轮效果翻倍，但丢失红尘羁绊) | 内在风险控制，阻止无脑堆修为 |
| **因果** | 善恶业力/业力债 | 机缘断绝(好事件卡概率归零) | 天劫难度飙升/劫雷提前 | 长期债务，让玩家"不敢乱来" |
| **福缘** | 运势/气运 | 厄运缠身(坏事件卡概率翻倍) | 天降机缘(必出稀有卡) | 短期波动，增加RNG趣味性 |
| **气血** | 肉身/生命能量 | 肉身崩溃(非体修直接转世) | 肉身成圣(体修专属Buff，气血≥90时伤害吸收) | 战斗缓冲，体修核心 |

### 与王权四维的关键区别

王权的四维是**对称的**(都是"不能太高不能太低")。修仙版引入**不对称设计**：

- **修为**：越高越好(只有爆满=突破，没有"太高"惩罚)
- **道心**：双向风险(太低走火入魔，太高"太上忘情"失去红尘羁绊=丢失道侣/师门线)
- **因果**：善恶双轨(不是简单的"越低越好"，善因和恶因有不同后果)
- **福缘**：纯波动条(随机性来源，玩家无法直接控制)
- **气血**：战斗缓冲(非体修多数情况下只是边缘属性，体修是主属性)

### 气血设计的特别说明

气血主要服务于**体修Build**和**战斗/渡劫场景**。

- **非体修**：初始气血 30，大部分卡牌不影响。只有在战斗卡/重伤事件/渡劫时才会消耗。归零=肉身崩溃直接转世。
- **体修**：初始气血 60，功法卡牌普遍提供气血增益。体修可以主动消耗气血来抵消修为/道心的损失（"硬扛"）。
- **丹药**：回春丹可以恢复气血，战斗中也可以使用。

这样设计保证：**非体修玩家不需要时刻盯着气血条**，但气血在关键时刻（渡劫、战斗）提供第二次容错机会。

### 因果双轨设计

因果不是单数值，而是**善恶双轨**：

```
善因 ────────────── 恶因
-50    -25    0    +25    +50
```

善因高：渡劫时天劫难度降低，但可能有"恩将仇报"反转事件（被救助者上门索要更多）。
恶因高：渡劫时天劫难度飙升，但魔道功法威力增强，某些魔修专属卡会解锁。
平衡态：正常渡劫，无特殊加成/减成。

这让"善恶选择"不是简单的道德题 — **恶人有恶人的玩法(魔修Build)**。

## 五、修炼路径系统 (功法Build)

这是突破王权"无长期Build"瓶颈的核心设计。

### 六大功法路径

| 功法 | 核心幻想 | 专属卡牌特征 | Build方向 | 天劫特色 |
|------|----------|--------------|-----------|----------|
| **剑修** | 一剑破万法 | 攻击性强、因果恶因增长快、道心消耗大 | 杀伐果断，以战养战 | 剑劫(万剑噬主) |
| **法修** | 五术万变 | 策略性强、多选项、需要预判 | 灵活应变，术法组合 | 五行劫(相生相克) |
| **体修** | 以身化道 | 被动增益多、气血主属性、修为增长慢但稳 | 肉身成圣，硬扛一切 | 肉身劫(身碎重塑) |
| **丹修** | 炼丹辅修 | 资源转换强、可制造道具、辅修型 | 以丹入道，资源循环 | 丹毒劫(药力反噬) |
| **阵修** | 阵法控场 | 控制型、改变卡牌规则、延迟效果 | 以阵困敌，规则改写 | 阵法劫(阵眼崩塌) |
| **符修** | 符箓召唤 | 召唤型、一次性强力效果、资源消耗 | 符道通神，爆发控场 | 符劫(符力暴走) |

### 六大功法核心差异（一句话定位）

| 功法 | 核心机制差异 | 玩法定位 |
|------|-------------|----------|
| **剑修** | 高攻高恶因，后期剑意成型后一卡翻盘点 | 玻璃大炮，刀尖舔血 |
| **法修** | 部分卡牌提供3-4个方向选择（多选项卡） | 策略型，信息博弈 |
| **体修** | 气血可替代修为/道心承受损失，渡劫容错高 | 坦克，慢但稳 |
| **丹修** | 独占丹药制作、经济循环、延寿能力 | 资源型，以物换命 |
| **阵修** | 免费拨动天机盘，可改变卡牌规则（如移除负面效果） | 控场，规则改写 |
| **符修** | 可储存强力符箓，一次性爆发改变局面 | 爆发，节奏控制 |

### 功法选择时机

在**炼气→筑基**突破时选择功法。选择后：
1. 专属功法卡牌加入卡池(权重高)
2. 通用卡牌权重降低
3. 解锁该功法的Build升级树
4. 功法标签写入玩家数据，影响卡牌判定与资源获取

### 功法Build升级树

每个功法有3条升级分支，在金丹期"结丹"时选择：

```
剑修:
├── 剑意流(攻击向): 剑气→剑意→剑域→剑心
├── 剑体流(防御向): 剑骨→剑肤→剑脏→剑心
└── 剑魂流(召唤向): 剑灵→剑仆→剑阵→剑心

法修:
├── 五行流: 五行术→五行阵→五行遁→五行真解
├── 雷法流: 掌心雷→雷池→雷劫体→雷神降世
└── 符法双修: 符箓精通→阵法通晓→万法归一

体修:
├── 筋骨流: 铁骨→铜皮→银血→金身
├── 内脏流: 炼心→淬肺→养肾→合道
└── 战体流: 战意→不屈→不灭→修罗

丹修:
├── 丹方流: 丹方辨识→火候掌控→炼丹宗师→丹道通神
├── 药理流: 药性识别→毒丹→禁丹→以丹入道
└── 养生流: 养生→延寿→不死→长生

阵修:
├── 困阵流: 迷阵→困阵→杀阵→诛仙阵
├── 辅阵流: 聚灵阵→护山大阵→传送阵→天地棋局
└── 符阵流: 符阵入门→阵符合一→万法阵眼→阵道真解

符修:
├── 符箓流: 基础符→中级符→高级符→天符
├── 召唤流: 纸人→阴兵→鬼神→天兵
└── 禁术流: 血符→命符→禁咒→咒道
```

升级通过**重复使用同类卡牌**触发 — 做多了某类决策，该类卡牌升级，效果增强。

### 跨境界Build成长

功法Build不会因转世重修完全清零：
- **道基**：每次转世保留1个Build升级(玩家选择保留哪个)
- **道基共鸣**：如果连续多世选同一功法，解锁隐藏的"道基共鸣"加成
- **转修**：也可以转世后换功法，但道基加成重置

## 六、因果回溯系统 — 修仙版蝴蝶效应

这是本游戏**最大的创新点**，也是修仙题材和王权玩法的灵魂融合。

### 设计理念

修仙的核心哲学是**因果轮回**。王权的概率卡池是"伪因果"(其实没有真正的因果链)。本游戏做**真因果**：

### 机制规格

```
## Mechanic: 因果回溯系统

**Purpose**: 让每次决策都有跨境界的长期后果，解决王权"决策无长期影响"的瓶颈
**Player Fantasy**: "种什么因，得什么果" — 玩家感受到修仙世界的因果律

**Input**: 每次滑动决策
**Output**: 生成隐藏的"因果种子"，在N轮后发芽为事件卡

**因果种子结构**:
  - 来源决策ID
  - 善/恶标记
  - 涉及角色/势力
  - 发芽延迟轮数(境界相关: 炼气期15轮, 筑基期20轮, 金丹期25轮, 元婴期30轮, 化神渡劫时结算)
  - 发芽条件(需要达到某境界/遇到某角色)
  - 后果事件卡ID
  - 是否可化解(有些恶因可以后续决策抵消)

**发芽流程**:
  1. 检查所有因果种子是否满足发芽条件
  2. 满足的种子转化为事件卡，加入卡池(高权重)
  3. 事件卡出现时，显示模糊预兆("似有旧识来访...")
  4. 玩家可能认出也可能不认出(取决于是否记得之前的决策)
  5. 事件卡处理完后，该因果链关闭或延续

**渡劫总结算**:
  - 所有未发芽的因果种子在渡劫时一次性结算
  - 善因总和 - 恶因总和 = 渡劫难度修正
  | 净善因 | 渡劫难度 |
  |--------|----------|
  | ≥30 | 天劫难度-50% |
  | 10~29 | 天劫难度-20% |
  | -10~9 | 正常 |
  | -30~-11 | 天劫难度+30% |
  | ≤-31 | 天劫难度+80% (魔修反而可能借此突破) |

**Edge Cases**:
  - 因果种子在转世后是否保留？→ 保留，以"宿命卡"形式出现
  - 同一角色的多个因果如何处理？→ 合并为复合事件(恩怨交织)
  - 因果种子太多怎么办？→ 上限30个， oldest 自然衰减；渡劫前显示"因果预览"
  - 化解后的因果是否还影响渡劫？→ 化解后从种子池移除，不再影响

**Tuning Levers**:
  - 发芽延迟轮数 [PLACEHOLDER]
  - 因果权重(影响卡池概率) [PLACEHOLDER]
  - 善恶因对渡劫的影响系数 [PLACEHOLDER]
  - 因果种子上限 [PLACEHOLDER - 暂定30]
```

### 因果链示例

```
炼气期: 遇到受伤妖兽
  ├─ 右滑(救治) → 善因种子A(妖兽·善·发芽延迟15轮)
  └─ 左滑(杀取内丹) → 恶因种子B(妖兽·恶·发芽延迟10轮) + 修为+10

  ...15轮后，金丹期...

金丹期: 种子A发芽 → 事件卡"化形妖兽来报恩"
  ├─ 右滑(接纳) → 获得妖兽道侣(强力长期卡) + 善因+5
  └─ 左滑(拒绝) → 妖兽心碎离去 + 道心-10(红尘劫种)

  ...10轮后，元婴期...

元婴期: 种子B发芽(如果当初选了杀) → 事件卡"妖兽族群寻仇"
  ├─ 右滑(赔罪) → 损失法宝 + 恶因-10(化解)
  └─ 左滑(再杀) → 恶因+15 + 获得妖兽内丹 + 因果恶化
```

### 因果预兆系统

为了让玩家**感知到因果**而不是被随机打脸：

- 因果种子发芽前2轮，显示**模糊预兆**："你近日心神不宁，似有旧事将了..."
- 发芽时，如果玩家之前做过类似选择，事件卡会带**回溯标记**："此事似乎与你在炼气期的某个决定有关..."
- 渡劫前，显示**因果总览**：列出所有未了因果，让玩家做最后准备

## 七、转世重修系统 (Roguelike核心)

### 死亡条件

| 死亡方式 | 触发条件 | 频率预期 |
|----------|----------|----------|
| 修为归零 | 修为条见底 | 最常见(新手主要死法) |
| 道心崩溃 | 道心归零→走火入魔→3轮内未恢复 | 中期常见 |
| 天劫不渡 | 渡劫失败 | 高境界主要死法 |
| 因果反噬 | 恶因爆满→业火烧身 | 魔修Build风险 |
| 寿元耗尽 | 寿元归零→天人五衰 | 全局兜底，防止无限拖局 |
| 肉身崩溃 | 气血归零(非体修更脆弱) | 战斗/渡劫风险 |

### 转世保留机制

| 保留项 | 说明 | 设计意图 |
|--------|------|----------|
| **前世记忆** | 解锁的剧情线永久可见 | 长期叙事进度 |
| **道基(1个)** | 玩家选择保留1个功法Build升级 | 跨世Build成长 |
| **灵根选择权** | 解锁的灵根类型可在转世时重新选择 | 策略灵活性 |
| **因果种子** | 前世未了因果 → 转世后的"宿命卡" | 因果连贯性 |
| **部分遗泽** | 特定法宝可作为"遗泽"极低概率转世保留 | 惊喜感与叙事合理性 |

### 转世重置机制

| 重置项 | 说明 |
|--------|------|
| 修为 | 回到炼气期初始 |
| 道心/福缘/气血 | 回到初始值 |
| 因果值 | 重置为0(但因果种子保留) |
| 当前功法Build | 重置(除了保留的1个道基) |
| 灵石/丹药 | 全部清空 |
| 法宝 | 大部分清空，极少数可触发"遗泽"保留 |
| 寿元 | 重置为80年(标准)或根据上一世表现浮动 [PLACEHOLDER] |

### 宿命卡系统

前世未了的因果，转世后以"宿命卡"形式介入：

```
宿命卡特征:
  - 在新一世的特定境界强制出现(无法跳过)
  - 带有"前世记忆"标记，玩家能看到前世的因果
  - 选择会影响当前世的因果走向
  - 解决后宿命卡消失，因果链关闭

示例:
  前世你杀了一个散修。
  转世后，筑基期出现宿命卡:
  "一散修拦路，眼神似有恨意...你隐约记得，此人面容与前世所杀之人相似。"
    ├─ 右滑(认罪赔礼) → 恶因-10，损失资源，但化解宿命
    └─ 左滑(再杀) → 恶因+15，获得资源，但宿命加深(下一世还会出现，更凶)
```

## 八、故事线架构

### 横向故事线 (同一境界内并行)

| 故事线 | 主题 | 卡牌特征 | 跨境界延续 |
|--------|------|----------|------------|
| **师门线** | 师徒恩怨、同门争斗、门派兴衰 | 师门角色卡、门派事件 | 师门存亡影响后期资源 |
| **正魔线** | 正道vs魔道的选择 | 立场抉择卡、势力冲突 | 正魔倾向影响渡劫方式 |
| **红尘线** | 道侣、凡人羁绊、情劫 | 情感决策卡、道侣事件 | 道侣可跨境界成长，情劫是主要道心风险 |
| **天道线** | 探索世界真相、飞升秘密 | 稀有探索卡、上古遗迹 | 解锁隐藏飞升结局，决定最终飞升类型 |

### 纵向故事线 (跨境界的长线)

| 故事线 | 触发方式 | 跨越范围 |
|--------|----------|----------|
| **前世因果** | 转世后的宿命卡 | 跨越2-3世 |
| **天道阴谋** | 化神期天道选择 | 从元婴到飞升 |
| **界域战争** | 飞升后解锁(续作DLC?) | 下界→上界 |
| **混沌初开** | 隐藏线，需多世收集碎片 | 全游戏周期 |

### 故事线交织设计

故事线不是独立的 — 它们通过**因果系统**自然交织：

```
师门线决策(救同门) 
  → 善因种子(同门·善)
  → 金丹期发芽: 同门报恩，介绍你认识道侣候选
  → 红尘线开启
  → 道侣是妖族
  → 正魔线触发(正道不容人妖恋)
  → 正魔选择影响天道线
```

这种交织不是脚本预设的，而是**因果系统自然产生**的 — 这就是"层层叠扣"。

## 十四、核心机制增强 (Advanced Mechanics)

本部分是将《王权》系列高阶理论（空间探索、多维决策、概率袋显性化）与修仙体系深度融合的进阶玩法。

### 1. 空间维度引入：【秘境试炼】 (节点地图)

当玩家在游戏中抽到特定机缘卡（如：上古秘境开启）并右滑进入时，游戏暂时脱离无限抽卡模式，转入节点地图界面。
- **触发规则**：
  - 炼气期：不出现
  - 筑基期：修为≥70时，10%概率
  - 金丹期：修为≥70时，20%概率
  - 元婴期：修为≥70时，30%概率
  - 化神期：修为≥70时，40%概率
  - 每局最多1次秘境
- **节点类型**：战斗、采集、休息、事件、商人、Boss
- **节点地图**：树状3-5层，每层2-3个选择，玩家自主选择路线
- **专属卡池**：秘境内使用秘境专属卡牌，不触发常规因果种子（避免交叉复杂）
- **奖励结构**：必得1件法宝/珍稀丹药 + 大量修为/灵石
- **失败惩罚**：可中途退出，但损失一半已获奖励；Boss战失败则损失全部奖励并扣气血
- **设计价值**：打破单一的左右滑动节奏，给玩家提供强烈的"主动探索感"和"阶段性目标感"。

### 2. 决策维度突破：【多目标互动】 (多方向滑动)

在特定的复杂事件（如多方势力火拼、正邪交锋）中，打破二元选择的限制。
- **玩法呈现**：卡牌不仅可以左右滑动，还可以向上/向下拖拽，甚至拖向屏幕四周代表特定势力的人像上。
  - *左滑*：相助正道（得罪魔道，积累善因）
  - *右滑*：相助魔修（得罪正道，积累恶因，获重利）
  - *上滑*：坐山观虎斗，两败俱伤后夺宝（善因-5，恶因-5，获宝，天道业力+15）
  - *下滑*：直接遁走（无事发生，福缘-5错失机缘）
- **出现频率**：仅占全部卡牌的5-10%，避免过度复杂化
- **教学规则**：多方向卡不在前10分钟出现，首次出现时带"?"提示引导
- **设计价值**：极大地丰富了修仙那种"弱肉强食、见机行事"的尔虞我诈感，扩展了策略空间。

### 3. Bag系统显性化：【天机/气运盘】 (可视化的权重干预)

将《王权》底层隐性的概率抽卡系统（Bag System）包装成修仙概念里的"天机"。
- **玩法呈现**：UI 角落新增一个"天机盘"。当玩家修剑道时，天机盘亮起剑形符文，明确提示："剑道机缘卡牌概率大幅提升"。当积累恶因时，天机盘被黑气缠绕，预警"仇家寻仇卡牌即将到来"。
- **进阶互动**：玩家可主动花费寿元"拨动天机盘"：
  - 剔除1张大凶之卡：消耗 5 年寿元
  - 将某张机缘卡权重拉满：消耗 10 年寿元
  - 阵修专属：每境界免费拨动1次天机盘（不消耗寿元）
  - 拥有特定法宝（如天机盘核心）时：额外免费拨动次数
- **设计价值**：把底层的数学机制变成了玩家可以主动把玩的策略系统，且代价(寿元)具有强烈的修仙代入感。

### 4. 节奏极端化：【极速天劫 Boss 战】 (限时反应挑战)

平时的左右划卡没有时间限制，但修仙的"渡劫"需要生死一线的压迫感。
- **玩法呈现**：触发渡劫时，脱离常规模式。连续出现9张天劫卡牌，每张卡有反应时间限制：
  - 元婴天劫：1.5秒/张
  - 化神九重天劫：1.2秒/张
  - 可用渡厄丹延长 +0.5秒/张
- **决策方式**：保持滑动，不引入新交互
  - 左滑：肉身硬抗（消耗气血）
  - 右滑：法宝/丹药抵挡（消耗资源）
  - 上滑：阵法/法修技能应对（阵修/法修收益更高）
  - 下滑：遁逃跳过（损失修为，但保气血）
- **因果联动**：恶因太多时，天雷速度更快，且出现心魔卡（滑错则道心大损）。善因高时，反应时间略微延长。
- **失败条件**：气血归零、道心归零、或连续3张未在时限内选择
- **失败惩罚**：
  - 元婴以下：修为回落50%，重生当前境界起点
  - 化神/渡劫：直接转世
- **设计价值**：平时修仙是慢节奏的运筹帷幄（种因），渡劫时则是肾上腺素飙升的动作反应（得果），完美契合修仙小说中渡劫时九死一生的紧张感。

针对界面层玩法的底层支撑，定义以下核心数据结构与实体资源经济循环。

### 1. 卡牌数据结构定义 (Card Data Structure)

### 2. 可消耗资源系统 (Consumable Resources)

五维属性本质是"状态条（平衡度）"，不作为支付手段。游戏引入以下实体资源支撑经济循环：

| 资源类型 | 核心定位 | 初始值 | 获取途径 | 消耗途径 | 跨界/转世处理 |
|----------|----------|--------|----------|----------|---------------|
| **灵石 (Spirit Stone)** | 基础经济货币 | 0 | 门派俸禄、战斗夺宝、秘境事件、商人交易 | 贿赂、购买法宝/丹药、启动阵法选项 | 跨界保留，转世清零 |
| **寿元 (Lifespan)** | 倒计时与高级代价 | 80年 | 延寿丹、突破小境界+10、特殊机缘 | 禁术（如拨动天机盘剔除凶卡）、重伤事件、部分战斗卡 | 转世重置 |
| **丹药 (Pill Slots)** | 战术一次性消耗品 | 最多3格 | 炼丹（丹修专属）、探索奖励、商人购买 | 战斗前/渡劫中主动拖拽使用 | 跨界保留，转世清零 |
| **法宝 (Artifact Slots)** | 常驻被动装备 | 最多2格 | Boss战掉落、上古秘境、商人购买 | 被动生效，可被更高级法宝替换，恶劣因果中可能损毁 | 跨界保留，转世极少数作为遗泽保留 |

#### 寿元消耗规则（关键修正）

寿元不是"每划卡扣1年"，而是**差异化消耗**：

| 场景 | 消耗寿元 | 说明 |
|------|----------|------|
| 普通划卡 | 0 | 日常修炼不扣寿元 |
| 战斗卡 | 0.2~0.5年 | 搏杀伤身 |
| 重伤事件 | 1~3年 | 肉身受损 |
| 禁术/天机盘干预 | 5~15年 | 逆天改命的代价 |
| 强行突破失败 | 5~10年 | 反噬 |
| 延寿丹 | +10~20年 | 丹修核心优势 |

按一局从炼气到飞升约150-200张卡计算，平均寿元消耗约40-60年，初始80年给玩家足够容错，但恶意乱用禁术会快速老死。

### 3. 法宝系统

法宝是常驻被动装备，提供卡池权重、属性波动、特殊机制等方面的加成。

#### 法宝类型与示例

| 法宝类型 | 示例 | 效果 |
|----------|------|------|
| 攻击型 | 青锋剑 | 剑修卡权重+20%，战斗卡气血损耗-10 |
| 防御型 | 玄龟盾 | 道心波动-30%，战斗卡气血损耗-15 |
| 因果型 | 轮回镜 | 宿命卡提前1轮显示预兆，因果预览更详细 |
| 经济型 | 储物戒 | 灵石获取+30%，商人购买价格-10% |
| 特殊型 | 天机盘核心 | 每境界免费拨动天机盘1次 |
| 体修专属 | 龙象内丹 | 气血上限+20，气血恢复速度+50% |
| 丹修专属 | 万宝炉 | 炼丹成功率+50%，可多携带1格丹药 |

#### 法宝获取与损毁

- **获取**：Boss掉落（40%）、秘境通关（50%）、商人购买（低概率）、任务奖励（10%）
- **替换**：获得新法宝时，可选择替换旧法宝或丢弃新法宝
- **损毁**：在极端因果事件或渡劫失败时，法宝可能损毁作为替死（1次性保护）
- **遗泽**：转世时，极低概率（5%）将1件法宝作为"遗泽"保留

### 4. 丹药系统

丹药是战术一次性消耗品，在战斗前或渡劫中主动使用。

#### 丹药类型表

| 丹药 | 效果 | 获取方式 | 丹修专属 |
|------|------|----------|----------|
| **回春丹** | 恢复气血30，或下次伤害减半 | 通用 | 否 |
| **清心丹** | 道心回到50（走火入魔时救命） | 通用 | 否 |
| **破境丹** | 突破瓶颈事件链跳过1张卡 | 丹修/稀有商人 | 是（丹修可稳定制作） |
| **延寿丹** | 寿元+15 | 丹修/特殊机缘 | 是（丹修可稳定制作） |
| **渡厄丹** | 渡劫时限+0.5秒/张 | 丹修/秘境 | 是（丹修可稳定制作） |
| **燃血丹** | 消耗气血20，换取修为+20 | 魔道/体修 | 否 |
| **隐气丹** | 跳过1张凶卡（不消耗寿元） | 丹修/稀有商人 | 否 |
| **悟道丹** | 下3张卡修为收益+50% | 秘境/特殊 | 否 |

#### 丹药使用规则

- 丹药栏最多3格，获得第4个丹药时必须先选择丢弃1个
- 丹药可在卡牌出现前预使用（如预判下一张是战斗卡）
- 渡劫中也可使用，但占用反应时间
- 丹修专属"万宝炉"可扩展到4格丹药栏

### 5. 道侣系统

道侣是长期剧情羁绊，不是单纯的Buff。

#### 道侣核心规则

- **获取方式**：通过因果回溯卡、红尘线事件、秘境奇遇获得
- **羁绊位**：最多3个道侣（未解情缘也算占用）
- **道侣效果**：
  - 解锁专属道侣事件卡（3-5张）
  - 提供被动属性加成（如白狐+福缘，剑修道侣+剑修卡权重）
  - 触发特定故事线（如妖族道侣触发正魔线）
- **道侣死亡**：
  - 战斗中可能为保护玩家而受伤/死亡
  - 死亡后产生强因果种子（"永失我爱"），影响渡劫
- **多情惩罚**：拥有3个道侣后，会触发"争风吃醋"冲突卡，导致道心下降
- **太上忘情**：道心过高（太上忘情）时，所有道侣自动离开，红尘线关闭

#### 道侣数据字段

```json
  "deathTriggers": ["white_fox_death_karma"]
}
```

### 6. 秘境触发与节点规则

（已在第十四节概述，此处补充运行规则）

#### 秘境运行规则

- **触发入口**：修为达到当前境界70%以上时，卡池中加入秘境入口卡（权重动态）
- **进入选择**：玩家右滑进入，左滑跳过（跳过不扣寿元，但本轮不再出现）
- **节点结构**：3-5层树状节点，每层2-3个分支
- **节点类型**：
  - 战斗：消耗气血，可能获得法宝/灵石
  - 采集：获得丹药材料/灵石，低战斗
  - 休息：恢复气血/道心
  - 事件：触发秘境专属剧情，可能种下因果
  - 商人：用灵石购买/出售
  - Boss：最终战，奖励最丰厚
- **退出机制**：玩家可随时选择"退出秘境"，保留已获奖励的一半；Boss战失败则全部失去
- **与主循环关系**：秘境不推进常规境界修为，但提供大量资源奖励，让玩家回主循环时更强势

### 7. 渡劫Boss战完整规则

（已在第十四节概述，此处作为可执行规格补充）

#### 渡劫流程

```
触发条件: 修为满 + 满足当前境界突破条件
    ↓
进入锁入式渡劫模式
    ↓
连续9张天劫卡(卡牌类型: TRIBULATION)
    ↓
每张卡限时反应:
  - 元婴天劫: 1.5秒
  - 化神九重天劫: 1.2秒
  - 可用渡厄丹延长0.5秒
    ↓
成功处理9张卡 → 突破成功
失败(气血/道心归零或超时3次) → 突破失败
```

#### 天劫卡类型

| 天劫卡类型 | 典型效果 | 推荐应对 |
|------------|----------|----------|
| 劫雷 | 气血-20~40 | 右滑用法宝/上滑阵法 |
| 心魔 | 道心-15~30 | 左滑硬抗（剑修/体修）/右滑清心丹 |
| 业火 | 因果结算，额外扣血 | 下滑遁逃（损失修为） |
| 五行神雷 | 按五行属性，应对错误加倍伤害 | 法修专属卡提示正确方向 |
| 天道拷问 | 重大剧情抉择，影响结局 | 根据善恶倾向选择 |

### 8. 存档系统

- **自动存档**：每次滑动后自动保存，防止意外退出
- **手动存档**：每局可创建1个"天命存档"（内购/看广告解锁额外槽位）
- **中断续玩**：从最后一张卡恢复，状态和卡池一致
- **转世存档**：每次转世创建新存档，旧存档保留为"前世回放"供玩家查看
- **云存档**：TapTap/Steam登录后自动上传（可选）

## 十七、元神分身系统

### 设计决策：不做"同时处理2张卡"

原方案"元婴期同时处理2张卡"存在严重问题：
- **阅读负担爆炸**：玩家需要同时读两张卡的文本和效果
- **UI复杂度飙升**：手机屏幕同时显示两张可滑动卡牌，误触率极高
- **节奏破坏**：王权的核心体验是"读一张卡→做一个决定"，双卡并行会打断这个心流

**最终方案**：元神分身 = **"第二决策选项层"**。在部分卡牌上增加一个消耗性的"元神选项"按钮，既保留"元神出窍"的修仙幻想，又不对核心UI动刀。

### 核心机制

- **解锁条件**：元婴期突破成功
- **资源**：元神能量
  - 初始值：1点
  - 上限：3点
  - 恢复：每3轮恢复1点
  - 转世：不保留
- **表现形式**：元婴期后，约20%的卡牌会额外显示"元神选项"按钮（通过卡牌JSON字段 `yuanshenOption` 标记）
- **消耗**：使用元神选项消耗1点能量；渡劫中使用消耗2点

### 元神选项类型

| 选项 | 效果 | 最佳使用场景 |
|------|------|--------------|
| **化身代受** | 本次卡牌的负面效果由元神承受，主身不扣 | 高压负面卡（如扣30道心） |
| **双生共鸣** | 本次卡牌的正面效果翻倍 | 高收益卡（如+20修为） |
| **灵识预警** | 预览下1张卡的类型/吉凶（信息模糊） | 需要规划资源时 |
| **身外化身** | 额外获得资源（灵石+50 或 丹药+1） | 资源短缺时 |

### 元神选项与功法的交互

| 功法 | 元神选项偏向 |
|------|-------------|
| 剑修 | 双生共鸣概率更高，鼓励高风险高收益 |
| 法修 | 灵识预警信息更明确（可预览下2张） |
| 体修 | 化身代受消耗更低（0.5点能量） |
| 丹修 | 身外化身可获得丹药/延寿材料 |
| 阵修 | 灵识预警可提示天机盘状态变化 |
| 符修 | 身外化身可获得符箓资源 |

### 卡牌JSON扩展

在决策结构中加入 `yuanshenOption`：

```json
{
  "LEFT": { ... },
  "RIGHT": { ... },
  "yuanshenOption": {
    "text": "以元神之力化解",
    "type": "ABSORB_NEGATIVE",
    "energyCost": 1,
    "description": "负面效果由元神承受，主身免疫本次扣减"
  }
}
```

### 元神能量UI

- 在属性条区域上方显示3个元神珠
- 能量满时元神珠发光，提示玩家可以使用
- 能量为0时，元神选项按钮变灰并提示"元神疲惫，需修炼恢复"

### 边缘情况

- **能量不足**：无法使用元神选项
- **渡劫中**：能量消耗翻倍，但渡劫卡必有元神选项（增加容错）
- **转世后**：元神能量从零开始，不继承
- **走火入魔时**：元神选项不可用（道心崩溃无法分神）

## 十八、多结局系统

### 设计原则

- **结局由整个旅程决定**：不是最后一张卡的选择，而是善恶因果、功法选择、道侣情况、天道倾向的综合结果
- **3个主结局 + 3个分支结局 + 2个隐藏/失败结局**：共8个结局，提供重玩价值但不至于让内容量失控
- **每个结局都有解锁奖励**：称号、头像框、新难度、新灵根等

### 结局总表

| 结局 | 类型 | 核心触发条件 | 风格 | 解锁奖励 |
|------|------|-------------|------|----------|
| **正道飞升** | 主结局 | 净善因≥30，道心≥80，天道选择倾向善 | 大圆满，霞光万道 | 解锁"正道真仙"称号 |
| **魔道飞升** | 主结局 | 净恶因≥30，选择逆天而行，功法剑/符/魔道 | 强者为王，血祭登天 | 解锁"魔道巨擘"称号 |
| **红尘兵解** | 分支 | 有道侣且道侣好感≥80，渡劫前选择放弃飞升 | 为爱转世，不慕长生 | 解锁"痴仙"称号，道侣系统新皮肤 |
| **因果归一** | 分支 | 净善因-5~5，道心≥80，无未了因果 | 超脱善恶，万法归空 | 解锁"因果道人"称号，混沌灵根获取加速 |
| **天道傀儡** | 分支 | 化神期后连续3次选择完全顺从天道 | 悲剧，发现天道真相 | 解锁"天道棋子"称号，天道线二周目剧情 |
| **永堕轮回** | 失败 | 渡劫失败且未了因果≥20 | 失败，因果缠身 | 无奖励，但触发"轮回图鉴"失败记录 |
| **混沌真解** | 隐藏 | 收集全部混沌碎片（多周目），触发天道线真结局 | 世界真相，揭开修仙界本源 | 解锁最强灵根"混沌灵根" |
| **逆天成圣** | 隐藏 | 全恶因通关（净恶因≥50），击败天道化身 | 终极挑战，以力证道 | 解锁"逆天圣者"称号，无尽轮回最终难度 |

### 结局判定流程

```
渡劫成功
  ↓
触发"天道拷问"最终卡（1张决定性卡牌）
  ↓
系统计算结局分数:
  - 善因分 = 净善因 × 1.5
  - 恶因分 = 净恶因 × 1.5
  - 道心分 = 道心值
  - 天道倾向分 = 化神期天道选择累积
  - 道侣分 = 有道侣且好感高 +20
  - 混沌碎片 = 每片 +10（仅影响混沌真解）
  ↓
按优先级匹配结局:
  1. 混沌碎片全收集 → 混沌真解
  2. 净恶因≥50 → 逆天成圣
  3. 净善因≥30 → 正道飞升
  4. 净恶因≥30 → 魔道飞升
  5. 天道倾向全善/全恶 → 天道傀儡（根据倾向）
  6. 有道侣且放弃飞升 → 红尘兵解
  7. 净善因-5~5且道心≥80 → 因果归一
  8. 渡劫失败 → 永堕轮回
  ↓
播放结局CG/文本 + 解锁奖励 + 进入轮回图鉴
```

### 结局CG与文本

每个结局包含：
- 1张结局插画（AI生成，风格统一）
- 200-300字结局文本
- 1个解锁称号/头像框
- 成就触发提示

### 轮回图鉴

- 在主界面/转世界面可查看
- 显示已达成结局和未达成结局的达成条件（模糊提示，不完全剧透）
- 提供"再走一遭"按钮，快速开始新一局

### 结局与Meta解锁

| 达成结局数 | 解锁内容 |
|------------|----------|
| 1个 | 开启"轮回图鉴" |
| 3个 | 解锁"异灵根" |
| 5个 | 解锁"无尽轮回"模式 |
| 7个 | 解锁"混沌灵根" |
| 全8个 | 解锁"天道行者"终极称号 + 隐藏NPC |

## 十九、飞升后内容

### 设计定位

飞升不是终点，而是**"当前轮回的毕业"**。飞升后提供Meta成长和新的挑战，但本体内不扩展"上界仙界"内容（避免开发量爆炸）。上界作为明确的DLC/续作方向。

### 三层飞升后内容

#### 层1：本体内Meta解锁（即时生效）

每次飞升（任意结局）后：
- 结局加入轮回图鉴
- 解锁对应称号和头像框
- 解锁新难度等级：普通 → 困难 → 炼狱 → 天道
- 解锁新的灵根外观/功法皮肤（纯视觉，不改变数值）
- 根据结局类型解锁特殊初始加成：
  - 正道飞升：初始善因+5
  - 魔道飞升：初始恶因+5
  - 红尘兵解：道侣出现概率+10%
  - 因果归一：初始因果上限+5

#### 层2：无尽轮回模式（通关任意结局后解锁）

- **概念**：更高难度的"爬塔式"轮回挑战
- **规则**：
  - 从炼气期开始，但属性波动+30%
  - 因果种子发芽延迟缩短20%
  - 渡劫反应时间缩短20%
  - 每通关一个无尽轮回，获得"仙缘点"
- **仙缘点商店**：
  - 初始灵石+20（50仙缘点）
  - 初始寿元+10（80仙缘点）
  - 初始丹药栏+1（100仙缘点）
  - 初始法宝栏+1（150仙缘点）
  - 元神能量上限+1（200仙缘点）
  - 解锁隐藏灵根"废灵根"（通关3次）

#### 层3：上界DLC / 续作（未来扩展，不纳入本体）

作为明确的续作方向，预留设计但不开发：
- 新境界：地仙 → 天仙 → 金仙 → 大罗
- 新系统：仙界宗门、界域战争、上界因果、仙职晋升
- 新结局：超脱天道 / 以身合道 / 开辟新界
- 传承系统：以上界仙人身份影响下一世下界轮回

### 飞升、兵解与转世的区别

| 事件 | 触发 | 效果 | 性质 |
|------|------|------|------|
| **飞升** | 渡劫成功 + 达成结局条件 | 通关，解锁Meta奖励 | 胜利 |
| **兵解** | 渡劫成功但选择放弃飞升 | 进入下一世，但保留全部记忆和部分属性 | 特殊结局/转生 |
| **转世** | 死亡或渡劫失败 | 部分保留，重置大部分进度 | 失败/重来 |
| **无尽轮回** | 通关后主动挑战 | 更高难度，赚取仙缘点 | 挑战模式 |

### 飞升后界面的核心信息

飞升结算界面显示：
- 本次结局名称
- 本局关键数据：存活轮数、善恶因统计、功法、道侣、因果链完成度
- 解锁奖励列表
- 三个按钮：
  - 「再修一世」（开始新游戏）
  - 「无尽轮回」（如果已解锁）
  - 「轮回图鉴」（查看成就）
