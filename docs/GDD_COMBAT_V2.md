## 1. 设计支柱

| 支柱 | 说明 | 衡量标准 |
|------|------|----------|
| 危险感 | 每场战斗都像走钢丝——灵力是命，格挡是本能 | 玩家在战斗中感到压力 ≥70% 回合 |
| 修为可见 | 我在坊市买的法宝、我苦修的道心……全都在战斗中看得见 | 每个参数至少 1 种战斗体现 |
| 巧技胜蛮力 | 不是拼数字，是拼手指和脑子 | 格挡时机窗口 → 技术好的玩家减伤比例 >60% |
| 法宝有魂 | 装备不只是 +5 ATK，而是改变战斗方式 | 每件法宝至少 1 个战斗动词 |

## 2. 六层架构概览

```
┌──────────────────────────────────────────┐
│ L1 灵力脉冲 Qi Pulse      — 消耗/回复节奏  │
│ L2 架势切换 Stance        — 攻/守/破三态   │
│ L3 格挡时机 Active Block  — 敌方攻击时操作  │
│ L4 连击链 Combo Chain     — 势层→终结技     │
│ L5 参数整合 Params        — 全部属性有存在感 │
│ L6 法宝动词 Equipment     — 法宝提供新按钮   │
└──────────────────────────────────────────┘
```

## 3. L1: 灵力脉冲 Qi Pulse

### 机制
- **灵力量 (maxQi)**: `floor(cultivation / 10) + 3`，范围 3~12
- **消耗**: 攻击 -1灵 / 技能 -3灵 / 防御 -0灵 / 法宝 -1~3灵
- **回复**: 每回合自动 +1灵
- **枯竭状态**: 灵力=0 时，只能「调息」(+2灵, 但本回合 DEF-50%)
- **溢出回复**: 守架势下 +2灵/回合

### 设计意图
防止"每回合都用最强技能"的无脑循环。强制"攒→放→调→放"的呼吸节奏。

## 4. L2: 架势切换 Stance

### 三种架势

| 架势 | ATK修正 | DEF修正 | 特殊效果 |
|------|---------|---------|----------|
| 攻 | +30% | -20% | 暴击率+10% |
| 守 | -30% | +50% | 灵力回复+1/回合 |
| 破 | +10% | +0% | 无视敌方架势增益 |

### 规则
- 切换不消耗回合（可在动作前自由切换）
- 敌人也有架势 → 破架势价值体现在"敌人守架势时你切破"

---

## 5. L3: 格挡时机 Active Block

### 机制
- 敌人出招时 → 屏幕中央出现格挡提示框、闪光、时间条
- **时间窗口**: 快攻 0.3s / 普通 0.6s / 重击 1.0s（由敌人速度属性决定）
- **判定**:
  - 窗口前30%内点击: **完美格挡** — 0伤害 + 敌方硬直1回合
  - 窗口内点击: **格挡** — 减伤80%
  - 未点击: **未格挡** — 全额伤害
- **兼容性**: 可与"防御"指令叠加（先减伤50%再格挡80% = 10%伤害）

### 设计意图
这是核心交互——把"看敌人打你"变成"你的手指正在救你的命"。

## 6. L4: 连击链 Combo Chain

### 机制
- **势 (Momentum)**: 连续命中敌人+1层，被击中归零，防御归零，调息归零
- **势 = 1-2**: 伤害+10%
- **势 = 3**: 解锁终结技（替换普通技能按钮）
- **势 ≥ 4**: 终结技伤害+20%

### 四功法终结技

| 功法 | 终结技名 | 效果 | 灵力消耗 |
|------|----------|------|----------|
| 剑修 | 万剑归宗 | ATK×3.0, 无视防御 | 3 |
| 法修 | 天雷破 | ATK×2.5, 追加2回合麻痹 | 4 |
| 体修 | 金刚不坏 | 2回合无敌 + 反击1次 | 2 |
| 丹修 | 万毒噬心 | ATK×2.0 + 敌方中毒(3回合) | 3 |

## 7. L5: 参数深度整合

### 每个属性在战斗中的映射

| 属性 | 战斗体现 | 公式 |
|------|----------|------|
| cultivation (修为) | 灵力量/基础伤害 | maxQi = cultivation/10+3, ATK += cultivation/8 |
| daoHeart (道心) | 暴击率/恐惧抵抗 | crit += daoHeart/10, 免疫"恐惧"状态阈值 |
| health (气血) | HP/恢复 | maxHP = health×3, 回合恢复 = health/20 |
| fortune (气运) | 随机天助 | fortune/100 概率触发"天助一击"(+50%伤害) |
| karmaGood (善业) | 天谴豁免 | 善业>100 → 死亡时50%概率复活至HP=1 |
| karmaBad (恶业) | 禁忌爆发 | 恶业>50 → 低血时触发"魔化"(伤害×2, 但扣道心) |
| lifespan (寿元) | 战斗代价 | 战斗失败扣3年, BOSS战扣1年 |

### 现有法宝重新设计

| 法宝 | 类型 | 战斗动词 | 灵耗 | 冷却 |

| 玄铁甲 | 防具 | 「铁壁」2回合 DEF×2 | 2 | 5回合 |
| 灵泉葫芦 | 恢复 | 「饮泉」回复15HP +1灵 | 0 | 3回合 |
| 剑心佩 | 武器 | 「剑气」远程先手(无视敌方格挡) | 1 | 2回合 |
| 避尘珠 | 挂件 | 「辟邪」抵消1次敌方特殊技 | 0 | 4回合 |
| 血玉扳指 | 武器 | 「血爆」伤敌2×ATK, 自伤15HP | 0 | 3回合 |

- 武器槽 ×1: 决定"攻击"按键的形态(斩/刺/轰)
- 防具槽 ×1: 决定"防御"按键的强化效果
- 挂件槽 ×1: 提供 1 个特殊技能按钮
- 消耗品槽 ×1: 提供 1 次性战斗技能

## 10. 平衡性数值表 (Tuning Sheet)

### 伤害公式
```
基础伤害 = max(1, ATK × 架势修正 - DEF × 穿透)
暴击伤害 = 基础伤害 × 1.5 (剑修终结技 ×2.0)
最终伤害 = 暴击伤害 × 随机浮动(0.85~1.15)
```

### 建议属性成长曲线

| 境界 | 修为范围 | 灵力量 | 基础ATK | 建议HP | 敌人ATK范围 |
|------|----------|--------|---------|--------|------------|
| 炼气 | 10-30 | 4-6 | 8-15 | 50-80 | 10-20 |
| 筑基 | 30-60 | 6-8 | 15-25 | 80-150 | 15-30 |
| 金丹 | 60-100 | 8-10 | 25-40 | 150-250 | 25-45 |
| 元婴 | 100-160 | 10-12 | 40-60 | 250-400 | 40-60 |
| 化神 | 160-250 | 12-15 | 60-85 | 400-600 | 55-80 |
| 渡劫 | 250-400 | 15-20 | 85-120 | 600-900 | 75-110 |

### 战斗回合数目标
- 普通小怪: 3-5 回合
- 精英怪: 5-8 回合
- Boss 战: 8-15 回合

## 11. 与剧情系统的融合

### 战斗触发节点 (融入已有的 120 张核心卡)

- **炼气期**: 妖兽遭遇(随机卡) + 同门切磋(关系事件)
- **筑基期**: 妖兽·烈焰虎(Boss卡) + 筑基后→解锁坊市(买装备备战金丹)
- **金丹期**: 心魔·自我镜像 + 势力冲突(根据已选择的势力)
- **元婴期**: 天劫·雷兽 + 因果回响(过去放过的NPC是否来复仇?)
- **化神期**: 血煞宗围攻 + 道侣保护战
- **渡劫期**: 天道监察者 + 最终选择

### 战力影响剧情
- 战斗胜利时的击杀/饶恕选择 → 影响 karmaGood/karmaBad
- NPC对决输赢 → 影响 NPC 好感弧线
- Boss战结果 → 决定能否进入下一境界
