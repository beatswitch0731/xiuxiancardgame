## 1. 设计支柱

以下四条是"一念仙途"不可妥协的核心体验。每一个设计决策必须对照这四条检验。

### 支柱 1：每一次滑动都是一次抉择
> 玩家不是在"选最优解"——而是在两个都有代价的选项中，选择自己愿意承受的后果。

- 没有纯正面卡。每张卡的两个选项都包含 **风险/收益不对称**。
- 拒绝"左边加修为、右边加灵石"的无脑选择。
- 每一张卡的选项应迫使玩家考虑：*我在乎什么？我愿意失去什么？*

### 支柱 2：因果不虚，报应不爽
> 你在炼气期做的一件小事，会在金丹期结出果子——好人未必好报，恶人也未必遭殃，但一切都有迹可循。

- 因果系统是游戏的叙事脊梁，不是数值系统。
- 因果种子延迟 5-20 轮才发芽，制造"忘了但突然回来"的冲击力。
- 因果闭环必须有叙事逻辑，不是随机。

### 支柱 3：修仙的本质是选择"成为谁"
> 剑修、法修、体修、丹修——不只是数值差异，而是四种不同的修仙哲学和世界观。

- 不同功法走的剧情线不同、遇见的人不同、面临的道德困境不同。
- NPC 对你的态度因功法而异：同样的白刃真人，面对剑修弟子和丹修弟子，说的话不一样。
- 同一个事件在不同功法视角下可能有完全不同的解读。

### 支柱 4：死亡不是结束，是另一种推进
> 每一次死亡都应该让玩家获得新的知识或解锁——转世是 meta-progression 的载体，不是惩罚。

- 至少 6 种死亡方式，各有独特 flavor text 和可能的解锁。
- 转世保留部分进度，但解锁新选项（新功法、新 NPC、隐藏剧情线）。
- 飞升是最难的结局，也是最高成就——但玩家可以选择不飞升。

## 2. 核心循环

### 2.1 时刻循环（10-30秒）

```
┌──────────────────────────────────────────────┐
│                                              │
│   抽卡 (CardSystem.draw)                     │
│     ↓                                        │
│   展示卡牌 → 阅读描述 → 选择方向             │
│     ↓                                        │
│   应用效果 + 种因果 + 推进支线               │
│     ↓                                        │
│   检查死亡 → 更新 UI → 下一张卡              │
│                                              │
└──────────────────────────────────────────────┘
```

**玩家心理**: "两张卡……左边风险大但收益高，右边稳妥但有隐藏代价。选哪个？" — 这是一个 3-10 秒的抉择时刻，核心体验。

### 2.2 会话循环（5-20分钟 = 一局）

- **开局（0-5轮）**: 选功法 → 初始加成一波 → 熟悉基础卡。
- **攀升（5-30轮）**: 境界突破 × 3-5 次 → 卡池升级 → NPC 关系建立 → 支线触发。
- **危机（30-50轮）**: 资源压力增大 → 死亡风险上升 → 高阶选择后果浮现。
- **终局（50-80轮）**: 要么死亡，要么飞升。死亡后立即看到转世选项。

### 2.3 长期循环（多局 = 转世链条）

- **第 1 局**: 探索 → 死亡 → 学习。
- **第 2-3 局**: 尝试不同功法 → 解锁更多结局 → 转世加成累积。
- **第 5+ 局**: 解锁隐藏功法/剧情 → 追求完美飞升 → 全结局收集。

## 4. 卡牌引擎

### 4.1 9 级优先级抽卡

每次 `draw()` 按以下优先级遍历，找到第一张满足条件的卡：

| 优先级 | 类型 | 触发条件 | 说明 |
|--------|------|---------|------|
| 100 | 死亡卡 | `gameState.dead === true` | 玩家已死，展示结局 |
| 90 | 瓶颈卡 | `cultivation >= threshold` | 突破或失败 |
| 80 | 支线当前卡 | 支线进行中 | 链式推进 |
| 70 | 支线入口卡 | 支线可触发 | 新支线开始 |
| 60 | 因果卡 | 种子 delay ≤ 0 | 因果发芽 |
| 50 | 道侣事件卡 | 概率触发 | 随机社交事件 |
| 40 | 势力暗流卡 | 概率触发 | 世界动态事件 |
| 30 | NPC 遭遇卡 | 概率触发 | 双 NPC 互动 |
| 10 | 普通卡 | 默认 | 权重随机 |

### 4.2 普通卡权重算法

```
weight = card.baseWeight × pathAffinity(×1.5) 
       + fortuneBonus(+2 if fortune>70 & !risk)
       × demonAffinity(×1.3 if karmaBad>50 & demon tag)
```

- 基础权重: 1-10（数据配置）
- 最近 8 张已玩卡进入冷却
- 一次性卡 (`once: true`) 永久过滤
- 功法/境界/flag 条件过滤

### 4.3 卡牌数据结构

```javascript
{
  id: "q_sword_training",        // 唯一ID
  type: "NORMAL",                 // NORMAL|BOTTLENECK|KARMA|QUEST|DUNGEON|DESTINY

  description: "白刃真人在演武场等你。晨光透过剑锋，映出一道寒芒。",
  realm: "qi",                    // 所属境界
  path: "sword",                  // 功法要求 (null=通用)
  weight: 5,                      // 基础权重
  once: false,                    // 一次性
  tags: ["training", "mentor"],   // 标签
  requiresFlags: {},              // 前置flag条件
  forbiddenFlags: {},             // 禁止flag条件
  choices: {
    left: {
      text: "认真修炼",
```

## 5. 属性与资源

### 5.1 核心属性 (0-100)

| 属性 | 初始值 | 最低死亡 | 最高死亡 | 含义 |
|------|--------|---------|---------|------|
| cultivation | 10 | — | — | 修为：满则触发瓶颈，突破提升境界 |
| daoHeart | 50 | 0 | — | 道心：为 0 走火入魔而死 |
| karmaGood | 0 | — | 100 | 善因：满 100 羽化登仙（意外死亡） |
| karmaBad | 0 | — | 100 | 恶因：满 100 天劫临身而死 |
| fortune | 50 | 0 | — | 福缘：为 0 天诛地灭而死 |
| health | 100 | 0 | — | 气血：为 0 身死道消 |

**设计意图**: 六个属性构成 3 对张力：
- `cultivation` ↔ `daoHeart`：追求修为可能伤道心
- `karmaGood` ↔ `karmaBad`：善恶对立，两端都是死
- `fortune` ↔ `health`：冒险求机缘可能损气血

当一个属性逼近死亡阈值时，玩家行为应发生明显偏转——"我快道心崩碎了，得找个安全选项"——这就是张力。

### 5.2 资源

| 资源 | 初始值 | 上限 | 来源 | 消耗（需补） |
|------|--------|------|------|-------------|
| spiritStone | 20 | — | 卡牌奖励 | **[无消耗]** |
| lifespan | 80 | — | 初始 + 转世加成 | 战斗卡/受伤减寿元 |
| pills | {} | — | 卡牌获取/炼丹 | 突破时自动消耗 |
| treasures | [] | — | 卡牌获取 | **[未使用]** |
| companions | [] | — | 卡牌选择 | 关系系统 |

**关键缺口**: 灵石和法宝有获取无消耗 → 需要设计消耗途径。

## 6. 功法系统

### 6.1 四种功法

| 功法 | 核心 fantasy | 属性加成 | 风险倾向 | 专属 NPC |
|------|-------------|---------|---------|----------|
| **剑修** sword | 一剑破万法 | cultivation+5, daoHeart+5 | 高风险高回报 | 白刃真人、剑灵儿 |
| **法修** spell | 道法自然 | cultivation+5, fortune+3 | 中庸平衡 | 天机老人 |
| **体修** body | 肉身成圣 | health+20, daoHeart+3 | 低风险稳健 | 殷血、血煞老祖 |
| **丹修** pill | 药石通天 | fortune+5, pills+1 | 资源管理型 | 慕青岚 |

### 6.2 功法差异化设计（需实现）

**当前状态**: 功法选择只影响初始加成和卡牌权重 ×1.5。

**设计目标**: 每种功法应有独特性格——

| 维度 | 剑修 | 法修 | 体修 | 丹修 |
|------|------|------|------|------|
| 卡牌倾向 | 战斗/历练 | 探索/悟道 | 淬体/忍耐 | 采集/交易 |
| 死亡方式 | 高风险多 | 均衡 | 低风险 | 资源耗尽 |
| NPC态度 | 白刃收徒严 | 天机指引 | 殷血认同 | 慕青岚合作 |
| 势力归属 | 青云剑宗 | 天枢道院 | **武盟(缺)** | **药王谷(缺)** |
| 专属支线 | 论剑之争 | **天枢秘典(缺)** | **肉身渡劫(缺)** | **药王传承(缺)** |

### 6.3 功法技能树（待实现）

每个功法应有 5-8 个被动/主动技能，境界突破时解锁。

**示例 —— 剑修技能树**:
```
炼气 → 剑心通明 (被动: 剑系卡权重+2)
筑基 → 剑气护体 (被动: 战斗受伤-20%)
金丹 → 人剑合一 (主动: 战斗可选"全力一击"第三选项)
元婴 → 剑域展开 (被动: 道侣事件概率+10%)
化神 → 无剑之境 (主动: 可跳过瓶颈卡一次)
```

> 当前版本: 功法技能树 **完全缺失**。建议 v0.3 引入简化版（每功法 3 技能）。

## 9. 道侣系统

### 9.1 三维关系模型

```
好感度 (Affection):  0-100  喜欢你有多深
羁绊   (Bond):       0-100  共同经历多少事
信任   (Trust):      0-100  是否相信你不会背叛
```

### 9.2 道侣事件触发

- 好感度 ≥ 70 时进入道侣候选池
- 每 8-15 轮触发一次道侣事件（优先级 50）
- 事件权重: 好感度 × 0.5 + 羁绊 × 0.3 + 信任 × 0.2

### 9.3 情劫/危机事件（待激活）

代码已实现（CompanionSystem._onHeartEvent）但从未被调用。

```
触发条件: 好感度 ≥ 80 且 善恶值发生剧烈变化(±20)
事件类型:
  - 善因危机: NPC 阻止你做坏事，考验关系
  - 恶因危机: NPC 受你恶行影响，面临背叛抉择
  - 信任危机: 随机事件考验信任值
```

> **当前**: 373 行死代码。需设计触发时机和事件内容。

### 10.2 势力声望

|---------|------|
| -100 ~ -40 | 敌对：该势力 NPC 拒绝交互 |

### 10.3 暗流机制

暗流是势力内部的动态事件链，随声望变化推进：

```
阶段 0 (声望 0-20)  → "山雨欲来" 卡
阶段 1 (声望 20-40) → "明争暗斗" 卡
阶段 2 (声望 40-60) → "剑拔弩张" 卡
阶段 3 (声望 60-80) → "决战时刻" 卡（决定结局）
```

**缺口**: 当前仅 sword/青云剑宗有暗流。需补 spell、body、pill 各一个。

## 11. 支线与因果

### 11.1 支线设计原则

每条支线必须满足：
1. **功法专属 × 2 条**: 只有选择该功法的玩家能触发
2. **通用 × 2 条**: 任何功法可触发，但选择可能因功法而异
3. **3-5 卡链**: 不过长（避免打断主线），不过短（有叙事重量）
4. **有因果种子**: 完成后种下种子，后续产生连锁反应

### 11.2 支线路线图

| # | 支线 | 功法 | 卡数 | 状态 |
|---|------|------|------|------|
| 1 | 白狐报恩 | 通用 | 3 | ✅ 已实现 |
| 2 | 药王传承 | pill | 3 | ⚠️ 数据已有需补 |
| 3 | 论剑之争（暗流） | sword | 4 | ✅ 已实现 |
| 4 | 天枢秘典 | spell | 4 | ❌ 缺 |
| 5 | 肉身渡劫 | body | 4 | ❌ 缺 |
| 6 | 九尾真相 | 通用 | 5 | ❌ 缺 |
| 7 | 血煞之路 | body | 4 | ❌ 缺 |
| 8 | 剑灵儿往事 | sword | 3 | ❌ 缺 |

### 11.3 因果种子设计

```
种子生命周期:
  播种(玩家选择) → 休眠(delay 轮) → 发芽(delay=0) → 抽卡(优先级60) → 闭环(新选择)

种子类型:
  - 善因种子: 好事的结果（可能好也可能坏）
  - 恶因种子: 坏事的报应（可能来也可能不来）
  - 中性种子: 随机事件的后续发展
```

**当前因果映射**: 仅 1 条（whiteFox → q_karma_fox）。目标: 至少 20 条因果映射。

## 12. 秘境探险

### 12.1 当前实现

### 12.2 设计目标（v0.3+）

每个秘境应有：
- **路线选择**: 每节点 2-3 条可选路线（"走左侧洞窟" vs "穿过大殿"）
- **风险梯度**: 高风险路线 = 高奖励 + 高受伤概率
- **功法优势**: 剑修在战斗秘境有加成，丹修在草药秘境有加成
- **秘境 Boss**: 最终节点有概率遇到 Boss（触发战斗）

## 13. 死亡与转世

### 13.1 六种死亡方式

| # | 死因 | 触发条件 | 结局 flavor | 转世解锁 |
|---|------|---------|------------|---------|
| 1 | 道心崩碎 | daoHeart ≤ 0 | "道心崩碎，走火入魔" | 无 |
| 2 | 气血耗尽 | health ≤ 0 | "气血耗尽，身死道消" | 体修功法加成 |
| 3 | 厄运缠身 | fortune ≤ 0 | "厄运缠身，天诛地灭" | 无 |
| 4 | 善因过满 | karmaGood ≥ 100 | "善因过满，羽化登仙" | 天枢道院声望 |
| 5 | 恶贯满盈 | karmaBad ≥ 100 | "恶贯满盈，天劫临身" | 血煞老祖线解锁 |
| 6 | 寿元耗尽 | lifespan ≤ 0 | "寿元耗尽，坐化而终" | maxLifespan+5 |
| 7 | 渡劫飞升 | 渡劫成功 | "渡劫成功，飞升成仙" | 最高成就 |

### 13.2 转世加成

```
上一局达到的境界 → startCultivation +3
上一局存活超过30轮 → startSpiritStone +5
上一局达到筑基或金丹 → maxLifespan +5
```

### 13.3 转世 v2.0 设计（待实现）

当前转世纯数值加成，缺乏选择深度。目标：

```
转世时可选"保留项"（3选1）:
  1. 保留一种法宝（带全部属性）
  2. 保留与一位 NPC 的关系值（50%）
  3. 保留一项功法技能

转世流派:
  - 轮回者: 保留最多 → 但难度增加
  - 清零者: 完全重置 → 获得独特开局 buff
  - 夺舍者: 选择不同身份开局 → 解锁隐藏剧情
```

## 14. 战斗系统（待实现）

### 14.1 设计原则

"一念仙途"的战斗不是动作游戏——它是**抽象化的博弈选择**。玩家不控制角色出招，而是在战斗卡的选择中体现战术。

### 14.2 战斗卡模型

```
战斗卡触发条件:
  - 卡牌 tags 包含 "combat"
  - 秘境 Boss 节点
  - 暗流最终阶段
  - 随机遭遇（优先级 35，低于 NPC 但高于普通卡）

战斗卡结构:
{
  type: "COMBAT",
  enemy: { name, hp, atk, def, rewards },
  choices: {
    left:  { text: "正面迎击", tactic: "aggressive" },
    right: { text: "以退为进", tactic: "defensive" },
    // 功法专属第三选项
    up:    { text: "剑气纵横", tactic: "sword_special" }
  }
}
```

### 14.3 战斗公式（草案）

```
基础伤害 = 攻方攻击力 - 守方防御力 (最低 1)
暴击率 = 功法加成 + 福缘 × 0.1
暴击伤害 = 基础伤害 × 1.5

剑修: atk+30%, def-20% → 高攻脆皮
法修: atk+10%, 暴击率+15% → 法术精准
体修: hp+50%, atk-10%, def+20% → 厚血肉盾
丹修: 可使用丹药瞬回HP → 资源消耗型
```

### 14.4 战斗奖励

| 结果 | 奖励 |
|------|------|
| 完胜（HP ≥ 80%） | 灵石×5, 丹药×1 |
| 险胜（HP < 50%） | 灵石×3 |
| 惨胜（HP < 20%） | 灵石×1, 道心+3（磨砺） |
| 战败 | 寿元-3, 道心-5 |

## 16. 玩家动机层

### 16.1 动机结构

```
短期 (单局内):
  → 突破下一个境界
  → 与喜欢的 NPC 提升关系
  → 完成一条支线
  → 活得更久

中期 (2-5局):
  → 尝试不同功法
  → 解锁更多 NPC/结局
  → 发现因果链条全貌

长期 (5+局):
  → 全结局收集（成就）
  → 全道侣羁绊满级
  → 发现隐藏功法/剧情线
  → 完美飞升（最难结局）
```

### 16.2 "再来一局" 钩子

| 钩子 | 触发时机 | 心理驱动 |
|------|---------|---------|
| "如果刚才选右边……" | 死亡后立即 | 好奇心 |
| 新功法解锁 | 达到某境界后 | 探索欲 |
| NP C 秘密 | 好感度 70+ | 角色依恋 |
| 因果"原来是这样" | 种子发芽时 | 叙事满足 |
| 转世加成 | 死亡结算 | 进度不丢失 |

### 16.3 缺失的动机要素

- **成就系统**: 无。需要 "全结局"、"全道侣"、"无伤飞升" 等成就。
- **每日/赛季内容**: 无。适合后续迭代。
- **难度曲线**: 无。转世后难度不变，缺乏挑战性递增。
- **玩家身份**: 无法命名/自定义角色。开局缺少代入感建立。
