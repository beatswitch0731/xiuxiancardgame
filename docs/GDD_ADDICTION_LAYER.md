# 上瘾引擎 v1.0 设计文档 (GDD)

> 版本:1.0 | 日期:2026-06-28 | 作者:GameDesigner | 状态:DRAFT
>
> **前提**: 此文档解决当前游戏"内容丰富但留不住人"的核心问题。六钩子系统可在不改动现有卡牌内容的前提下逐层叠加。

---

## 0. 设计支柱

| 支柱 | 心理学原理 | 实施原则 |
|------|-----------|----------|
| **不确定性渴望** | 变率奖励 VR-5 | 玩家永远不知道下一张命盘翻出什么——但知道必定有回报 |
| **沉没成本锚定** | 损失厌恶 + 禀赋效应 | 突破89%时关机？你辛辛苦苦攒的修为就悬在那里 |
| **收集强迫症** | 齐加尼克效应 + 进度可见性 | 传承残卷 7/8 → 大脑会一直想着那最后一片 |
| **独特性幻觉** | 自我叙事 + 选择正当化 | "我放过的那个人后来成了我的贵人——你的故事呢？" |
| **惊险快感** | 差点成功效应 | 3%天机卡和心魔反噬都是"差一点"的重演 |

## 2. 钩子 1: 命盘轮转 — 核心变率奖励

### 2.1 触发机制

```
counter = 0
每次玩家滑动一张卡:
  counter++
  if counter % 10 == 0:
    暂停正常卡牌流
    播放"天机涌动"转场动画
    展示 5 张覆面天机牌
    玩家选一张翻看 → 获得奖励
    恢复卡牌流
```

### 2.2 奖励分布 (VR-5 强化表)

命盘奖励池按稀有度分层，算法保证**绝对不是每次都给好东西**——给好东西的频率刚好是不确定的：

| 稀有度 | 比例 | 示例奖励 | 玩家反应 |
|--------|------|----------|----------|
| 传说 (金) | 5% | 龙脉印记: 永久+20%战斗伤害 | 🤯 极度惊喜 |
| 史诗 (紫) | 15% | 混元石: 下次突破+15%概率 | 😮 非常开心 |
| 稀有 (蓝) | 30% | 剑心佩碎片: 传承残卷+1 | 🙂 不错 |
| 普通 (白) | 45% | 灵石袋: +500灵石 | 😐 还行 |
| 空卦 | 5% | 天命未显，下次必定非空 | 🤨 下次一定好 |

**关键心理学**: 空卦 5% 的存在是为了让传说 5% 更甜。如果每次都给好东西，多巴胺会适应性下降。

### 2.3 5 张覆面牌的构成算法

```
function generateDestinyDeck():
  pool = shuffle(全部奖励池)
  // 保证至少 1 张稀有以上
  guaranteed = random([稀有, 史诗, 传说], weights=[0.5, 0.35, 0.15])
  deck = [guaranteed]
  deck += pool.random(4) // 其余随机
  return shuffle(deck)   // 打乱位置
```

玩家永远不知道那 1 张保证稀有以上的牌藏在哪个位置——**五选一的焦虑与期待就是钩子**。

### 2.4 坊市扩展

| 坊市物品 | 价格 | 效果 |
|----------|------|------|
| 命盘密钥 | 2000 灵石 | 下次命盘可翻 2 张（取较好的） |
| 天机罗盘 | 5000 灵石 | 命盘稀有保底提升至史诗 |

## 3. 钩子 2: 心魔反噬 — 损失恐惧

### 3.1 触发机制

```
当玩家突破失败 (breakthrough failed):
  暂停正常流
  展示"心魔滋生"特效 (屏幕边缘暗红侵蚀)
  弹出心魔卡，三选一:
```

### 3.2 三个选项

| 选项 | 效果 | 隐藏代价 |
|------|------|----------|
| **接受心魔** | 恶业 +10, 修为 +5, 下次突破概率 +10% | 恶业路线展开，后续遭遇天魔卡 |
| **抵抗心魔** | 道心 -3, 修为 +2 | 连续抵抗 3 次解锁"心如铁石"成就 |
| **暂时封印** | 无即时效果 | 封印累计 5 次后集体爆发 (魔劫事件) |

### 3.3 为什么这让人上瘾

失败不是终点而是新的起点。突破失败的沮丧被转化为"我选哪一个"的决策快感。而且**每个选项都有代价**——没有免费午餐——制造真实的焦虑感。

### 3.4 与战斗系统的联动

```
当玩家修为 ≥ 突破阈值的 90%:
  如果有"心魔丹" → 可选择服用，降低心魔出现概率 30%
  如果师尊传承值 ≥ 50 → 触发"护体"，心魔反噬选项变为:
    接受心魔 (修为+8, 恶业+5 减半)
    师尊训诫 (道心 +2, 但传承值 -10)
    暂时封印 (同原版)
```

## 4. 钩子 3: 传承残卷 — 收集驱动

### 4.1 掉落机制

每张普通卡牌滑动后，有概率掉落残卷碎片：

| 稀有度 | 掉落率 | 视觉效果 |
|--------|--------|----------|
| 金质残卷 | 2% | 金色闪光 + 震动 |
| 紫质残卷 | 8% | 紫色光晕 |
| 蓝质残卷 | 20% | 蓝色微光 |
| 白质残卷 | 35% | 普通掉落 |

### 4.2 传承套装

每套传承 = 8 片残卷。集齐后合成：

| 传承名称 | 关联玩法 | 合成效果 |
|----------|----------|----------|
| 剑心传承 | 剑修路线 | 解锁被动 "剑意": 每场战斗首回合 ATK×1.5 |
| 丹道传承 | 炼丹路线 | 解锁被动 "丹眼": 丹药效果 +25% |
| 阵道传承 | 阵法路线 | 解锁被动 "阵心": 可布置一座防御阵 |
| 天书残页 | 通用 | 揭示一条隐藏剧情线 |
| 妖皇血脉 | 战斗/恶业路线 | 解锁被动 "妖化": 战斗中可短暂变身 |
| 仙尊遗志 | 道心路线 | 解锁被动 "天佑": 道心不会因失败而降低 |

### 4.3 收集进度可视化

在"传承图鉴"界面展示：

```
剑心传承 ████████░░ 7/8  你在寻找最后一片...
丹道传承 ██░░░░░░░░ 2/8  刚刚开始
阵道传承 ██████████ 8/8  ✓ 已合成
```

**剩余 "1 片" 的焦虑 = 最高强度的上瘾钩子**。

### 4.4 战斗掉落扩展

```
战胜精英怪: 必定掉落 2~4 片残卷 (高稀有度概率翻倍)
战胜 Boss:   必定掉落 1 片传说/史诗 + 3 片随机
战胜小怪:    20% 概率掉落 1 片
```

## 5. 钩子 4: 突破倒计时 — "再玩一把"

### 5.1 始终可见的进度条

```
┌─────────────────────────────────────────────┐
│  🔥 金丹突破进度  ████████████░░░░░  87%    │
│  距离突破还需约 3~4 张卡                     │
└─────────────────────────────────────────────┘
```

### 5.2 视觉反馈阶梯

| 进度 | 视觉效果 |
|------|----------|
| 0-50% | 灰色进度条，无特效 |
| 50-75% | 进度条变蓝，微微发光 |
| 75-90% | 进度条变紫，脉冲动画 |
| 90-99% | 进度条变金，剧烈闪烁 + 屏幕边缘金光 |
| 100% | 全屏金光炸裂 → 突破卡弹出 |

### 5.3 为什么有效

进度条 87% = 你不可能关掉游戏。这是人类行为心理学中最可预测的效应之一：**目标梯度效应**——越接近目标，动力越强。

## 6. 钩子 5: 因果涟漪 — 叙事投入

### 6.1 核心机制

游戏内部维护一个 **karmaLog**（因果日志），记录玩家的每一个重大选择：

```json
{
  "events": [
    {"id":"k_log_001","card":"q_beast_mercy","choice":"left","summary":"放过受伤妖兽"},
    {"id":"k_log_015","card":"fd_elder_trial","choice":"right","summary":"接受师尊试炼"},
    {"id":"k_log_023","card":"gd_monastery_raid","choice":"left","summary":"独自挑战寺院"}
  ]
}
```

### 6.2 涟漪触发时机

| 原始事件 | 涟漪时机 | 涟漪内容 |
|----------|----------|----------|
| 放过妖兽 | 3~5 张卡后 | 妖兽带领族群来报恩，+3修为 + 兽王印记 |
| 杀死妖兽 | 5~8 张卡后 | 妖兽宗门寻仇，强制战斗 |
| 拒绝师尊试炼 | 7~10 张卡后 | 师尊失望，传承值 -10，但另一条传承开启 |
| 接受魔道交易 | 4~6 张卡后 | 交易内容反噬，天魔索取代价 |
| 帮助陌生人 | 10~15 张卡后 | 陌生人实为隐世高人，传授秘技 |

### 6.3 涟漪的 "独特故事" 幻觉

涟漪卡的文案必须体现"这是你的选择导致的"：

> ❌ 坏文案: "一个妖兽出现在你面前。"
> ✅ 好文案: "三个月前你在青竹林放走的那只幼兽，如今已是妖兽之王。它记得你的气息。"

## 7. 钩子 6: 天机一闪 — FOMO 引擎

### 7.1 触发机制

```
每张普通卡:
  if random() < 0.03:
    当前卡立即变为"天机卡"
    展示平行世界的另一种可能
```

### 7.2 天机卡示例

```
┌─────────────────────────────────────────────┐
│             🜁 天 机 一 闪 🜁                │
│                                             │
│   若你当时选择了 "拒绝禁术"...                │
│                                             │
│   你将在三个月后发现：                       │
│   • 慕青岚没有被反噬                         │
│   • 你获得了 "清心诀" (稀有传承)             │
│   • 但魔道宗门不会视你为盟友                 │
│                                             │
│   [ 窥得天机，继续前行 ]                     │
└─────────────────────────────────────────────┘
```

### 7.3 为什么这是最强的钩子

天机卡有双重效果：
1. **即时**: 玩家看到"另一条路更好"→ FOMO 启动
2. **长期**: 玩家会在下次遇到类似选择时想起天机卡 → 行为改变 → "再开一局看看另一条路"

### 7.4 恶业加成

```
天机卡出现概率 = 3% + (恶业 / 200)%
```

恶业 200 = 天机出现概率 4%。天魔喜欢诱惑恶人。

## 8. 全局节奏设计

### 8.1 按境界的钩子密度

不同境界的钩子密度应该不同——新手需要更密集的正反馈：

| 境界 | 命盘间隔 | 残卷掉落倍率 | 天机概率 | 说明 |
|------|----------|-------------|----------|------|
| 炼气 | 每8张卡 | ×1.5 | 4% | 新手蜜月期，多给好东西 |
| 筑基 | 每10张卡 | ×1.0 | 3% | 基准线 |
| 金丹 | 每10张卡 | ×1.0 | 3% | 基准线 |
| 元婴 | 每12张卡 | ×0.8 | 2.5% | 中后期放缓 |
| 化神 | 每12张卡 | ×0.8 | 2.5% | 好东西更难拿 |
| 渡劫 | 每15张卡 | ×0.6 | 2% | 终局稀缺感 |

> 原则: 前中期给甜头，后期稀缺化——让玩家觉得"好东西越来越难遇到了"，创造"珍惜感"而非"麻木感"。

### 8.2 单次游戏会话的目标弧线

```
0 min   ─ 进入游戏，突破倒计时 64%，残卷 3/8
5 min   ─ 命盘轮转触发 → 翻到传说！兴奋峰值
8 min   ─ 突破倒计时 91%，每张卡都闪烁
10 min  ─ 突破失败 → 心魔反噬弹出 (低谷)
11 min  ─ 选择接受心魔 → 恶业+10 但获得意外修为 (反弹)
13 min  ─ 天机一闪 → 看到另一条路的可能性
15 min  ─ 再次突破 → 成功！进入金丹境界 (高潮)
```

一句话总结节奏设计：**高潮-低谷-反弹-惊喜-再高潮**，15 分钟内 5 次情绪起伏。

## 9. 实现优先级

### P0 (必须首批实现，改动最小效果最大)
| 系统 | 理由 | 预估工作量 |
|------|------|-----------|
| 突破倒计时 | 只需要一个 UI 进度条 + 已有的突破逻辑 | 0.5 天 |
| 命盘轮转 | 独立系统，不依赖其他钩子 | 1 天 |

### P1 (核心钩子)
| 传承残卷 | 需要新建数据表 + 掉落逻辑 | 1.5 天 |
| 心魔反噬 | 需要在突破失败路径上加分支 | 1 天 |

### P2 (叙事深度)
| 因果涟漪 | 需要 karmaLog 系统 + 涟漪事件表 | 2 天 |
| 天机一闪 | 需要平行世界内容 + 低概率触发 | 1.5 天 |

## 10. 平衡性验证清单

在实现后必须逐项验证：

- [ ] 炼气期玩家在前 20 张卡内至少获得 1 次传说/史诗命盘奖励
- [ ] 没有任何玩家连续 3 轮命盘全是普通/空卦（保底机制）
- [ ] 突破失败率在道心≥50时不超过 40%
- [ ] 传承残卷不会在单次会话中让玩家感到"根本集不齐"（前 50 张卡至少 3 套传承达到 4/8）
- [ ] 天机卡出现频率让玩家平均每 30 张卡遇到一次
- [ ] 因果涟漪的延迟不超过 15 张卡（太久玩家会忘记原始事件）
- [ ] 空卦后下一轮命盘必定有稀有以上奖励

## 11. 与现有系统的接口

```
上瘾引擎
  ├── 命盘轮转 ← 坊市 (命盘密钥) ← 道侣 (好感度加成)
  ├── 心魔反噬 ← 师尊 (传承值护体) ← 坊市 (心魔丹)
  ├── 传承残卷 ← 战斗 (Boss掉落) ← 坊市 (残卷探测器)
  ├── 突破倒计时 ← 修炼系统 (修为积累速度)
  ├── 因果涟漪 ← StoryNetworkSystem (karmaLog)
  └── 天机一闪 ← 恶业系统 (概率加成)
```

所有钩子都**利用已有系统的数据**，不需要重构现有代码。每个钩子可以独立开发和测试。
