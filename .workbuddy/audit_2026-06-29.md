## 漏洞清单

### P0 阻断性漏洞（叙事系统输出断链）

**问题**：`StoryNetworkSystem`、`CompanionSystem`、`NpcSystem`、`FactionSystem` 四个系统会通过以下事件发射叙事卡牌，但 `game.js` 完全没有监听这些事件：

```
storynetwork:narrativeCard  ← StoryNetworkSystem 的核心输出
companion:eventCard         ← CompanionSystem 弧线推进输出
faction:eventCard           ← FactionSystem 阵营事件输出
npc:encounterCard           ← NpcSystem NPC 遭遇卡输出
```

**后果**：玩家触发了好感值、传承值、弧线推进等叙事条件，系统内部确实生成了对应的叙事卡——但这些卡牌信号发射后进入了真空，`game.js` 从来不知道有卡要展示。

**修复方案**（在 `game.js` 的 `init()` 的事件监听区域添加）：
```js
// 叙事卡注入主流
eventBus.on('storynetwork:narrativeCard', (data) => {
  if (data && data.card) {
    this.currentCard = data.card;
    this._inCombat = false;
    this._triggerUpdate();
  }
});
eventBus.on('companion:eventCard', (data) => {
  if (data && data.card) { this.currentCard = data.card; this._triggerUpdate(); }
});
eventBus.on('faction:eventCard', (data) => {
  if (data && data.card) { this.currentCard = data.card; this._triggerUpdate(); }
});
eventBus.on('npc:encounterCard', (data) => {
  if (data && data.card) { this.currentCard = data.card; this._triggerUpdate(); }
});
```

### P1 严重漏洞（3张卡被境界过滤器永久跳过）

位于 `cards:qi` 模块的 3 张特殊卡牌缺少 `realm` 字段：
- `death`（死亡卡）
- `ending_ascension`（飞升结局卡）
- `path_select`（道途选择卡）

`_drawNormal()` 用 `card.realm === currentRealm` 过滤，这三张卡永远进不了抽卡池。

**修复**：这些是特殊流程卡，不应进抽卡池——应从 `cards:qi` 移除，改为由 `game.js` 的特殊逻辑（死亡/飞升/道途分叉）直接调用 `cardSystem.getCard(id)`。

**修复**：在 `index.html` 的初始化调用区域添加：
```js
if (typeof choiceEchoEngine !== 'undefined') choiceEchoEngine.init();
if (typeof sceneLayerSystem !== 'undefined') sceneLayerSystem.init();
if (typeof litPixelRenderer !== 'undefined') litPixelRenderer.init();
```
