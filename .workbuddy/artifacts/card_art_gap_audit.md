# 卡牌美术规格缺口审计报告

> 审计日期：2026-06-29 | 审计范围：265张卡牌 × 4维美术规格（画风 / 颗粒度 / 比例 / 氛围感）

## 一、现状总览

### 1.1 数据层 — **裸数据，零美术字段**

265张卡牌的 JSON 定义中，**没有任何一张包含美术相关字段**（`art`、`visual`、`sprite`、`texture`、`bgClass`、`mood`、`atmosphere`、`border`、`frame`、`theme` 等全部为空）。

```json
// 当前所有卡牌的典型结构（缺美术维度）
{
  "id": "q_start_sword",
  "type": "NORMAL",
  "title": "剑修入门",
  "description": "你在剑坪上感悟剑气..."
  // ← 缺少 art/video/mood/bgClass/sprite/texture 等全部美术字段
}
```

### 1.2 渲染层 — **仅覆盖 NPC 立绘，无卡牌类型视觉**

| 渲染系统 | 覆盖范围 | 缺口 |
|----------|---------|------|
| `PC98CardSystem.js` | 16个NPC角色（8核心+5随机+2青楼+1凡人） | 不覆盖卡牌类型差异 |
| `LitPixelRenderer.js` | 8核心NPC的WebGL光照 | 不覆盖卡牌类型差异 |
| `SceneLayerSystem.js` | 6个场景位置的氛围CSS类 | 不覆盖卡牌 |
| `UI.renderCard()` | 仅渲染 `card.type` CSS类名 + 可选NPC肖像 | 无卡牌框体、无类型背景、无氛围层 |

```js
// UI.js line 271 — 唯一的卡牌视觉关联
this.cardEl.className = `card card-${card.type.toLowerCase()}`;
// 例如: card card-normal, card card-combat, card card-destiny
// 但 style.css 中完全不存在这些类的样式定义！
```

### 2.1 NORMAL（93张）— 游戏主体内容

**代表卡牌**：`q_start_sword` 剑修入门、`f_sect` 宗门大比、`d_awakening` 化神觉醒

| 维度 | 当前状态 | 缺口 |
|------|---------|------|
| **画风** | 无 | 需要决定：用Lit Pixel渲染背景+前景？纯PC98？混搭？ |
| **颗粒度** | 无 | 精灵分辨率未定义（NPC立绘512×768，但普通事件卡尺寸未定） |
| **比例** | 无 | 卡牌显示比例：是否和PC98角色卡一样3:4竖版？还是16:9横版？ |
| **氛围感** | 无 | 93张卡分布在6个境界，每张卡的事件场所完全不同（剑坪/坊市/密室/山林），需要对应色调方案 |

**风险等级**：🔴 **致命** — 这是玩家看到最多的卡牌类型（35%），完全没有任何视觉方向。

---

### 2.2 SPECIAL（49张）— 魔道抉择 / 交织事件 / 飞升后

**代表卡牌**：`dp_demon_whisper` 魔道低语、`iw_orthodox_demon_clash` 正魔信仰交锋、`pa_fairy_tea` 仙茗论道

| 维度 | 当前状态 | 缺口 |
|------|---------|------|
| **画风** | 无 | 魔道线需要暗黑/血色视觉语言；交织事件需要双色冲突视觉；飞升后需要圣洁/超然视觉 |
| **颗粒度** | 无 | 魔气/灵气/仙气的像素化表现密度应该不同 |
| **比例** | 无 | 同上 |
| **氛围感** | 无 | 三套完全不同的情感色调：魔道（猩红+暗紫+压抑）、交织（冷暖冲突+撕裂感）、飞升（白+金+空灵） |

**风险等级**：🔴 **致命** — 三条核心叙事线（正魔抉择 / 跨线交织 / 飞升后内容）的视觉区分度为零。

---

### 2.3 KARMA（35张）— 因果系统

**代表卡牌**：`k_fox_returns` 狐影重现、`k_tianshu_echo` 天枢的回响、`k_body_ascension` 肉身不坏

| 维度 | 当前状态 | 缺口 |
|------|---------|------|
| **画风** | 无 | 因果应该是透明/半透明质感？还是轮回环视觉？ |
| **颗粒度** | 无 | 因果回响可能需要一种特殊的"褪色"或"重影"像素效果 |
| **比例** | 无 | 是否需要不同于普通事件的卡牌形状？ |
| **氛围感** | 无 | "因果"需要专属色调——轮回金？业火红？空灵白？ |

**风险等级**：🟡 **严重** — 因果系统是区别于传统卡牌游戏的核心机制，缺少视觉语言会让玩家无法感知"这是因果卡"。

---

### 2.4 DESTINY（23张）— 死亡 / 转生 / 道途选择

**代表卡牌**：`death_dao_collapse` 道消、`rb_memory_sword` 前世记忆·剑意、`path_select` 道途选择

| 维度 | 当前状态 | 缺口 |
|------|---------|------|
| **画风** | 无 | 死亡卡需要终结感（黑白？崩碎像素？）；转生需要轮回感；道途选择需要分岔路视觉 |
| **颗粒度** | 无 | 死亡卡可能需要更高对比度的像素处理 |
| **比例** | 无 | 命运卡可能需要不同的卡牌形状（圆形？门形？） |
| **氛围感** | 无 | 死亡=黑+白+血红；转生=淡金+白；道途选择=对称双色 |

**风险等级**：🟡 **严重** — 死亡是 roguelite 核心体验，没有视觉冲击力的死亡画面=没有情感重量。

---

### 2.5 QUEST（23张）— 六条支线任务链

**代表卡牌**：`q_sword_1~4` 剑道传承、`q_pill_1~4` 失传丹方、`q_tianshu_1~4` 天枢秘典

| 维度 | 当前状态 | 缺口 |
|------|---------|------|
| **画风** | 无 | 每条任务链应有独特的视觉丝带/图腾（剑纹/丹炉纹/阵纹/血纹/符文/狐纹） |
| **颗粒度** | 无 | 任务进度指示（1/4→4/4）需要视觉表达 |
| **比例** | 无 | 支线卡是否需要比普通卡更小的尺寸？ |
| **氛围感** | 无 | 每条链有自己的情绪线：剑道（锐利冷峻）、丹方（温暖药香）、秘典（神秘幽蓝） |

**风险等级**：🟡 **严重** — 六条支线如果全用同一套视觉，玩家无法区分"这是哪条任务线"。

## 四、优先级建议

```
🔴 P0 — 致命缺口（必须立即补）：
   1. 13种卡牌类型的 CSS 卡牌框体定义（style.css）
   2. 突破/瓶颈卡的视觉特效（游戏最高爽点）
   3. 死亡卡的视觉冲击力（roguelite核心）

🟡 P1 — 严重缺口（应尽快补）：
   5. 因果系统的专属色调
   6. 六条支线的视觉丝带/图腾
   7. SHOP卡的商业氛围
   8. DUNGEON卡的探索视觉层
   9. NPC遭遇/道侣事件的卡牌场景背景

🟢 P2 — 改进缺口（可逐步迭代）：
   10. LOCATION卡的CSS粒子动画实现
   11. 回响卡（Echo）的褪色/重影视觉
```
