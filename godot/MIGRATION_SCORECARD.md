## 一、怎么读这张表

| 列 | 含义 |
|---|---|
| **阶段** | 原子子项编号。大阶段已拆为可独立签收的小项 |
| **进度** | `已通过 / 总数`。允许部分通过，这是关键 |
| **状态** | `未开始` / `功能性通过` / `完全签收`（见下） |
| **证据** | 产出该状态的测试名或命令 |
| **未覆盖** | 已知但尚未验证的部分。**允许带未覆盖签收** |
| **M 对应** | 对应的原任务书 M 阶段 |

### 三态定义

| 状态 | 判定条件 | 可用性 |
|---|---|---|
| 未开始 | 无任何证据 | — |
| **功能性通过** | L0 可加载 + L1 冒烟 + L2(Tier A) 全过 | 可继续开发后续模块、可演示 |
| **完全签收** | 功能性通过 + L3 边界 + L4 视觉 + Tier B/C 达标 | 可进发布候选 |

> **L4 视觉不阻塞 L0–L3。** 美术未定稿不冻结功能进度。
