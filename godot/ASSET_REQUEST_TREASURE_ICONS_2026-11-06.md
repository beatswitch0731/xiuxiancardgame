1. 把 18 张 PNG 放进上面的 `items\` 目录

```

# 期望 NONCOMBAT_CONTENT_REPOSITORY_PASS ... unlisted=0
```

4. 手动验收：游戏内进入「法宝装备」弹窗，每行文字左侧应出现 26×26 图标；已装备与未装备的行都应显示。

## 五、为什么不是 55 张

55 件法宝里有 16 件都是 `artifact_4`（青云剑匣、万卷封魔残页等）。按「槽位 × 品阶」复用只需 18 张就能覆盖全部，且品阶视觉语言统一。若后续某件法宝需要专属图标，代码已支持优先读 `icon` 字段——但**当前不能加这个字段**：

`content/data/` 下每个 JSON 都在 `content/source_manifest.json` 的 `data[]` 里绑了 `sha256` 与 `bytes`。任何字节改动都会让 `noncombat_content_repository` 立刻报 `Source SHA mismatch` 并拒绝索引整个内容层（本次已实测复现并回滚）。要加字段必须先同步更新 manifest 的 sha256 与 bytes，那是独立的数据变更流程，不在本轮。
