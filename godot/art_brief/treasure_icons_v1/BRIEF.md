## 三、画风总则（硬约束）

项目美术母语（摘自 `docs/ART_DIRECTION_BIBLE_v1.md`）：

> **水墨结构、PC98 像素颗粒、暗色命书、克制的修仙异象**

落到这批图标上：

| 维度 | 要求 |
|---|---|
| 技法 | 手绘像素画。**硬边色块**，受控抖色。禁止平滑喷枪、禁止羽化 |
| 网格 | 按 **64×64 逻辑网格**作画，每格放大成 8×8 实心方块，输出 **512×512** |
| 抗锯齿 | **零**。不允许任何中间过渡像素，alpha 只有 0 或 255 |
| 描边 | 统一墨黑 `#141A19`，在 64 网格上 **1 像素**宽。禁止无描边、禁止双色柔边 |
| 色数 | 单图 **≤ 16 色**（凡品 ≤ 8、灵品 ≤ 12、真品 ≤ 14、玄品/仙品 ≤ 16） |
| 背景 | 完全透明，四角 alpha = 0 |
| 外框 | **不画**任何边框、圆角徽章、卡片底、圆形底盘 |
| 光照 | 无发光、无 bloom、无边缘光、无镜头光斑。体积只靠色块明度差 |
| 构图 | 单一物件居中，占画布约 78%，四周留 6 逻辑像素安全区 |
| 可读性 | 缩到 **26×26** 仍能一眼分辨物件类别 |

### 调色板（只准用这些）

| token | 色值 | 用途 |
|---|---|---|
| 墨 | `#141A19` | 描边、最深阴影 |
| 纸 | `#EEE5D1` | 亮面、布、纸 |
| 灰纸 | `#C9C3B4` | 铁、石、次级亮面 |
| 冷玉 | `#9FBCB1` | 玉、灵气、正道物件 |
| 旧金 | `#BDA77B` | 铜件、包角、环扣 |
| 深旧金 | `#8A7550` | 青铜暗部、木胎 |
| 朱砂 | `#B66C61` | **只用于危险/仙品点缀**，全图不超过一处 |
| 冷白 | `#F2F0E8` | 极少量高光，1~4 像素 |

### 品阶视觉分级（必须能一眼区分）

| 品阶 | 语言 |
|---|---|
| r2 凡品 | 只用墨 + 灰纸，无任何装饰件，轮廓最简 |
| r3 灵品 | 加一种材质色（旧金或冷玉），允许一处极简纹样 |
| r4 真品 | 加一档高光，允许两道结构线，材质分层清晰 |
| r5 玄品 | 允许一处朱砂或冷玉点缀，边缘可有一像素冷高光 |
| r6 仙品 | 允许一点天金/冷白，纹样最繁复；**仍禁止发光与粒子** |

## 七、禁止事项

| # | 禁止 | 原因 |
|---|---|---|
| 1 | 改文件名 | 代码按 `{slot}_{rarity}` 拼路径，改名即失效 |
| 2 | 加外框/圆角徽章/圆形底盘 | 图标已是列表行内元素，加框会双层套 |
| 3 | 用渐变或发光表达材质 | 破坏 PC98 像素颗粒感，且 26px 下糊成一片 |
| 4 | 画人物、手、脸 | 这是物件图标，不是立绘 |
| 5 | 写任何文字/数字/品阶角标 | 品阶已由行尾中文标出，重复且会乱码 |
| 6 | 改 `treasures.json` 加 `icon` 字段 | SHA 硬绑定，会让内容索引整体失败 |
| 7 | 输出 1024×1024 或非 8 倍数画布 | 会破坏 64 网格对齐，缩小时出现半像素 |

## 十、manifest.json 字段速查

给自动化流程用，人读可跳过。

| 字段 | 含义 |
|---|---|
| `items[].id` | 唯一标识，与文件名同源 |
| `items[].fileName` | 落盘文件名，**不可改** |
| `items[].outputPath` | 相对 `godot/` 的落盘路径 |
| `items[].absoluteOutputPath` | 绝对落盘路径，可直接写文件 |
| `items[].enginePath` | `res://` 引擎路径 |
| `items[].jsonRef` | 若将来改用数据字段时的引用写法 |
| `items[].subjectZh` | 中文内容说明（画什么） |
| `items[].prompt` | 英文正向 prompt，可直接投喂 |
| `items[].paletteHint` | 该张建议用色，取自统一调色板 |
| `items[].acceptance` | 该张的专项验收项 |
| `globalNegative` | 全套统一负向 prompt |
| `rarityLanguage` | 品阶视觉分级定义 |
| `canvas` | 画布/网格/块大小约定 |
